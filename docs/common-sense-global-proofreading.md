# 常识判断全局校对规范

## 目标

- 目录严格对应原书“篇—章—节—小节”，不再用合并目录或内部知识点代替正式层级。
- 知识卡内容准确、完整、不过时；表格、重点和插图与正文语义一致。

## 目录规则

1. 原书正式目录是主结构，固定采用“篇—章—节—小节”四级；小节是最小目录颗粒度。
2. 一个原书正式小节对应一个独立详情入口；同一小节内容较多时，可在该入口内部使用页签或卡片列表。
3. 小节内部的数字序号或主题标题属于知识点，只能作为页内结构，不得提升为目录小节或独立入口。
4. 多个章节可以复用底层素材，但不再共用同一个详情页；已合并且对应不精确的卡片直接拆分。
5. 暂无内容的章节保留位置并标记待整理；记忆关联不改变目录层级。

## 文字规则

1. 核对人名、年代、作品、数字、期限、比例、机构和概念边界。
2. 保留“原则上、通常、可以、应当、除外”等决定结论的限定词。
3. 检查OCR漏字、错字、串行，表格列错位及不同卡片之间的矛盾。
4. 法律、政策和动态科技以现行官方资料为准；与原资料冲突时修正正文并留下内部记录。
5. 填空直接整理为完整知识陈述；小程序不展示题干、答案或来源。

## 学习导读硬性门槛

1. 学习导读必须按小节内部的知识点逐项总结，每个知识点均须有独立导读，不得只提供整页或整小节总括。
2. 每条导读必须给出核心结论及可用于回忆的关系、顺序、对比、条件或易混边界；只复述标题或罗列本页内容视为无效。
3. 每个知识点导读必须保留到源文知识点 ID 的映射。知识点数量与有效导读数量必须一致，覆盖率不足 100% 时阻断发布。
4. 跨知识点时间线、总口诀和分类框架只能补充串联，不能替代逐知识点总结。
5. “30秒回顾”属于小节级全局总结，必须覆盖全部知识点并在所有页签保持一致显示，不得只挂在第一个页签或按页签拆分。

## 执行顺序

法律 → 经济 → 科技 → 历史与文学 → 全局目录、搜索与页面回归。

## 交付记录

每篇形成“原位置—当前问题—修正结果—核验依据”的校对记录；确定性问题直接修正，存在内容取舍的项目单独列出。

## 本轮结果

- 原书四篇目录及已整理章节的入口已逐项核对；第一篇恢复为“历史常识、文学常识、科技文化常识”三个正式章节。
- 已整理内容共 72 张详情卡；目录中的全部入口均能解析到有效分类或详情。
- 法律、经济、科技及文史中的复合详情已按正式章节或单一主题拆开。
- 14 张插图均使用 `common-sense/` 云端资源路径，由统一云函数换取临时地址；模型引用、资源清单与本地源文件一致。
- 数据结构校验无错误；刑罚、常见罪名及行政执法六节已依据现行法律补齐，法律篇不再包含待整理入口。
- 第二轮逐句交叉复核已覆盖全部72张详情页；正式目录38个末级入口均可解析，无缺失目标、占位文本或乱码。按约定未进行微信开发者工具72页全量点击截图，界面由用户抽样检查。
