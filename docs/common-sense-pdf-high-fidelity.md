# 常识 PDF 高保真解析实施说明

## 目标

在不依赖单一 OCR 结果的前提下，完整恢复 PDF 的文字、层级、表格、插图和重点样式，并转换为小程序可复用的知识卡。首轮试点范围为常识判断第 31-37 节。

## 核心规则

1. 每页同时读取 PDF 文本层和高清渲染图；文本层异常时只对异常区域使用中文 OCR。
2. 内容按标题、段落、列表、表格、插图和结构化知识实例拆分，不把整页压成连续文本。
3. 结构化实例优先还原为“名称、核心解释、补充、例子、易错点”等字段。
4. PDF 原有粗体必须保留；时间、数字、例外和易错内容可增加学习高亮，两类高亮分别记录。
5. 插图在解析阶段自动检测、裁剪和关联上下文；水印、Logo、二维码忽略，低质量或难判断图片标记为待补图。
6. 原文填空直接依据上下文和通用知识补全，按普通知识内容保存，不保留题干、空位或来源展示。
7. 每个知识点预留稳定 ID，后续可建立时间、因果、人物事件、对比和易混关系；本轮不生成关系网络。

## 处理流程

1. 建立 PDF、页面和内容区域清单。
2. 提取文字坐标、字体、字号、字重、线条和图片区域。
3. 识别 CID 乱码、阅读顺序异常、表格及疑似缺失区域。
4. 对异常区域执行 OCR，并与文本层结果合并。
5. 恢复篇章层级、表格单元格、知识实例和原文重点样式。
6. 使用通用知识补全空缺，复核法律数字、期限和专有名词。
7. 转换为小程序知识卡并生成逐页质量报告。
8. 通过数据校验和页面视觉抽查后，才允许替换现有内容。

## 试点产物

- 31-37 节逐页证据与风险清单。
- 结构化解析结果和插图资源清单。
- 修订后的常识知识卡。
- 页面覆盖率、乱码、表格、粗体、插图和人工复核报告。

## 验收标准

- CID 乱码为 0，章节标题顺序完整。
- 表格不被压成散乱文本，关键行列和重点样式可对应原页。
- 原文粗体、数字、期限、否定词和例外条件无明显遗漏。
- 核心插图已关联知识点；未采用的图片有明确分类结果。
- 填空已补成自然、完整、可直接学习的知识表述。
- 所有知识卡、目录引用和渲染数据通过项目校验。
