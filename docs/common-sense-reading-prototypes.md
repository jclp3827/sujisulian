# 常识详情页阅读优化实施说明

## 正式应用范围

- 思想与礼仪：先秦思想映射与“年龄称谓”复杂表格的移动端卡片化。
- 行政复议：程序、管辖和数字规则。
- 微观经济学：概念、比较和市场结构。
- 晚清危机与救亡探索：历史时间线。
- 词曲与戏剧：人物、流派与作品映射。
- 基础物理：规则、图示与辨析。

上述六张保留为“阅读优化样例”，用于集中查看特殊呈现方式；正式阅读层已覆盖全部 71 张常识详情页。

## 统一阅读层

每张常识详情页增加：学习导读、核心内容地图、阅读路线、当前页签的页内导航和30秒回顾。导读由已有标题、摘要、页签与内容块自动生成，不改变原始知识表述。

原有资料不删除。列表、图片和完整表格继续保留在速记之后。

## 内容呈现规则

- 长历史列表改为按阶段排列的时间线。
- “年龄称谓”（3列、8行）改为双列记忆卡：称谓为主标题，年龄和对象并列呈现；其他复杂表格统一采用单列信息卡，避免横向滑动。
- 复杂表格判定为“4列及以上”，或“3列且不少于5行”；当前共 29 张自动转换，其余表格保持原表格形态。
- 所有详情页的列表增加编号和独立卡片层级。
- 原图补充标题和说明，保持云函数图片加载方式不变。
- 历史时间线、年龄称谓记忆卡等特殊呈现保留为样例配置，后续按内容语义逐类扩展。

## 验收点

- 首屏可读出本页结论与四个高频判断点。
- 长页面可由页内导航定位到当前页签的知识段。
- 表格卡片在窄屏下无需横向滚动。
- 原目录、搜索、图片清单与详情数据校验继续通过。
