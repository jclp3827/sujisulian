# 常识详情页第二轮逐句交叉复核

## 复核口径

每个文字字段同时检查三层：原资料或权威来源、当前结构化字段、同卡及跨卡上下文。重点核对专名、年代、数字、条件、例外和“应当/可以/原则上”等限定词；图片仅核对资源引用与图文对应，不进行微信开发者工具全量逐页截图。

状态只使用三类：`已复核`、`待复核`、`需人工确认`。首轮目录整理、拆页或数据校验通过，不等同于第二轮逐句复核完成。

## 本轮主要修正

- 县级人大代表仍由选民直接选举；间接选举从设区的市级及以上人大代表开始。
- 全国人大“选举”与“根据提名决定人选”的权限分开表述。
- 国家主席按宪法职权表述为代表中华人民共和国进行国事活动、接受外国使节，不再使用容易误导的“唯一代表”判断。
- 民事法律行为无效规则补入“强制性规定不导致无效的除外”；不当得利按善意、恶意得利人分别表述。
- 丧偶儿媳、丧偶女婿列为第一顺序继承人，以“尽主要赡养义务”为前提。
- 盗窃罪不再机械等同于“秘密窃取”；交通肇事罪与危险驾驶罪按行为阶段、结果和主观罪过区分。
- 行政处罚普通程序并非一律法制审核，改为法定重大、听证及疑难复杂等情形审核。
- 行政复议普通程序复杂案件可延长，但最多不超过30日。
- GDP采用“常住单位在一定时期内生产活动的最终成果”；支出法采用“最终消费支出+资本形成总额+货物和服务净出口”。
- 用电安全区分绝缘与保护接地，不再写成所有用电设备均须接地。
- 《南京条约》赔款补全“银元”单位；平型关大捷补全“全国抗战以来、主动对日作战”的判断边界。
- 将含南宋陆游的“唐诗高峰”统一为“唐宋诗歌”；补齐元曲四大家中的白朴、郑光祖，并明确王实甫不属于四大家。
- 五人制篮球区分罚球1分与三分线内外2、3分；室内排球补充拦网触球不计入三次击球。

## 校验

- 常识模块：16个分类、72张详情页。
- 正式目录：4篇、38个末级入口，均能解析到有效分类或详情页。
- 模型校验：无结构错误、无缺失目录目标、无可疑占位或乱码；常识模块无搜索元数据警告。
- 界面检查：按约定由用户抽样，本轮不执行72张详情页全量点击与截图。
