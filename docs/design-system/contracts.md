# 花生开小灶 Design System V1.0：设计契约

治理包版本：`1.0.0-ds2.3`；阶段：DS-2；生效边界见 README。

approved 的批准依据为用户本轮列出的产品原则和 DS-2 治理授权；不表示当前实现、数值或设备效果通过验收。draft 供产品审定，不覆盖已验收行为。

## Foundations

### DS-FND-001｜继承现有基础

状态: approved

适用范围: 全部模块；基础设施

替代: 无

继承 theme.wxss、公共 UI、module-home、组件和阅读样式。六层是逻辑职责，不另建六套框架。批准原则不批准任何具体视觉数值；现有数值仅是实现观察。

### DS-FND-002｜数值与几何候选规则

状态: draft

适用范围: 视觉变更消费者

替代: 无

文字、页面边距、卡片内距、控件间距、圆角、阴影、图标及必要动效按角色登记。等值整理、待审统一、长期角色差异分别处理；不自动换算 px/rpx，不因数值相同归并。对比度、触控与适配承接专项文档的适用目标，须同构建验证。

## Themes

### DS-THM-001｜模块身份与状态分离

状态: approved

适用范围: 四模块及公共组件

替代: 无

保留花生笔记、公考常识、政治理论、行测速练长期皮肤。主题色不等同正确、错误、警告或记忆评价；身份、知识语义、系统结果独立表达。

## Semantics

### DS-SEM-001｜客观结果语义

状态: approved

适用范围: 客观答题及通用操作状态

替代: 无

客观答题错误采用红色，并与选中、正确、警告、禁用、加载、完成分别定义。该原则不得被解读为本阶段直接替换页面颜色。具体红色色值及组合尚未批准。

### DS-SEM-002｜记忆自评独立

状态: approved

适用范围: 记忆与回忆任务

替代: 无

记住了、有点模糊、没想起、跳过属于记忆评价，不等同客观答题对错；不得自动套用错误红色、答题评分或正确率。

### DS-SEM-003｜操作状态候选协议

状态: draft

适用范围: 共享操作和状态组合

替代: 无

同角色保持主、次、辅助层级；默认、按下、选中、处理中、禁用、结果和失败分别描述。禁用不擦除已产生的正确/错误结果。异步操作绑定任务与内容身份，防重复提交；具体锁与反馈方式由适配器实现。

## Components

### DS-CMP-001｜复用分类与业务边界

状态: approved

适用范围: 全部登记组件与 Pattern

替代: 无

A 全局公共、B 可配置公共、C 业务专用、D 待治理。C 是正常成员；A 不要求一次迁移全部页面。公共结构、视觉及操作协议不得定义评分、正确答案、记忆结果、业务进度、完成条件、队列或业务持久化。已有带副作用组件只登记，不因此自动获得拆改授权。

### DS-CMP-002｜消费者与复用选择

状态: approved

适用范围: 共享能力的变更和新功能

替代: 无

开发前查登记、源码、示例和真实消费者，说明复用/配置/扩展/新建选择；合理新建允许存在。修改公共能力核对所有消费者，记录例外与影响。登记中的 draft 实现不因被引用变为批准设计。

### DS-CMP-003｜卡片角色

状态: approved

适用范围: 卡片和内容表面

替代: 无

卡片按角色建立共同几何语言；阅读正文保留特殊性。入口、题目、反馈等具体角色数量、密度、圆角和阴影为待审候选，禁止反向把现有值标为批准规范。

## Patterns

### DS-PAT-001｜进度输入与业务统计

状态: approved

适用范围: 进度、计数及学习指标

替代: 无

输入：模块提供当前位置、总量、完成量、比例及标签。触发：任务状态更新。展示状态：当前位置、已处理、跳过、完成、无任务应可区分。结果：仅表达给定事实。恢复：模块恢复任务后重新提供视图。业务责任：组件不自行改变统计口径、分母或完成条件。

### DS-PAT-002｜两种选择题任务模式

状态: approved

适用范围: 客观选择任务

替代: 无

即时提交：有效点击直接产生业务作答，反馈后按业务规则锁定。确认提交：先形成可修改的草稿，再显式确认。结果由模块判断。恢复包括内容身份、选择、提交、反馈及必要的查阅/答案暴露事实。按任务角色选择模式；现有页面采用哪种模式属于事实，不自动批准改动或认定全部相同。

### DS-PAT-003｜两种记忆前进模式

状态: approved

适用范围: 记忆自评任务

替代: 无

输入：内容身份、是否揭晓、可用反馈、资源就绪和模块状态。触发：揭晓或有效自评。支持自动前进与停留核对两种模式；自评含义由业务管理。恢复：当前卡片、揭晓、评价及来源位置。重复触发不能误用到另一张卡片；具体改造须另获授权。

### DS-PAT-004｜设置生效与恢复

状态: approved

适用范围: 学习设置与显示设置

替代: 无

设置必须声明角色、生效时机及是否影响活动任务；不得静默重置任务。输入为草稿或显示偏好，保存/取消职责明确，失败不能冒充已保存。立即刷新、下一组生效及阅读即时显示均可按业务角色存在。恢复由所属模块负责，不统一改写存储。

### DS-PAT-005｜组合体验候选契约

状态: draft

适用范围: 搜索、来源往返与异常恢复

替代: 无

搜索保留查询、范围、意图及结果位置；来源往返保留同题/同卡/揭晓/滚动状态。加载、无内容、失败、未保存、过期分别表达。重试同一意图，失败不能被假成功覆盖。退出、返回与完成分开。该条作为候选规范，不追加更改现有业务流程的授权。

## Experience

### DS-EXP-001｜家族感与任务独立

状态: approved

适用范围: 全产品

替代: 无

统一交互语法和产品家族感，不强制所有页面相同。笔记、常识、政治优先横向治理；行测速练是成熟实践参考，暂不主动改造其内部体系。专项控件、限时训练、照片处理等合理独立。

### DS-EXP-002｜阅读独立性

状态: approved

适用范围: 阅读正文及相关控件

替代: 无

阅读正文允许专门的字号、行距、排版宽度和内容层级；外围公共控件保持共同语言。不得把长文或知识正文强制转换为普通题目卡；已有阅读专项只在其批准范围内适用。

### DS-EXP-003｜状态、授权与分层证据

状态: approved

适用范围: 规范使用、修改和验证

替代: 无

已审定产品原则可作为规则；数值、未经验证的视觉差异及候选交互不得标 approved。已有行为不因原则获批而自动获得修改授权。静态检查、控制器/业务检查、真实页面、设备验收和发布分别报告；不得因测试通过自动接入候选。

### DS-GOV-001｜跨对话执行闭环

状态: approved

适用范围: 规范发现与演进

替代: 无

当前索引是唯一规范入口。规则、组件与例外使用稳定 ID。开发前选择、开发后检查与证据形成闭环；新建不要求机械复用，行为变化遵守产品授权。隔离树规则不自动约束未接入树；版本接入、兼容、弃用和消费者影响必须明确。

## 当前实现冲突的处理

记录“当前源码事实 → 相关规则 ID/状态 → 消费者和风险 → 保留/适配/需授权变化”。原则与当前行为不一致时先保持行为，报告差距，不为满足检查而更改业务。已批准原则冲突由当前用户指令及索引适用范围处理；两个 approved 条款同范围冲突时暂停受影响决定并报告。

## 待产品审定

具体色值与字号/密度、角色卡片几何、每类任务采用哪种提交/前进策略、进度条的具体标签和呈现、活动任务设置的具体适配方案仍需在 DS-3 或对应批次审定。选择题和自评支持两种模式已经批准，不重复上交为问题。
