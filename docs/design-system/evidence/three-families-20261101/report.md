## 工程与行为验证

开发者工具最终编译 PASS，原始结果见 build.json。Design System 激活检查 PASS（1.0.0-ds2.3 adopted-common-baseline）；验证器自测 52 项、本地交互分发 4 项、政治隔离记录可靠性 13 项 PASS。前后原始记录在 tests/。常识学习、笔记学习页面、笔记记忆旧脚本均在基线与候选失败，保留原始断言，不记通过。没有修改业务 JS、评分、题库、存储、云函数或学习队列。

四个改动模板的事件绑定序列与基线一致；CSS 调整双按钮可见顺序以使主操作靠右，未替换处理器。没有把截图投影当作真实点击，真实提交、设置往返、保存恢复、连点防重复、按下触摸、iOS/Android 字体和底部安全区仍需实际交互验收。

375/428 无可靠自动化机型切换能力，未用 mock 系统尺寸伪造测试。已请求用户协助切换；未回复或未实测仍保留 NOT TESTED。390 的可见表面与控件几何可供产品初审，不能据此宣布全屏宽或全部消费者状态验收通过。

用户后续明确选择“本轮先保留其他宽度未验证”。因此 375/428 在本轮按用户决定延期，状态仍为 NOT TESTED；不再请求本轮切换，不据此扩大 390 宽结论。

## 最小接入与回退

相对 acdb1c1 仅两个样式文件、四个页面的 WXML/WXSS、登记及本证据目录；后续接入应选择这些精确差异，并将两种共享样式视为不可拆散的消费者包。候选继承 DS-2.3 真实祖先关系，但不因此使新规则在旧树或 main 生效。产品批准后还需针对实际目标版本逐页协调、检查题库并行任务和消费者，运行构建、显示和真实交互回归；不整体合并旧候选历史。回退采用各检查点反向补丁或检出基线到独立树，不重置主线、不改变业务记录。
