## 设计原因与自主复查

上一轮将相同角色归类，却没有共同可测尺寸；原生 button 和 view 各自沿用不同宽度、行高、内边距和外层布局。前次缺少同视口横向测量，错误地把截图存在视为一致性证据。

本轮先在基线同视口实测，再建立 [候选规格](spec.md)，采用局部共享样式而保留各页面的 handler。首次实现的原生 button 实测扩成 184px、view 为 78px；修正宽度后又发现三个原生 button 被容器推向中间，分别修正笔记练习、常识每日及常识设置返回的对齐。最终整页对照和几何表重新检查了所有主要消费者。导读由 26px 增至 44px 后标题区高度变化仍需产品审定；固定 78px 仅适用于本轮四字文案，不是通用长文案规则。

PAT-ACTIONS 新增该 draft 样式的源码和四个实际页面登记；原 approved 产品契约与其他实现状态未升级。后续新增同类入口应先查此候选及规格、检查实际文案、逐页面实测边界和右对齐，并与真实页面拼图复核；不得只看 CSS 类名。
