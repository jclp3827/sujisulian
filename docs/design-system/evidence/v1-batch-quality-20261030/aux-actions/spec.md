# 学习页面辅助操作候选规格

状态：设计候选，未经产品批准。基线 `548a5948` 的 390 宽真实页面测量分别为笔记练习 74×46、笔记记忆 93×44、常识每日 74×44、知识导读 62×26、政治练习 66×45、笔记返回学习 83×29 CSS px。截图及各自夹具见 before/。

比较后采用：白底细边、蓝色文字、圆角矩形；四字入口视觉框和点击区为 78×44px，左右各 12px 内边距；13px、字重 600、8px 圆角、1px 边框，文字垂直水平居中。首次实测发现原生 button 的 auto 宽度为 184px 而 view 为 78px，故明确限定本次四字文案宽度；其他文案长度需另行适配。采用完整 44px 可见框以避免透明触控区与相邻操作互相覆盖；不额外给入口套卡片。按下变浅蓝；原生 button 的 disabled 使用半透明样式，view 的禁用条件和事件拦截由业务负责，本轮入口无禁用状态。色彩使用当前学习域蓝色，政治保持蓝色身份；不改变其他角色的颜色。

标题与操作在同一行时垂直居中，两者间至少 8px；标题允许自然换行，按钮不收缩，右侧对齐页面内容边界。多辅助操作如“全部卡片”保留文本次级层级、与设置按钮保持间距。导读的分类标签与按钮同一行、标题和组说明第二行，属于带分类的布局变体；政治标题带说明，保留原文本顺序，按钮居中对齐标题组。原生导航栏和安全区不参与页面标题区计算。

学习设置与返回学习共享外观但保留各自 handler；政治 daily 的“一问一答”是跨模式导航，仍可使用同级辅助外观但不得改语义。普通底栏、选项和记忆自评不采用此规格。现有 PAT-ACTIONS 的普通操作试点允许保留几何，故此为限定消费者的新候选，不更改 approved 契约或宣布组件 approved。
