# 03 审计与质量门禁

> 状态：通用门禁已确认；政治内容的时效性与官方来源清单待资料到位后补充

## 基本判断

OCR 无法证明零错误。本试点追求的是：错误更容易暴露、关键内容必须复核、所有修订可追溯、未解决风险不能发布。

## 三层事实

1. **原始证据层**：忠实保存资料原貌，不因资料可能过时而改写。
2. **事实校对层**：记录官方现行表述、修订原因、依据和日期。
3. **学习展示层**：在不丢失事实和条件的前提下，生成地图、完整内容、速记卡和导读。

如果政治资料与官方现行表述不一致，正式页面采用已确认的现行内容，但必须保留原文、修订记录和依据。

## 风险等级

### 高风险：必须人工确认

- 年份、数字、比例、期限、届次和人数。
- 否定词、例外、条件、范围和程度词。
- 政治理论的固定表述和关键词。
- 会议、文件、机构、领导关系和职权。
- 公式、符号、上下标和表格合并单元格。
- 不同来源冲突的内容。
- OCR 引擎结果不一致的内容。

### 中风险：双证据一致后抽样或专项确认

- 人名、地名、著作和历史事件。
- 长段落中的顺序、并列和父子层级。
- 图片与图注归属。
- 自动生成的知识点边界和关系。

### 低风险：可自动通过但进入抽样

- 两路证据一致的普通说明文字。
- 已在同一资料中多次稳定出现的非关键格式文字。
- 页眉页脚、水印等明确排除区域。

风险低不等于事实正确；抽样用于发现模型共同错误和规则盲区。

## 审核状态

```text
pending → in_review → approved
                    ↘ rejected
approved --源文件或规则变化--> stale → in_review
```

- `pending`：尚未审核。
- `in_review`：正在处理差异或对照来源。
- `approved`：当前来源版本下可进入正式知识源。
- `rejected`：识别不可用或内容不应纳入。
- `stale`：来源、提取工具或校对依据变化，旧审批失效。

## 单元级审核记录

每次人工决定至少记录：

```json
{
  "unitId": "politics-s001-p003-u012",
  "decision": "use-corrected-text",
  "before": "",
  "after": "",
  "reason": "",
  "evidence": [],
  "reviewedAt": "2026-08-27",
  "sourceHash": "..."
}
```

单人试点不强制虚构 `reviewedBy`；未来多人协作时再增加身份字段。

## 自动门禁

### 来源完整性

- 原始文件哈希与清单一致。
- 页数、页面图和页级记录数量一致。
- 正文区域均已映射或排除。
- 正式知识引用的 `source_units` 均存在。

### OCR 与版面

- 未解决差异数量为 0。
- 高风险单元均为 `approved`。
- 表格行、列、逻辑单元格和合并关系一致。
- 公式均保留原图证据并完成审核。
- 无未解释的标题跳级、跨栏串行或页间丢失。

### 事实校对

- 需要现行校对的内容均有官方依据、校对日期和状态。
- 原文与展示文字不一致时有明确修订记录。
- 未经确认的 AI 建议不能出现在正式展示层。

### Markdown 知识源

- 稳定 ID 唯一，状态允许发布。
- 必填属性、目录归属和来源引用完整。
- 内部链接可解析，无循环前置依赖。
- 卡片能够形成明确的“提示—回忆—答案”，不是正文截断。

### 小程序输出

- 正式 Markdown 与运行时内容映射一致。
- 地图节点、目录、搜索索引和卡片均能找到目标知识点。
- 不存在草稿、待审或过期内容泄漏到发布包。
- 数据结构和包体检查通过。

## 人工验收单

每个发布批次输出一页简表：

- 来源文件、版本和页码范围。
- 页面数、正文区域数、证据单元数。
- 文本层/OCR 差异数及已解决数。
- 高、中、低风险单元数量。
- 表格、公式、图片数量及审核状态。
- 知识点数、来源映射覆盖率和卡片覆盖率。
- 现行校对项和官方依据。
- 待处理项、排除项及原因。
- 构建版本与小程序知识包版本。

## 抽样策略

首个政治试点采用更严格的抽样：

- 高风险内容 100%检查。
- 每种版面类型至少抽查一页。
- 低风险普通段落按批次抽查。
- 每次升级 OCR 或结构模型后，对固定金标样本全量回归。

若抽样发现一种新错误，必须：

1. 搜索整个批次是否存在同类问题。
2. 补充自动检测规则或提高对应风险等级。
3. 使受影响的已审核单元失效。
4. 重新运行相关门禁。

## 发布阻断原则

以下任一情况存在时禁止发布：

- 正式内容无法回到原始证据。
- 高风险文字未人工确认。
- OCR 差异未解决却被自动选中。
- 表格或公式结构无法确认。
- 来源可能过时但未完成现行校对。
- 草稿或 `stale` 内容进入运行时。
- 为了页面简洁而截断、隐藏或改写关键条件。
