## 启动前不做的假设

资料已提供（政治理论 / 政治理论.pdf），因此以下项从首批样本中补决：

- 政治模块正式目录层级。
- 原始资料的权威性和时效范围。
- 总页数、扫描质量和表格比例。
- 一个详情页对应章、节、小节还是知识点。
- 首批上线覆盖范围。
- 是否需要现行政策或官方文件校对层。
- 最适合政治内容的地图和卡片类型。

这些决定必须根据真实资料样本产生。

## P0：资料接收与范围冻结

输入：用户提供的政治 PDF、图片、补充来源或说明。

执行：

- 建立来源清单、哈希和页数。
- 识别资料版本、目录、答案版和勘误版。
- 检查授权、时效和官方校对需要。
- 选择能代表普通段落、表格、图片、复杂版面和高风险表述的样本页。
- 确定首个可完整验收的正式目录单元。

产物：

- 政治来源清单。
- 资料质量报告：见 [09-political-intake-log](./09-political-intake-log.md)。
- 样本页清单。
- 首批边界和排除项。

退出条件：资料完整，试点范围明确且没有依赖现有模块内容。

## P6：更新演练与复盘

至少模拟一次资料更正或新增：

- 加入一个新来源版本或修改样本页。
- 验证来源哈希使相关审核失效。
- 重新审核受影响单元。
- 生成内容差异和新知识包。
- 验证未受影响内容保持稳定。

复盘记录：

- 自动处理比例和人工审核负担。
- OCR 漏错类型和规则补充。
- Markdown 编辑效率。
- 地图、详情和卡片使用问题。
- 本地进度与版本兼容问题。
- 是否具备迁移现有模块的收益。

## 试点结束后的决定

只允许三种结论：

1. **通过**：流程可靠，开始制定现有模块迁移顺序。
2. **有限通过**：政治模块继续使用，但暂不迁移旧模块，并修复明确瓶颈。
3. **不通过**：保留有效工具和内容，停止扩大范围，不为统一形式继续投入。
