# 第五节 建设社会主义文化强国

## 一句话理解

建设社会主义文化强国要坚持党的领导和马克思主义在意识形态领域的指导地位，坚定文化自信，弘扬革命文化并推动中华优秀传统文化创造性转化、创新性发展。

## 速记卡

### 提示

建设社会主义文化强国，党的领导、马克思主义指导地位和文化自信各是什么定位？

### 答案

党的领导是中国特色社会主义文化发展道路最本质的特征；马克思主义是根本指导思想，要坚持其在意识形态领域的指导地位；坚定文化自信是建设社会主义文化强国、推动社会主义文化繁荣兴盛的关键。

### 易错

不要把文化自信理解为排斥其他文明成果。
