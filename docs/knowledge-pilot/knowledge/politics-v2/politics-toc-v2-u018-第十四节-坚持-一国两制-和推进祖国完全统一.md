# 第十四节 坚持“一国两制”和推进祖国完全统一

## 一句话理解

“一国两制”首先要坚持一国原则，同时尊重两制差异，维护国家主权、安全、发展利益并推进祖国完全统一。

## 速记卡

### 提示

怎样理解“一国”和“两制”的关系？

### 答案

“一国”是根本，是实行“两制”的前提和基础；“两制”从属和派生于“一国”，并统一于“一国”之内。

### 易错

不要把“一国”和“两制”理解为并列且相互独立。
