# 第十五节 中国特色大国外交

## 一句话理解

中国特色大国外交服务民族复兴和人类进步，推动建设新型国际关系、构建人类命运共同体。

## 速记卡

### 提示

新时代中国特色大国外交的重要目标是什么？

### 答案

推动建设新型国际关系，推动构建人类命运共同体，为民族复兴创造有利外部条件并促进人类进步。

### 易错

不要把和平发展误解为不维护国家核心利益。
