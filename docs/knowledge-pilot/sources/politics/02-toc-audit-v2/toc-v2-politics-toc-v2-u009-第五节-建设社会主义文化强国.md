第五节 建设社会主义文化强国
【考场传真】
（单选）习近平总书记强调，要锚定2035年建成文化强国的战略目标，不断
增强人民精神力量，筑牢强国建设、民族复兴的文化根基。下列做法有利于文化
强国建设的是：
①坚持用马克思主义激活中华传统文化中的优秀因子并赋予其新的时代内涵
②坚持在文化建设中把经济效益放在首位、经济效益与社会效益相统一
③坚持把激发创新创造活力作为深化文化体制机制改革的中心环节
④坚持利用第一、合理发掘和积极干预原则，推动文化遗产系统性保护和利用
A.①③ B.①④ C.②③ D.②④
【考点精析】
1.中国具有百万年的人类史、一万年的文化史、五千多年的文明史。中华文
明是世界上唯一绵延不断且以国家形态发展至今的伟大文明。中华文明有连续性、
创新性、统一性、包容性、和平性的突出特性。
2.中国特色社会主义文化发展道路最本质的特征是坚持党的领导。
3.建设社会主义文化强国、推动社会主义文化繁荣兴盛，关键在于坚定中国
特色社会主义文化自信。
4.要坚持发展社会主义先进文化，弘扬革命文化，传承中华优秀传统文化。
5.马克思主义是我们立党立国、兴党兴国的根本指导思想，要坚持马克思主
义在意识形态领域指导地位的根本制度。
6.要坚持创造性转化、创新性发展，用马克思主义激活中华传统文化中的优
秀因子并赋予其新的时代内涵。
7.坚持保护第一、合理利用和最小干预原则，推动文化遗产系统性保护和统
一监管。
8.弘扬以伟大建党精神为源头的中国共产党人精神谱系。
9.坚持以人民为中心的创作导向，坚持把社会效益放在首位、社会效益和经
济效益相统一，把激发创新创造活力作为深化文化体制机制改革的中心环节。
10.宣传思想文化工作的首要政治任务是用党的创新理论武装全党、教育人
民。
11.文化强国之“强”最终要体现在人民的思想境界、精神状态、文化修养上。
【小黑母题特训】
（单选）文化是一个国家、一个民族的灵魂。建设社会主义文化强国，是实现
中华民族伟大复兴的必然要求。下列相关说法，正确的是：
①要坚持发展社会主义先进文化，弘扬革命文化，传承中华优秀传统文化
②建设社会主义文化强国、推动社会主义文化繁荣兴盛，关键在于坚定中国
特色社会主义文化自信
③马克思主义是我们立党立国、兴党兴国的根本指导思想
④文化强国之“强”最终要体现在国家文化产业的规模和经济贡献上
