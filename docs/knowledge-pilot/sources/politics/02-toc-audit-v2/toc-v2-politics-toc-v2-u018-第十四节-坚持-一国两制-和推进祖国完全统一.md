第十四节 坚持“一国两制”和推进祖国完全统一
【考场传真】
（单选）关于“一国两制”，下列说法错误的是：
A.“一国两制”的基础和前提是“一个中国原则”
B.“一国两制”构想最初提出来是为了解决台湾回归问题
C.“一国两制”的构想成功运用的最早范例是香港回归
D.“一国两制”的最高原则是保持香港、澳门长期繁荣稳定
【考点精析】
一、全面准确理解和贯彻“一国两制”方针
1.“一国两制”是指在统一的国家之内，国家主体实行社会主义制度，个别
地区依法实行资本主义制度。“一国”是实行“两制”的前提和基础。
2.“一国两制”的最高原则是维护国家主权、安全、发展利益。
3.“一国两制”的提出是从解决台湾问题开始的。
4.“一国两制”在实践中首先运用于解决香港问题、澳门问题。
5.全面管治权是授权特别行政区高度自治的前提和基础。
二、全面贯彻新时代党解决台湾问题的总体方略
1.坚持党中央对对台工作的集中统一领导，这是统一的根本保证。
2.坚持“和平统一、一国两制”基本方针，这是统一的大政方针。
3.坚持一个中国原则和“九二共识”，这是统一的政治基础。
4.坚持推动两岸关系和平发展、融合发展，这是统一的实践途径。
5.坚持团结台湾同胞、争取台湾民心，这是统一的根本动力。
6.坚持决不承诺放弃使用武力，这是统一的战略支撑。
【小黑母题特训】
（单选）解决台湾问题、实现祖国完全统一，是党矢志不渝的历史任务，是全
体中华儿女的共同愿望，是实现中华民族伟大复兴的必然要求。下列与之相关的
表述正确的是：
①坚持决不承诺放弃使用武力，这是统一的政治基础
②坚持团结台湾同胞、争取台湾民心，这是统一的根本动力
③坚持推动两岸关系和平发展、融合发展，这是统一的实践途径
④坚持一个中国原则和“九二共识”，这是统一的战略支撑
A.①② B.②③ C.③④ D.②④
