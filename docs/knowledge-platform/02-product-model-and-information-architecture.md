## 1. 本文要解决什么

本文冻结通用知识平台的产品骨架：用户处于什么认知状态、首页负责什么、怎样建立焦点、四种活动和四类目标怎样组合，以及政治、常识、笔记怎样使用同一模型而不被强制做成同一界面。

本文不决定具体地图布局、内容块视觉和动画参数。

## 2. 推荐产品模型

平台以“知识焦点”而不是“页面”为中心。用户有两个顶层状态：

```text
无焦点
├─ 观察知识领域
├─ 选择学习目标
├─ 搜索或提出问题
└─ 恢复最近焦点

已聚焦
├─ 体系定位
├─ 关系探索
├─ 完整阅读
└─ 主动回忆
```

页面只是这些状态的移动端容器，不定义知识本体。

## 3. 默认认知链路

推荐默认链路：

```text
领域地形
→ 知识区域
→ 当前知识焦点
→ 关系定向
→ 完整阅读
→ 主动回忆
```

### 为什么关系在阅读之前

阅读前的“关系定向”只提供受控上下文：

- 需要先知道什么。
- 它属于哪个知识区域。
- 最容易与什么混淆。
- 为什么值得进入完整阅读。

它不要求用户先理解全部关系。阅读后可以进入“深度关系探索”，沿相邻知识切换焦点并记录探索轨迹。

因此关系分为两个深度：

- `orientation`：阅读前的一层定向。
- `exploration`：阅读后或用户主动触发的关系探索。

## 4. 首页信息架构

### 4.1 首页必须包含

1. 模块 L0 知识地形。
2. 继续探索：最近焦点及其路径。
3. 用户目标入口。
4. 搜索或问题入口。
5. 内容状态说明，仅在模块存在校对或版本风险时显示。

### 4.2 首页不包含

- 全量知识单元平铺。
- 无焦点速记卡。
- 独立的目录、地图、搜索、卡片功能大厅。
- 需要先理解具体知识点才能使用的关系工具。

### 4.3 推荐首页结构

```text
模块标题与一句话说明

知识地形 L0
├─ 主要知识区域
└─ 进入目录投影

继续探索
└─ 最近焦点 / 最近路线 / 无记录时隐藏

选择目标
├─ 快速了解
├─ 系统学习
├─ 易混突破
└─ 考前速记或模块等价目标

搜索或提问
```

四类目标不要求每个模块使用完全相同的展示文案，但必须映射到通用路线类型。

## 5. 四种认知活动

### 体系

用于发现、定位、返回和选择焦点。可以表现为地形、目录、主题列表或其他模块投影，但必须由正式导航数据生成。

### 关系

围绕当前焦点解释前置、后续、易混和相关。没有已确认关系时自然降级为路径、同级或来源上下文，不能造假。

### 阅读

承载完整事实、结构化理解、易混边界和来源证据。它是其他形态的事实母体。

### 回忆

在明确焦点或范围内要求用户主动恢复内容。无范围时必须先选择范围、恢复上次范围或随机抽取并明确说明范围。

## 6. 四类用户目标

### 快速了解

适合首次进入或时间有限。默认停留在地形 L0–L2、核心知识和一句话理解，不自动把用户送入长正文。

### 系统学习

先选择导航范围，再利用正式顺序和前置关系形成连续路线。路线必须可说明“为什么按此顺序”。

### 易混突破

只在模块存在已确认易混数据时启用。入口先展示易混对，随后进入对照阅读和辨析回忆。

### 考前速记

政治和常识可以使用该名称；笔记模块可配置为“快速回顾”。无论文案如何，都必须先获得范围，不能默认第一篇知识。

## 7. 跨模块落法

| 模块 | L0 地形 | 导航节点 | 默认目标侧重 | 无关系时降级 |
|---|---|---|---|---|
| 政治 | 两篇理论区域 | 部分、篇、章、节、知识点 | 系统学习、易混突破、考前速记 | 显示正式目录路径和同级知识 |
| 常识 | 学科/主题区域 | 层级、学科、分类、知识点 | 快速了解、系统学习、易混突破 | 显示分类路径、规则和对照 |
| 笔记 | 科目知识地图 | 科目、分类、知识点 | 快速了解、系统学习、快速回顾 | 显示科目路径和相关题型/引用 |

模块配置负责名称、导航节点类型、可用目标和增强镜头；通用平台负责状态、返回、降级和内容一致性。

## 8. 入口与焦点建立规则

| 入口 | 无焦点时行为 | 建立焦点后默认活动 |
|---|---|---|
| 知识地形 | 逐层选择导航区域或知识单元 | 关系定向 |
| 目录投影 | 精确定位知识单元 | 关系定向 |
| 搜索结果 | 先展示路径、摘要、命中和关系概况 | 用户选择体系/关系/阅读 |
| 问题入口 | 定位直接知识、相关和易混候选 | 结果预览 |
| 快速了解 | 选择区域或采用模块推荐范围 | 体系 |
| 系统学习 | 必须选择正式范围 | 体系/关系定向 |
| 易混突破 | 必须选择易混对或区域 | 关系 |
| 考前速记 | 必须选择、恢复或明确随机范围 | 回忆 |
| 深链 | 直接恢复知识单元及指定活动 | 深链指定活动 |

## 9. 返回与循环

默认“返回”不是简单上一篇页面，而是返回认知来源：

- 从阅读返回关系定向：保留内容锚点。
- 从关系切换相邻知识：加入探索轨迹。
- 从相邻知识返回：回到上一焦点和关系视窗。
- 从焦点返回地形：恢复原导航节点和视窗。
- 从回忆回看原文：定位对应内容块。
- 完成回忆后：可返回路线、体系或继续下一项。

具体状态字段由03文档定义。

## 10. 异常和降级

### 没有关系

隐藏深度关系入口；关系定向显示目录位置、同级知识或来源上下文，并说明暂无已确认关系。

### 没有回忆项

隐藏回忆入口或显示“返回完整内容”；不能临时从正文随机挖空。

### 没有最近焦点

首页隐藏继续探索，不使用第一条知识伪造历史。

### 没有地图能力

以目录或主题列表提供完全可达的等价导航。

### 数据处于校对状态

可以在隔离试验环境展示明确状态，但不能因 UI 完成而获得发布资格。

## 11. 验收场景

### IA-AC-001：无焦点回忆

给定用户从未进入某模块，当点击考前速记时，系统必须要求选择范围或明确随机范围，不得打开第一条知识。

### IA-AC-002：体系建立焦点

给定用户在模块 L0 地形，当逐层选择到知识单元时，系统建立唯一焦点并先提供路径和关系定向。

### IA-AC-003：跨活动保持焦点

给定当前焦点，从关系切到阅读再切到回忆时，知识 ID、导航路径和来源版本保持一致。

### IA-AC-004：模块能力降级

给定某模块没有关系或回忆数据，其首页和工作台不出现空壳入口，完整阅读和体系定位仍然可用。

### IA-AC-005：跨模块一致而不同形

政治、常识和笔记使用相同焦点状态与活动语义，但分别展示自己的导航节点、目标文案和支持能力。

## 12. 放弃的方案

| 方案 | 放弃理由 |
|---|---|
| 首页平铺知识列表 | 信息量随内容增长失控，不能表达领域结构 |
| 目录、地图、搜索、卡片四个并列入口 | 把观察镜头误做成功能大厅，用户必须自己组织链路 |
| 所有模块强制同样四张卡 | 忽略模块数据差异，最终产生大量空状态 |
| 阅读作为所有入口的默认落点 | 用户在理解位置和关系前先面对长正文 |
| 关系作为无焦点入口 | 没有中心节点时关系图缺乏认知锚点 |
| 用页面返回栈代表探索轨迹 | 页面历史无法表达用户沿哪些知识关系探索 |
