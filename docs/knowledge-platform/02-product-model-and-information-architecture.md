## 1. 本文要解决什么

本文冻结通用知识平台的产品骨架：用户处于什么认知状态、首页负责什么、怎样建立焦点、四种活动和四类目标怎样组合，以及政治、常识、笔记怎样使用同一模型而不被强制做成同一界面。

本文不决定具体地图布局、内容块视觉和动画参数。

## 2. 推荐产品模型

平台以“知识焦点”而不是“页面”为中心。用户有两个顶层状态：

```text
无焦点
├─ 观察知识领域
├─ 选择学习目标
├─ 搜索或提出问题
└─ 恢复最近焦点

已聚焦
├─ 体系定位
├─ 关系探索
├─ 完整阅读
└─ 主动回忆
```

页面只是这些状态的移动端容器，不定义知识本体。

## 3. 顶层意图与共享知识表面

平台不把全部能力串成一条固定漏斗。首页先区分两类意图：

```text
自由探索：KnowledgeSpace全景 → 原地展开分支 → 独立KnowledgeCard / 卡内关系 / 同卡回忆
目标任务：系统推荐 → 一键开始 → GoalGuide持续引导 → 目标特有完成反馈
```

二者建立焦点后共享同一逻辑连续性、焦点、活动、轨迹、路线、显示偏好和viewport状态。`KnowledgeSpace`与`KnowledgeCard`使用微信原生页面分工；同一Space/Card渲染器可被自由探索与路线复用。体系、关系、阅读、回忆保留为内部活动语义，但不默认形成四个并列标签。

### 关系怎样进入知识表面

完整知识卡可以按需提供受控关系上下文：

- 需要先知道什么。
- 它属于哪个知识区域。
- 最容易与什么混淆。
- 为什么值得进入完整阅读。

它不要求用户先经过独立关系页。完整内容始终可直接展开；阅读前后都可以按需进入一层关系探索，沿相邻知识切换焦点并记录探索轨迹。

因此关系分为两个深度：

- `orientation`：阅读前的一层定向。
- `exploration`：阅读后或用户主动触发的关系探索。

## 4. 首页信息架构

### 4.1 首页必须包含

1. 搜索或问题入口，以用户熟悉的输入框形态立即可见。
2. 单一状态主任务：活动路线、最近焦点或首次快速了解三选一。
3. 用户目标入口。
4. 一个低权重“浏览全部知识”入口，进入独立KnowledgeSpace的全览和等价目录。
5. 内容状态说明，仅在模块存在校对或版本风险时显示。

### 4.2 首页不包含

- 全量知识单元平铺。
- 无焦点速记卡。
- 独立的目录、地图、搜索、卡片功能大厅。
- 需要先理解具体知识点才能使用的关系工具。

### 4.3 推荐首页结构

```text
模块标题与一句话说明

搜索或提问

当前推荐
└─ 继续最近路线 / 继续最近焦点 / 首次快速了解（三选一）

选择目标
├─ 快速了解
├─ 系统学习
├─ 易混突破
└─ 考前速记或模块等价目标

浏览全部知识
└─ 进入KnowledgeSpace全景 / 等价目录
```

搜索用于用户已经知道自己要找什么；单一状态主任务用于恢复会话或给出默认建议起点；其他目标用于表达想达到什么结果；“浏览全部知识”用于进入结构认知。首页不声称“最适合你”，也不把这些入口做成同权功能卡。

四类目标不要求每个模块使用完全相同的展示文案，但必须映射到通用路线类型。首次进入默认推荐快速了解而不是强迫用户先理解地形操作；快速了解由系统直接提供经审核、可回源的连续导读，L0/L1结构只用于持续说明“当前内容位于整体哪里”，不能成为必须逐站点击的主体。

## 5. 四种认知活动

### 体系

用于发现、定位、返回和选择焦点。可以表现为地形、目录、主题列表或其他模块投影，但必须由正式导航数据生成。

### 关系

围绕当前焦点解释前置、后续、易混和相关。没有已确认关系时自然降级为路径、同级或来源上下文，不能造假。

### 阅读

承载完整事实、结构化理解、易混边界和来源证据。它是其他形态的事实母体。

### 回忆

在明确焦点或范围内要求用户主动恢复内容。无范围时由系统先恢复或生成可解释的推荐范围；用户可以次级调整或选择明确随机，不得默认第一篇知识。

## 6. 四类用户目标

### 快速了解

适合从未系统学习、只有零星印象或时间有限的用户。主体是一份有限、内容先行的连续导读：用经审核的解释、正式连接点和代表例形成第一张认知图，同时以轻量L0/L1结构持续定位；不要求遍历目录、逐个打开知识卡，也不自动把用户送入长正文。完整知识卡和KnowledgeSpace都是可选深入出口。

### 系统学习

系统先按profile默认、当前有效上下文、正式顺序和前置关系推荐连续路线。开始前展示范围、数量、依据和首尾知识；用户可次级调整，但不从空白选择器开始。

### 易混突破

只在模块存在已确认易混数据时启用。系统先推荐一组正式ContrastPair并解释依据，再引导先判断、核对边界、回看来源和按能力再辨；换组或限定范围是次级控制。

### 考前速记

政治和常识可以使用该名称；笔记模块可配置为“快速回顾”。系统优先恢复有效卡组，否则按profile生成明确范围的冻结卡组；不能默认第一篇知识。

## 7. 跨模块落法

| 模块 | L0 地形 | 导航节点 | 默认目标侧重 | 无关系时降级 |
|---|---|---|---|---|
| 政治 | 两篇理论区域 | 部分、篇、章、节、知识点 | 系统学习、易混突破、考前速记 | 显示正式目录路径和同级知识 |
| 常识 | 学科/主题区域 | 层级、学科、分类、知识点 | 快速了解、系统学习、易混突破 | 显示分类路径、规则和对照 |
| 笔记 | 科目知识地图 | 科目、分类、知识点 | 快速了解、系统学习、快速回顾 | 显示科目路径和相关题型/引用 |

模块配置负责名称、导航节点类型、可用目标和增强镜头；通用平台负责状态、返回、降级和内容一致性。

## 8. 入口与焦点建立规则

| 入口 | 无焦点时行为 | 建立焦点后默认活动 |
|---|---|---|
| 知识地形 | 在同一空间选择区域、分支或知识 | 完整知识卡 |
| 目录投影 | 按正式层级精确定位知识 | 完整知识卡 |
| 搜索结果 | 展示标题、命中类型和命中摘要 | 按可解释命中直接进入正式位置 |
| 问题入口 | 定位直接知识、相关和易混候选 | 按命中类型直接进入正文块、关系或回忆 |
| 快速了解 | 系统生成有来源的连续导读；不先选篇章或范围 | QuickGuide连续内容；结构定位持续在场，完整卡/知识空间为可选深入 |
| 系统学习 | 系统推荐正式范围；调整为次级 | 当前知识周期 |
| 易混突破 | 系统推荐正式对照；换组/限定区域为次级 | 左右稳定在场的对照表面 |
| 考前速记 | 系统恢复或推荐冻结卡组；调整/随机为次级 | 单张回忆卡 |
| 深链 | 直接恢复知识单元及指定活动 | 深链指定活动 |

## 9. 返回与循环

默认“返回”不是简单上一篇页面，而是返回认知来源：

- 从完整卡进入关系再返回：保留内容锚点和卡片展开状态。
- 从关系切换相邻知识：加入探索轨迹。
- 从相邻知识返回：回到上一焦点和关系视窗。
- 从焦点返回地形：恢复原导航节点和视窗。
- 从回忆回看原文：定位对应内容块。
- 完成回忆后：可返回路线、体系或继续下一项。

具体状态字段由03文档定义。

## 10. 异常和降级

### 没有关系

隐藏深度关系入口；知识卡仍显示目录位置、同级或来源上下文，完整内容保持直接可达。

### 没有回忆项

隐藏回忆入口或显示“返回完整内容”；不能临时从正文随机挖空。

### 没有最近焦点

首页隐藏继续探索，不使用第一条知识伪造历史。

### 没有地图能力

以目录或主题列表提供完全可达的等价导航。

### 数据处于校对状态

可以在隔离试验环境展示明确状态，但不能因 UI 完成而获得发布资格。

## 11. 验收场景

### IA-AC-001：无焦点回忆

给定用户从未进入某模块，当点击考前速记时，系统必须先展示一个有依据的推荐范围和开始动作；用户可次级调整或明确随机，不得打开第一条知识。

### IA-AC-002：体系建立焦点

给定用户在知识空间或目录选择到知识单元时，系统建立唯一焦点并直接打开同一完整知识卡；关系只作为卡内上下文或按需深入，不增加预览过门。

### IA-AC-003：跨活动保持焦点

给定当前焦点，从关系切到阅读再切到回忆时，知识 ID、导航路径和来源版本保持一致。

### IA-AC-004：模块能力降级

给定某模块没有关系或回忆数据，其首页和工作台不出现空壳入口，完整阅读和体系定位仍然可用。

### IA-AC-005：跨模块一致而不同形

政治、常识和笔记使用相同焦点状态与活动语义，但分别展示自己的导航节点、目标文案和支持能力。

## 12. 放弃的方案

| 方案 | 放弃理由 |
|---|---|
| 首页平铺知识列表 | 信息量随内容增长失控，不能表达领域结构 |
| 目录、地图、搜索、卡片四个并列入口 | 把观察镜头误做成功能大厅，用户必须自己组织链路 |
| 所有模块强制同样四张卡 | 忽略模块数据差异，最终产生大量空状态 |
| 阅读作为所有入口的默认落点 | 用户在理解位置和关系前先面对长正文 |
| 关系作为无焦点入口 | 没有中心节点时关系图缺乏认知锚点 |
| 用页面返回栈代表探索轨迹 | 页面历史无法表达用户沿哪些知识关系探索 |
