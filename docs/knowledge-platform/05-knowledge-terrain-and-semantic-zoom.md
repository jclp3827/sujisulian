## 1. 本文要解决什么

本文冻结正式导航数据怎样成为移动端“知识地形”，缩放时知识粒度怎样变化，目录和地形怎样可逆，以及在节点很多、标题很长、缺少关系或不能使用手势时怎样仍然完整可达。

本文定义的是信息、投影和交互语义，不决定最终颜色、曲线、阴影和动画时长。08可以优化视觉，但不能改变层级含义、节点预算、稳定位置和等价访问规则。

## 2. 知识地形的产品定义

知识地形不是把目录换成散落卡片，也不是展示全部关系的自由力图。它是同一份正式导航树和已确认关系在不同认知尺度下的受控投影：

```text
正式导航树：回答“知识在哪里、由什么构成”
关系镜头：回答“当前范围内哪些知识怎样相连”
当前焦点：回答“我正在理解什么”
空间位置：帮助用户形成可恢复的领域方位感
```

地形必须同时具备：

1. 有稳定的区域、主干、分支和焦点位置，而非每次进入重新洗牌。
2. 缩放改变展示对象和信息密度，而不只是放大字体。
3. 默认先表达正式体系，关系作为镜头叠加，不能改写目录。
4. 地形、目录和列表中的每一个正式对象可相互定位。
5. 不使用地图、双指手势或动画时仍能完成全部导航任务。

## 3. L0–L4 信息契约

> S5.5B修订边界：本节的L0–L4继续用于定义信息粒度，不再等同于页面层级或用户必须依次通过的导航步骤。L4表示同一知识卡的完整展开态，不再预设为与知识空间割裂的第五个过门页。以下层级结论只规定“此时应表达什么”，不预先规定“用什么整体构图和分支形态表达”。

### 3.1 层级结论

真正的地形语义尺度为 L0–L3；L4是同一KnowledgeUnit的完整内容态，由具体知识入口直接进入，不继续在地图画布上把正文块画成知识节点。

```text
L0 领域：这个模块由哪些主要区域构成
  ↓
L1 分支：这个区域有哪些正式主分支
  ↓
L2 知识群：这个分支包含哪些知识群或知识单元
  ↓
L3 焦点邻域：当前知识在哪里，与哪些一层对象直接有关
  ↓ 直接打开同一完整知识卡
L4 完整知识卡：当前知识完整讲了什么
```

这解决两个冲突：既保留“体系—关系—阅读”的空间连续性，又避免在移动端将文章、关系和全库节点塞入同一无限 Canvas。

### 3.2 每层信息预算

| 层级 | 主对象 | 必须显示 | 可选显示 | 同屏节点预算 |
|---|---|---|---|---|
| L0 | 模块主要区域 | 区域名、范围/数量、稳定位置 | 显式核心锚点、最近焦点 | 最多8个区域 |
| L1 | 当前区域的主分支 | 分支名、父区域、子范围、正式顺序 | 分支摘要、跨分支关系提示 | 最多12个分支 |
| L2 | 知识群或知识单元 | 标题、所属分支、是否可建立焦点 | 一句话理解、局部状态 | 最多16个节点/聚合 |
| L3 | 当前焦点及一层邻域 | 焦点、完整路径、关系类型入口 | 最多6个关系邻居、同级位置 | 中心1个 + 邻域不超过10个 |
| L4 | 完整知识卡 | 同一知识身份、有来源的小卡与连续正文 | 关系上下文、回忆投影、原文定位 | 不属于地图节点预算 |

节点预算只限制一次呈现，不截断数据。超出预算的对象必须进入确定性聚合、分段或等价目录，且始终提供“查看全部”。

### 3.3 层级不是源目录深度的机械复制

不同模块的导航深度不同。投影器把正式导航映射到认知尺度，而不是要求所有模块恰好四级：

- 导航浅：允许 L1直接进入 L2知识单元。
- 导航深：在 L1/L2中逐层进入，不把多级标题同时摊开。
- 一个导航节点绑定知识单元时，可以从该节点直接建立焦点。
- 层级映射由 `ModuleProfile.navigation` 和导航类型配置决定，页面不写死篇、章、节。

## 4. 基础地形与关系镜头分工

### 4.1 基础地形只表达正式体系

基础投影中的主干、区域和分支来自 `NavigationNode`：

- 主干：模块根到当前范围的正式父子结构。
- 分支：当前范围的正式子节点。
- 顺序：正式 `order`。
- 位置：由父节点、顺序和稳定 ID 派生。

关系数量、搜索热度、收藏或页面运营状态不能改变正式父子和顺序。

### 4.2 关系通过镜头叠加

| 空间语义 | 数据依据 | 地形表现语义 | 列表等价表达 |
|---|---|---|---|
| 路径 | `prerequisite` 及派生后续 | 有方向的学习路径 | 前置/后续分组和理由 |
| 桥梁 | 跨分支 `related` | 连接不同区域的桥接提示 | 相关知识及所属路径 |
| 警戒 | `contrast`、条件和例外 | 易混/边界区域提示 | 易混对照和理由 |
| 锚点 | 显式核心标记或模块策展 | 区域中的核心知识 | 核心知识列表及依据 |
| 岔路 | 同级并列或路线选择 | 多个可继续方向 | 同级/下一步列表 |

L0–L2默认不铺开全部关系边，只显示有关系的轻量提示或聚合数量。用户切换镜头或进入 L3后才展示具体关系，避免目录和关系线互相覆盖。

### 4.3 不从图结构猜核心知识

核心锚点必须来自显式策展字段、正式路线或模块配置。关系度数高、搜索次数多或处于目录前部都不能自动等同“核心”。没有显式依据时只显示普通节点。

review 状态和风险标记可以显示为文字徽标，但不得通过放大、居中或改变地形位置暗示知识更重要。

## 5. 移动端空间骨架

> 原baseline以“主干—分支—局部邻域”作为一种受控示例。S5.5B现已进一步确认稳定分区底图、紧凑区域栏和去重后的原地展开；本节仍不得自行决定全局缩略方式、320px预算和连接叠加，最终细节由S55B-P03至P05确认。

### 5.1 推荐采用“主干—分支—局部邻域”

移动端不展示一张需要横向拖很远的整库思维导图，而是在稳定主干上进入当前范围：

```text
L0：区域地形，建立全局方位
 ↓ 选择区域
L1：沿主干查看正式分支
 ↓ 选择分支
L2：在局部知识群中选择焦点
 ↓ 建立焦点
L3：中心焦点 + 受控一层邻域
```

每一层都是全库的局部视窗；上级路径始终可见或一键展开。用户不需要拖动一张超大画布寻找离屏节点。

### 5.2 空间连续性的最低要求

- 同一节点在同一父范围内拥有稳定 `positionKey`。
- 进入下一级时，所选节点成为下一视窗的来源锚点。
- 退出时恢复上一级范围、焦点节点和语义视窗。
- 切换目录/地形时保持范围、焦点、展开路径和层级。
- 视觉动画关闭后，面包屑、选中态和返回文案表达相同方向。

动画细节由08定义，状态来源必须使用03的活动快照。

## 6. 确定性聚合与密度控制

### 6.1 聚合优先级

当正式子节点超过当前层预算时，按以下顺序处理：

1. 优先显示正式中间导航节点，不跨层铺开后代。
2. 使用模块 profile 显式声明的总览分组。
3. 若源结构仍是大平面，按正式顺序形成确定性的范围聚合。
4. 始终提供同范围完整目录/列表，不隐藏剩余知识。

禁止按屏幕空间临时聚成每次不同的节点团，也禁止为了美观发明新的正式分类。

### 6.2 TerrainAggregate

范围聚合只是视图对象，不是知识：

```text
TerrainAggregate
├─ id: agg:<scopeNodeId>:<firstOrder>:<lastOrder>
├─ scopeNodeId
├─ childIds[]
├─ title: 可解释范围标签
├─ count
└─ positionKey
```

- 聚合 ID 可稳定恢复视窗，但不能成为关系、回忆、搜索或纠错的正式目标。
- 打开聚合只改变投影范围，不建立知识焦点。
- 正式导航变化后聚合可以失效，由03的安全恢复规则回到父范围。

### 6.3 长标题和窄屏

- 地形节点优先显示完整可辨识标题，允许两行；不能只靠省略号区分相似知识。
- 超过节点容器承载能力时显示稳定短标签，并在节点预览中展示完整标题；短标签必须来自显式字段或可逆规则。
- 320px窄屏采用纵向局部地形或列表，不产生页面级横向溢出。
- 任何隐藏标题的图形都必须有文字列表等价项。

## 7. 语义缩放交互

### 7.1 点击和明确控件是主操作

用户可以只用单指点击、展开/收起、路径和返回整体完成全部导航。L0–L3由投影器表达语义尺度，不要求界面提供四个层级按钮；双指缩放、拖动和过渡动画只作为增强。

### 7.2 双指缩放规则

- 一次手势释放后最多跨一个语义层级。
- 放大聚合或导航节点：在同一空间展开其分支；是否采用放大手势由S55B-P01至P05决定。
- 放大或点击知识单元：保存空间viewport并直接打开完整知识卡，不进入预览或独立关系页。
- 缩小：回到父范围并保持当前焦点高亮。
- 手势阈值未达到时只恢复当前层，不留下半层状态。
- 缩放过程中不改变正式焦点，只有语义层切换完成后提交状态事件。

### 7.3 拖动边界

拖动只用于当前局部视窗内查看，不能成为访问离屏数据的唯一方式。到达视窗边界时提供明确下一范围或“查看全部”，不允许无边界漂移。

## 8. 目录与地形可逆投影

两种投影共享：

```text
ProjectionState
├─ moduleId
├─ scopeNodeId
├─ semanticLevel
├─ focusNodeId
├─ focusedPointId
├─ expandedPathIds[]
├─ lens
├─ selectedAggregateId?
└─ scrollAnchorId / viewportToken
```

### 8.1 地形切目录

- 目录展开到 `scopeNodeId` 的正式路径。
- 当前焦点或聚合中的来源节点保持选中。
- 地形 `viewportToken` 留在 system 快照中，不写入目录数据。

### 8.2 目录切地形

- 使用相同范围和焦点重建当前语义层。
- 目录展开的非当前兄弟节点不强制全部铺入地形。
- 节点超预算时按相同确定性聚合规则处理。

### 8.3 无地图能力

模块或设备降级为目录/列表时，`scopeNodeId`、焦点、镜头含义和返回目标仍相同。地形不是独立内容源，因此不会产生“地图里有、目录里没有”的知识。

## 9. 镜头能力与启用条件

| 镜头 | 启用条件 | 默认层级 | 无数据时 |
|---|---|---|---|
| `directory` | 所有模块必备 | L0–L3 | 不可关闭 |
| `prerequisite` | profile声明 + 有有效前置关系 | L2/L3 | 隐藏 |
| `contrast` | profile声明 + 有有效易混关系 | L2/L3 | 隐藏 |
| `related` | profile声明 + 有有效相关关系 | L3 | 隐藏 |
| `route` | 当前存在有效学习路线 | L1–L3 | 返回目录镜头 |
| `review` | 存在用户学习状态且07启用 | L1–L3 | 延期，不显示空镜头 |
| `timeline` | 显式时间实体和顺序达到模块门禁 | L1–L3 | 第一轮延期 |
| `entity` | 显式人物/文件/会议实体达到门禁 | L1–L3 | 第一轮延期 |

镜头只改变可见连接、强调和说明，不改变正式导航、焦点身份和内容。未知或失效镜头按03规范化为模块默认镜头。

## 10. 搜索、问题和路线定位

### 10.1 搜索结果定位

“在体系中查看”执行：

1. 用目标知识反向重建完整导航路径。
2. 进入能够包含该知识的最低可读范围，通常为 L2。
3. 高亮目标节点和命中内容，不立即替用户建立焦点。
4. 用户确认具体KnowledgeUnit后直接打开同一完整知识卡，关系只作为卡内上下文或可选镜头。
5. 返回时恢复搜索词、结果序号和列表位置。

如果目标知识已失效，停留搜索结果并说明内容版本变化，不按标题猜替代项。

### 10.2 路线定位

路线镜头只高亮路线范围、当前位置、已定义顺序和下一步，不改变地形位置。路线中的每一步仍可切回目录镜头查看正式体系。

## 11. TerrainViewModel

地形页面不得直接遍历模块源文件。推荐由纯投影器生成：

```text
TerrainViewModel
├─ moduleId
├─ projection
├─ semanticLevel
├─ scope
├─ breadcrumb[]
├─ nodes[]
│  ├─ id / sourceId
│  ├─ role: region | branch | aggregate | point | focus | context
│  ├─ title / shortTitle
│  ├─ count
│  ├─ positionKey
│  └─ state labels
├─ links[]
│  ├─ kind: hierarchy | prerequisite | contrast | related
│  ├─ sourceId / targetId
│  └─ label / direction
├─ overflow
├─ availableLenses[]
└─ listEquivalent
```

输入只能是 `KnowledgePackage + ModuleProfile + KnowledgeContext + viewport class`。相同输入必须生成相同节点、连接、顺序和 `positionKey`；具体像素由响应式布局层计算。

页面不能手写节点坐标、复制标题或在 UI 中确认关系。profile可以提供区域顺序、短标签和策展锚点，但不能存绝对像素或依赖 `.canvas`。

## 12. 三模块代表性线框

### 12.1 政治理论

```text
L0  政治理论
    ├─ 习近平新时代中国特色社会主义思想
    └─ 马克思主义基本原理

L1  当前篇主干
    ├─ 第一章 总论
    ├─ 后续正式章节……
    └─ 查看目录投影

L2  当前章
    ├─ 知识点A
    ├─ 知识点B
    └─ 知识点C

L3  当前知识焦点
    ├─ 前置
    ├─ 易混
    └─ 相关
```

政治验证两大区域、42个正式导航节点、37个知识单元和39条关系；风险状态只显示徽标，不改变地形重要性。

### 12.2 常识

```text
L0  学科/主题区域（超过8个时分段，不平铺知识点）
L1  当前学科的正式分类
L2  分类内规则、概念或知识单元
L3  当前知识 + 路径/同级；有正式关系才显示关系镜头
```

常识用于验证大规模聚合、法律规则/例外、长标题和缺少正式关系时的自然降级。

### 12.3 笔记

```text
L0  科目区域
L1  科目下分类
L2  知识点
L3  当前知识 + 分类路径 + 可选题型连接
```

题型连接是模块增强，不自动变成知识关系；没有关系时 L3仍能通过路径、同级和阅读入口成立。

## 13. 验收场景

### MAP-AC-001：语义而非几何缩放

给定政治 L0，用户逐层进入 L1、L2和 L3时，主对象分别从篇区域变为章节、知识点和焦点邻域；不能只放大同一批节点。

### MAP-AC-002：完整可达

给定政治37篇知识，用户不用双指和拖动，只用点击、展开/收起和目录即可到达每一篇，并可返回原空间范围。

### MAP-AC-003：大规模聚合

给定常识某范围超过16个子项，地形按正式中间节点或确定性范围聚合，不形成节点团；“查看全部”显示完整且顺序一致的目录。

### MAP-AC-004：位置稳定

相同 package、profile、context 和屏幕类别连续生成两次地形，节点顺序、连接和 `positionKey` 一致；新增后序知识不随机移动已有前序节点。

### MAP-AC-005：目录/地形可逆

给定用户在 L2选中某节点，切换目录再返回地形后，范围、层级、焦点、展开路径和镜头保持一致。

### MAP-AC-006：搜索定位回返

从搜索结果定位知识时，地形展示其完整路径和节点；返回搜索后恢复原查询、结果序号和列表位置。

### MAP-AC-007：无关系模块

给定笔记知识没有正式关系，L0–L3体系仍完整；关系镜头隐藏，地形不从标签或题型伪造关系边。

### MAP-AC-008：未知镜头降级

深链请求模块不支持的镜头时，保留范围和焦点并回到目录镜头，不出现空白地图。

### MAP-AC-009：无地图等价

关闭地图能力或启用无地图模式后，同一范围、焦点、关系理由和下一步都可以在目录/列表中访问。

### MAP-AC-010：知识空间进入内容

从知识空间打开具体知识时，KnowledgeContext接收相同焦点、路径和来源，并通过原生页面栈进入独立KnowledgeCard；正文不在地图节点或KnowledgeSpace页展开，原生返回后恢复原分支、节点和语义viewport。

## 14. 放弃的方案

| 方案 | 放弃理由 |
|---|---|
| 一张包含全库的无限 Canvas | 移动端方向感差、性能不可控，也无法提供完整等价导航 |
| 自由力图每次实时排布 | 节点位置漂移，用户无法建立可恢复的空间记忆 |
| 把整个目录横向展开为思维导图 | 长标题和深层级导致横向拖动，竞品的可用但笨拙问题会被复制 |
| 缩放只改变节点尺寸 | 没有改变认知粒度，不是真正语义缩放 |
| L4继续在地图展示正文块 | 将体系、关系和阅读混成复杂画布，破坏完整阅读 |
| 关系度数自动决定核心节点 | 将数据连接数量误当知识重要性 |
| 为适应节点预算截断剩余知识 | 用户无法知道和访问完整体系 |
| 以颜色或图形作为唯一含义 | 无法满足可访问性和列表等价要求 |
| 依赖双指缩放才能进入下层 | 手势可发现性低，也不适合所有设备和用户 |
| 将聚合节点写回正式知识树 | 视图优化污染内容事实和目录结构 |
