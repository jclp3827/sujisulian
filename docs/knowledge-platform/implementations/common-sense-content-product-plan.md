## 1. 产品目标与范围

把用于验证学习流程的候选材料，建设成可以持续编写、核验、维护和编排的学习内容。四个模块分别制定标准、分批验收，共用知识目标与题目资源。

用户应能通过一问一答认识知识，通过口诀建立记忆线索，通过易混辨析识别差异，通过考前急救完成有限范围的回看和检测。每一种学习方式都清楚说明实际覆盖内容，能回到对应正文。

本方案包含：知识目标、题库、口诀学习包、易混对照、急救专题、内容准入、缺口处理、进度兼容，以及基于内容关系的站内推荐。首页结构与 UI-02 确定的蓝白样式、四方格、底部主按钮、简化设置、直接展示导读保持。

“全部常识”继续提供完整正文查阅；每日常识是内容分发入口，共用正式学习资源。正文补正另列来源问题处理，不随出题静默改写。站外通知、商业化、付费、公开发布不在本轮交付范围。

## 2. 已核对基线与问题

本方案登记时的候选内容为：45 道自编学习题、13 条口诀、15 个主题组、4 组易混对照。正文有 170 个小节、581 个页签；候选内容涉及 17 个小节的部分知识、26 个页签。候选均未被批准为正式学习内容。

已有能力：正文单元定位、内容版本与准入、口诀逐句释义和配套题、易混初判/对照/复辨、入口显式编排、来源变化后的失效处理。继续复用这些能力。

主要缺口：

1. 学习目标作为题目上的 `objective` 文本存在，没有独立稳定身份；现有编排中的“目标清单”实质使用题目 ID。
2. 题目不足以区分基础记忆、情境理解和条件边界；多数主题固定三题，不能代表正式覆盖标准。
3. 口诀已关联题目，但缺少统一的适用性判断、记法选择、教学质量评审和目标级覆盖台账。
4. 一问一答、每日和考前精选大量使用同一候选集合，考前专题尚缺独立的入选依据与编排。
5. 全库原子知识目标尚未盘点，不能用题目数或小节涉及数计算“全部考点覆盖率”。

## 3. 产品结构与内容唯一来源

```text
正文单元 / 经核验的补充依据
                  ↓
             独立知识目标
       ┌──────────┼──────────┐
     配套题目    口诀逐句映射    易混比较维度
       └──────────┼──────────┘
         四种学习方式的显式编排
                  ↓
      答题与阅读事实 → 站内回顾安排
```

同一个目标可以有多道题、被多个模块选用。各模块保存选用关系及教学顺序，不复制出四套互不相通的事实库。口诀、题目和对照的事实都要回溯依据，不能相互引用来证明自身正确。

### 3.1 独立知识目标

每个目标描述一个可以明确检验的判断能力，如“能根据振动频率判断音调关系”。既不以整章作一个目标，也不把仅有措辞差异的同一事实重复建目标。

必填内容：稳定 ID、所属领域/主题、目标描述、正确结论、适用条件、必要例外或明确的无例外说明、正文单元引用、补充来源、版本、审核状态、适用学习方式。另记录编写优先级及理由；没有真题统计时只标编辑优先级。

### 3.2 题目

每题记录稳定 ID、版本、题型、题干、选项、答案、解析、干扰项理由、主要考查目标、辅助目标、检测用途、来源、编写类型、模块选用关系和审核状态。

检测用途分为基础识别、情境应用、条件边界。每个试点目标至少有一道直接检测题；适合变式的目标至少补一题不同问法/情境，未配变式时记录原因。不能靠替换人名或调换选项充当有效变式。

自编题明确标记“自编学习题”。真题、真题改编和自编题分开登记；真题需核实考试、年份、卷别、题号、可追溯原题及答案依据，并明确可使用范围。来源或使用条件不清的材料不进入正式题库。

### 3.3 资源关系与记录

- 题目与目标：允许多对多，但明确主要与辅助目标。综合题答错不能直接把所有关联目标都判为未掌握。
- 口诀句子与目标：允许多对多，每个关系标明覆盖内容、条件，以及该句单独是否足以表达完整目标。
- 口诀与题目：通过目标建立关系，再显式选择本条自测所用题目；不自动收录所有相关题。
- 易混行与目标：登记比较对象、条件、差异和目标；检测题覆盖本次声明的差异。
- 急救专题与资源：引用目标、回看材料和题目，保存顺序、范围和入选理由。
- 阅读记录、答题记录、目标检测情况分开。阅读完成、揭晓答案或答对一次，都不能自动宣称掌握。

## 4. 四个模块的内容产品标准

| 模块 | 建设单位 | 学习内容与流程 | 完整性要求 |
|---|---|---|---|
| 一问一答 | 目标及配套题 | 判断 → 答案/解释 → 可回原文或进入针对性回看 | 单题目标明确，答案唯一或规则明确，干扰项有依据，题组不重复凑数 |
| 常识口诀 | 一条完整口诀学习包 | 看口诀与逐句释义 → 自测 → 定位相关句/条件 → 返回原阅读位置 | 口诀、目标、条件、来源和自测相互对应，声明覆盖的目标都有检测 |
| 易混辨析 | 一组概念比较 | 初判 → 相同维度对照 → 不同问法复辨 | 对照有真实混淆理由和共同维度；初判/复辨职责明确，不能只重复原题 |
| 考前急救 | 一个短复习专题 | 明确范围 → 精简回看/检测 → 补缺 → 完成 | 有选入与排除理由、有限任务量；精选与个人待回顾分开 |

数量遵循现有设置：问答/急救 5/10/15 道，口诀每组 1/3/5 条，每日最多 5 道。易混试点保持完整三题流程，由内容标准决定每题职责。今后需要更长易混包时另登记批次，不自动突破当前页面预算。

### 4.1 一问一答

以独立目标建设基础题和适用的变式题，优先消除无效干扰项、题干歧义、答案提示和“看口诀字面就能选”的题。解析至少说明正确原因及核心易错点；必要时逐项解释选项。

同组不重复出同一道题。跨组复习允许重复，但复述原题与新变式的结果分开记录。对暂时没有变式的目标，允许使用已审核基础题，不声称已经检验迁移应用。

### 4.2 常识口诀：形成方法

生产顺序固定为：确定目标集合 → 判断口诀适用性 → 选择记法 → 编写候选 → 逐句还原知识 → 核验条件与例外 → 配套题 → 教学评审和试用。

记法包括对应、顺序串联、分类归纳、对照记忆；不要求押韵。规则长、例外多、需因果推导或压缩后容易失真的目标，优先采用简明解释或对照表，并登记“不适合口诀”的理由。

每条口诀学习包必须包含：标题与记忆目的、口诀全文、记忆方式、带稳定 ID 的句子、逐句释义、目标清单、条件、例外、排除范围、来源、配套检测、版本与状态。

口诀的质量判定：

1. 准确：逐句能对应有依据的知识，不省略决定对错的条件。
2. 清楚：简称、代词和谐音有解释，无多种相互冲突的还原方式。
3. 有记忆价值：相比原文降低记忆负担，补充解释不过度复杂。
4. 范围诚实：按具体目标声明覆盖，不凭章节标题宣称整章掌握。
5. 能检测：有针对记忆、理解或边界的题，而非只让用户补口诀原句。

短小组合优先，具体长度由主题和手机阅读效果决定，不以固定字数作为合格标准。不合适的口诀可撤回或改写；不为覆盖率强行配口诀。

### 4.3 常识口诀：映射与自测规则

映射表至少包含：口诀 ID/版本、句子 ID、目标 ID/版本、覆盖类型、条件引用、题目 ID/版本、检测用途、答错回看位置。

以现有“声音三特性”作为关系结构示例，下面不是新内容审核结论：

| 记忆点 | 检测安排 | 回看位置 |
|---|---|---|
| 音调的对应关系 | 基础对应 + 适用的情境变式 | 对应句及解释 |
| 响度的对应关系 | 基础题 + 条件辨析 | 对应句、适用条件 |
| 音色的辨别作用 | 场景识别 | 对应句及示例 |
| 三者区别 | 综合辨析 | 三句对照及条件 |

自测只选择口诀实际覆盖的目标。多目标题若要求口诀外的必要知识，不进入本条自测；可进入普通问答并单独说明范围。配套题缺失的口诀保持候选，补齐后才正式开放。

一轮短测不能检测全部目标时，记录已测与未测目标，后续轮换补齐；完成提示表达本轮实际检测量，不显示整条已掌握。现有自测短组上限先保持最多 5 题，超过预算的口诀在编写时优先拆为独立小条；需跨轮覆盖的方案在 C2 专门验证。

答错/主动揭晓时，基础题回看对应句，情境题回看解释，边界题回看条件。多目标题无法定位原因时回看相关范围，不伪造精确诊断。回看不强制中断答题，可在解释中直接进入，返回保留题位。

### 4.4 易混辨析

每组说明为什么值得放在一起比较：含义相近、同名异义、条件不同、相邻范围或已有错误表现。编辑推断和真实答题数据依据分别记录。

先规定比较维度，再编写初判与复辨。复辨至少改变问法或场景，并检验声明的关键差异。不得用不同条件下的结论作无条件对照。某一关键目标、对照依据或必需配套题失效时，整组退出准入。

### 4.5 考前急救

精选专题围绕明确任务组织，如“某类概念基础回看”，列目标、入选理由、材料、题目与完成范围。优先复用审核过的资源，缺少合适检测时补题。未经试用不承诺固定完成分钟数。

入选理由可为基础性、编辑确定的典型混淆、个人待回顾。只有记录考试范围、年份区间、样本及统计方法后才能使用高频标签；未核实的考情宣传不能成为排序依据。

精选与个人待回顾继续独立。个人集合为空显示真实空态，不自动替换成精选。试点精选仅说明两个主题的有限范围，不能包装成全部考前必备。

## 5. 内容生产、来源核验与缺失项

每批按“范围台账 → 目标提取 → 编写 → 事实核验 → 教学审核 → 关系检查 → 页面试读 → 入口编排”推进。编写者可使用工具起草、比对和查漏；内容批准由用户指定的审核人作出，不由自动检查替代。

来源使用规则：正文是当前主要依据；遇到歧义、时效问题和缺项时补充官方文件、权威教材或专业机构材料，保存标题、链接/定位、获取日期、适用日期、支持的具体结论及改编情况。网络搜索服务于具体核验问题，不批量搬运题库或口诀。

| 缺失/冲突 | 处理方式 | 可继续的工作 |
|---|---|---|
| 正文没有拆出目标 | 列入待盘点，按选定小主题提取 | 其他已明确目标的编写 |
| 来源含糊或彼此冲突 | 暂停对应目标派生；核验后提出正文修订单 | 不受影响的目标 |
| 法律/时效材料无法确认适用版本 | 暂不作为正式依据，记录待核日期与问题 | 稳定内容试点 |
| 目标不适合口诀 | 记录理由，选择解释或对照 | 问答和适用的易混材料 |
| 有口诀、无配套题 | 保持候选并补齐检测 | 开发试读，不计正式可用 |
| 有题目、没有目标或有效来源 | 补映射与核验，完成前不正式编入入口 | 其他合格题目 |
| 数量不足 | 按实际数量出组，不跨范围、不重复凑数 | 正文查阅及已有合格内容 |
| 无真题/频次证据 | 保持自编/编辑精选标记 | 基础学习资源建设 |
| 外部材料使用条件不清 | 不直接纳入；寻找清晰来源或依据事实自编 | 原创题和自主表达的记法 |
| 内容被修订或撤回 | 重新核对受影响目标、口诀、对照和入口 | 不受影响的资源保持可用 |

现有三项待核页签继续隔离：`microeconomics/demand-factors`、`microeconomics/demand-income-elasticity`、`thermodynamics/phase-change`。本方案不解除这些限制。

## 6. 站内分发与学习反馈

先确保资源关系可用，再调整分发。C0–C3 主要建设内容及必要映射；C4 承接原 B4 的首批站内编排，站外提醒仍单独登记。

- 初次学习：按所选范围，从编辑编入的基础目标开始，使用已有默认题量。
- 未完成：保留现有普通入口自动恢复，不恢复“继续上次”卡片或提示。
- 答错/揭晓/标记再看：保留原始行为，在明确映射范围内安排回看；未作答不记错。
- 重复练习：同一目标可轮换已审核变式，避免同组重复；不把一次正确上升为掌握。
- 每日常识：沿用现有最多 5 题、回顾最多 2 题及同日冻结，新增内容需显式编入，不能使当日已生成组重排。
- 考前急救：编辑专题与个人待回顾分别编排，给出用户可理解的选择理由。

记录仅复用常识既有本地进度体系；目标检测信息从题目记录及明确映射得出，不另造互不一致的掌握进度。需要新增的字段、来源版本和旧数据迁移先在 C1a 验证。

## 7. 兼容与变更边界

1. 保留现有有效资源 ID、来源引用与历史记录，新增独立目标 ID 和关系层；不直接把旧题目 ID 全量替换成目标 ID。
2. 旧问答、口诀自测、阅读位置、易混阶段和个人回顾都需覆盖迁移测试。历史题目记录仍表示当时那一道题的行为，不能无依据映射成整目标掌握。
3. 新内容只在后续新组按显式入口清单使用；未完成组不因扩题被静默重排。
4. 保留现有来源/内容版本准入。旧组因依据变化确实失效时，解释失效并按既有规则重新编排，不把其作为一般“继续上次”提示。
5. 旧候选逐项决定保留、修订、停用；不批量升为 approved。移除资源保留可追踪的迁移关系，不抹去用户历史。
6. 复用现有构建器、内容服务和学习引擎。目标层、关系校验和选题改造以小批演进，不建设第二套平行题库服务。

### 8.2 每批验收记录

每批记录五类状态，分别报告，不合并成一个“已完成”：内容编写、自动关系检查、人工内容审核、实际页面与真机体验、发布。开发试读可以使用现有 review 机制；正式入口只消费满足原准入条件的资源。

自动检查至少覆盖：稳定 ID/版本有效，引用完整，题目答案合法，目标与句子/题目对应，口诀自测不越界，比较维度和必需资源齐全，入口声明合法，受影响资源失效，以及既有记录兼容。

人工审核至少覆盖：事实准确、条件完整、表达清楚、答案无歧义、干扰项合理、口诀有记忆价值、检测能区别不同能力。页面验收包括实际题目消费、正文定位、底栏不遮挡、读测往返与旧会话恢复；真机和大字号单独记录。

验收状态未满足时，列明确缺项、处理人和下一步；可以交付候选和证据，但不标为正式内容验收完成。

### 8.3 C5-n 扩建与退出机制

C5-n 以尽可能扩大高质量题库为目标，不预设一个较小的题量上限；每批最多两个小主题只是质量控制和回归边界，不是总量限制。扩建以 170 个正文小节的处置台账为分母，每个小节或从小节中拆出的候选主题必须登记为以下状态之一：`待盘点`、`可建设`、`已建设`、`合并复用`、`不适合出题`、`待补依据`或`延期`，并记录理由。

单个主题满足以下条件后退出本主题建设：

1. 范围、排除项、来源和独立目标已经明确；
2. 每个适合检测的目标至少有一道直接检测，关键条件、易混或高价值目标有不同问法的检测，无法建设变式时记录理由；
3. 答案、干扰项理由、正文定位和必要的时效核验完整；
4. 口诀、易混辨析和急救专题均已作出“建设、复用或不适用”决定；
5. 入口编排、会话迁移和自动回归通过，人工审核与发布状态单独记录。

整个 C5-n 在同时满足以下条件时退出连续扩建并转入维护状态：

1. 170 个正文小节不再存在 `待盘点` 状态；
2. 不再存在能够直接进入下一批的 `可建设` 主题；
3. 所有 `待补依据`、`延期`、`合并复用` 和 `不适合出题` 项都有具体原因及重新开启条件；
4. 所有 `已建设` 主题均满足本方案的关系检查和批次验收要求；
5. 完成一次按文史、科技、经济、法律的全领域复查，没有发现遗漏的独立目标或仅因追求题量而重复建设的题目。

进入维护状态不代表题库冻结。正文新增或修订、官方依据变化、用户错题数据暴露稳定缺口、已有题目失效，或出现可验证的新目标时，重新把对应项目标为 `可建设`，恢复一个不超过两个小主题的新批次。题库退出依据是内容已经完成处置且继续扩题只会带来重复或低质量，不以单一题目总数作为完成标准。

## 9. 建设效果与覆盖口径

每批报告：已盘点目标数、已核验目标数、有直接检测的目标数、有有效变式的目标数、适合口诀的目标数及已配口诀数、口诀映射完整性、易混组完整性、各入口实际准入量、待核/停用数量。

覆盖率必须注明分母：只对本批已盘点目标计算，不对全库未盘点目标推定覆盖。口诀覆盖分母是明确适合且计划建设口诀的目标，不以所有目标强求口诀全覆盖。

产品试用再观察：不同问法的检测结果、同一目标反复错误、口诀回看后的后续表现、内容纠错反馈、专题实际完成时间。样本不足只报告观察值，不宣称口诀有效提升或考试提分。
