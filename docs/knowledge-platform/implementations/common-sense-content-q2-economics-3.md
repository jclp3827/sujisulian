## 2. 记忆资源

- **多同、多异、少互、独无**：升级为结构口诀候选。“多同自由全，完全竞；多而有差易进退，垄断竞；少数互相看，寡头；独家无近替、进入难，完全垄断。”学习时先看厂商数量，再看产品差别和进入条件；少数厂商追加相互依存，独家追加近似替代品边界。
