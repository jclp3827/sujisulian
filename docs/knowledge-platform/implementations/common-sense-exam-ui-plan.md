# 考前急救信息展示与组件一致性分批方案

工作树：`codex/common-sense-learning-v1`。日期：2026-10-25。用户授权：登记方案后按批次实施。EUI-1、EUI-2已完成开发与定向验证，尚未人工点击/真机验收。

## 目标及边界

题目优先进入首屏，范围说明按需查看，进度只保留一套；复用已有知识导读的紧凑布局、局部操作样式与通用样式变量。保留“精选回看／个人待回顾”的不同学习路径。

不改题目、答案、选题规则、计分、待回顾准入、稳定ID、来源、存储协议或正式准入；不修改训练模块和公共组件接口。不把样式一致理解为照搬训练页三张统计卡。

## EUI-1：标题、范围和进度（开发完成）

- 导航栏继续显示“考前急救”；答题页内主标题显示当前题所属精选专题。跨专题时跟随当前题，不固定取第一个专题。
- 个人待回顾页标题使用“个人待回顾”；具体知识主题可在题卡提供，不将混合错题假称某一精选专题。
- 主标题旁提供“范围说明”“学习设置”。范围说明默认关闭，换题、切模式或进入设置时收起。展开后显示当前适用专题的目标、覆盖与不覆盖内容。
- 移除常驻范围大卡及面向用户的“纳入理由”“完成边界”长段。编排资料保留；完成状态仍由既有引擎决定，完成页继续提示记录不等于掌握及回顾安排。
- 合并为一张紧凑进度卡：当前题目x/n、答对数、一根进度条。不同时显示已处理统计卡、百分比文字及重复选题理由。
- 完成态显示完成结果；空队列不出现1/0、错误专题或范围说明。设置态保留独立设置界面。
- 题卡、解析和底部按钮保持现状，留待EUI-2。

验收范围：两模式、跨专题标题、展开说明不写进度、切模式恢复各自会话、空队列与完成态；56项学习回归、模板编译和定向开发者工具页面数据/布局检查。首屏目标是题干及首个选项进入可见区，不声称任意长题或任意字号都一屏容纳完整选项。

## EUI-2：题卡、解析、选项宽度与设置模板（开发完成）

- 题卡标题、题干、选项和来源提示的信息层级与训练组件样式一致；个人待回顾的知识主题按可核实来源显示。
- 答后区突出正确答案、判断依据和易错条件，避免解释与来源堆叠。
- 统一悬浮底栏主次按钮的尺寸、顺序、留白和安全区，保持原事件行为。
- 选项明确占满题卡可用宽度，保留完整文字和可读字号，不用截断、限行或缩字掩盖折行问题；长选项仍允许自然换行。
- 常识学习页共用局部设置模板：单一设置标题、学习范围、每组数量、低调的刷新提示与固定底部保存。范围采用三列网格，数量保持三档；不修改训练模块或公共样式。
- 进入设置隐藏学习组标题和统计，关闭设置保持当前题目，保存仍按已有逻辑即时刷新；保留保存失败及重试行为。
- 针对未答、答后、跳过、末题、完成和保存失败状态验证；必要时以少量样例先确认呈现，再推广。不在本批重写题目或扩库。
