# 知识导读样本 UI 第三轮：对齐正文阅读品质

日期：2026-10-25。工作树 `common-sense-learning-v1`；基线 `381964581f4a6af22f49f63a4fd3e7d5dbfb9698`。本轮只调整知识导读样本页的展示层，不扩库、不扩大重点标注批次，不改变学习存储、判分和身份协议。

## 最终层次

- 原生导航保留功能名称；内页只显示绿色科目定位与当前知识组大标题，不再重复“知识导读”。
- “学习设置”位于科目行右侧；“本组说明”与知识组标题同排，默认收起。展开内容采用正文页同类的浅绿导读面板。
- 原三张独立进度卡合并为一张轻量进度卡，保留当前卡片、已回顾、记住了和训练模块同款细进度条，避免多个卡片争抢注意力。
- 知识点卡采用正文页的白色阅读面、蓝色章节标记、明确标题和舒展正文。候选加工方式和查看原文降为卡片底部辅助信息。
- 正文字号为 30rpx、行高 1.74：略高于正文页常规信息块，适合单卡快速阅读，同时与 40rpx 知识点标题保持清晰层级。
- 已审阅的前三批共十五张力学卡使用深色粗体和由底部向上渐隐的主题蓝宽底线；底部不透明度为 42%，经 36%、24% 逐步过渡，并在 13rpx 处完全透明。换行后仍跟随对应短语。未入批卡不自动推断重点。
- 候选状态缩为单行弱提示，保留审核身份和与正式进度隔离的信息，但不参与主要视觉层级。

## 复用边界

页面继续使用全局主题变量、`surface-card`、`pill-action` 和训练进度条结构。正文页、训练页、公共主题与公共组件均未修改；知识导读页只复用其视觉语言，不新增公共接口。

## 验证

- 2350 张卡片的文字与签名保持不变；候选重点卡仍为 5 张。
- 学习回归 56 项、知识导读页面检查、候选包检查、两项生成一致性检查通过。
- 10 份模板/样式离线编译通过，故意损坏模板能够被拒绝。
- 样式检查锁定 30rpx / 1.74 的正文阅读参数，以及粗体、主题蓝、13rpx 渐隐范围参数。
- 微信开发者工具实测首卡默认收起、本组说明不写存储、切至牛顿第三定律后显示 3 处既定重点；四个测试缓存键在结束后恢复并回读确认。
- 模拟器分别检查默认收起和展开说明两种状态；未上传。
