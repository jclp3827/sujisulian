## 3. 候选卡范围

### 3.1 明清

- 政权主线：明朝建立与灭亡、永乐时期、后金到清朝建立、康乾盛世；
- 重要事件：郑和下西洋、土木之变、戚继光抗倭；
- 国家治理：废丞相与设内阁、地方三司、厂卫、一条鞭法、八股取士、军机处、理藩院与驻藏大臣、摊丁入亩；
- 社会经济：美洲作物、景德镇制瓷、纺织业资本主义萌芽。

### 3.2 散文

- 典籍与经典：《山海经》、四书、五经、六经、《淮南子》；
- 作家与流派：唐宋八大家、韩愈、柳宗元、欧阳修。

## 4. HOLD 与风险处置

8 项内容没有通过润色强行准入：

1. 清初台湾收复与建置的时间线：源文混合进军、投降、攻台和建置年份；
2. 三藩之乱参与者：源文未区分尚可喜和尚之信；
3. 明朝是否为首个由南统一北的全国政权：比较范围和“统一”定义不明；
4. 《尼布楚条约》边界与领土表述：条约条款被压成单一结论；
5. 闭关锁国政策起始与严重程度：海禁、口岸管理和闭关政策混用；
6. 《淮南子》是否最早完整记载二十四节气：属于文献史极值判断；
7. 韩愈是否最早提出古文概念：概念、倡导和运动边界不清；
8. 柳宗元是否为首位独立创作寓言的作家：体裁和“第一位”判定范围不清。

每项均已登记来源、问题原因和恢复所需证据，且不计入 27 张可学习候选卡。
