## 重点标注合同

用户补充“重点突出”应形成批次逐批优化。因此取消全库自动关键词高亮，只用显式审阅清单。每张标注绑定稳定卡ID和标题/正文哈希；内容变化或任何选定短语失配时，整卡回退普通文字。未入批卡不推断重点。每卡最多三处、合计不超过四分之一正文，保留条件、否定词与关系，不只加粗孤立名词。

首批仅覆盖经典力学的5张基础卡（并非整个23卡知识组都已完成标注）：

| 卡ID（均以physics::开头） | 标注 | 判断依据 |
|---|---|---|
| force-three-elements | 大小；方向；作用点 | 明确三要素的具体组成 |
| newton-first-law-inertia | 合力为零；匀速直线运动；不是一种力 | 同时保留条件、运动状态和惯性的性质边界 |
| newton-second-law | F＝ma；质量一定；方向与合力方向相同 | 公式、比较条件与方向关系 |
| newton-third-law | 大小相等、方向相反；不同物体；不能相互抵消 | 同时突出大小方向关系、作用对象与不能抵消的结论 |
| friction-force | 相对运动或相对运动趋势；相反；增大压力 | 阻碍的对象、方向关系与常见改变方法 |

这些是展示标注，不是新增知识题库或正式事实审核。黄金样例相同稳定ID、相同文案可复用这5张标注；653卡旧投影基线身份不同，不按相似标题套用。
