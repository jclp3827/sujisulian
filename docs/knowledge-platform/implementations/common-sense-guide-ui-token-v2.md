# 知识导读样本 UI 第二轮：层次与通用主题

日期：2026-10-25。工作树 common-sense-learning-v1；基线 381964581f4a6af22f49f63a4fd3e7d5dbfb9698。承接上一轮布局和5张重点样本，不扩库、不扩大重点标注批次。本记录补充上一轮登记，不覆盖历史回执。

## 展示层次

- 原生导航保留功能名称；内页改为当前知识组名称（如“经典力学”），不再重复“知识导读”。科目作为较小的定位信息，“学习设置”仍可进入设置。
- “本组说明”与知识组标题同排，默认收起，按需展开；换卡后收起。说明不再占据首要视觉位置，文本保持原样。
- 知识点标题字号高于知识组标题。正文保留完整信息，在句子边界分段；仅已登记的5张力学样本用深色粗体及下划线突出条件、关系、结论。
- 查看原文位于卡片底部右侧；加工方式用次要文字。四个记忆标记按钮仍固定底部，原有行为不变。

## 训练进度与主题复用边界

使用训练页面当前实际使用的三格进度结构与通用 surface-card 样式，显示“当前卡片、已回顾、记住了”，配一条进度条。删除卡内及条下的重复计数；记住了为用户自评数量，不是判分。数据来自现有会话结果，没有改存储、判分和身份协议。

颜色、文字、圆角、背景、阴影及大部分间距引用现有 theme token，共23个引用均有定义；进度卡尺寸、字号和细条厚度沿用训练页布局。未修改公共 theme/ui、训练页面及公共组件。曾尝试直接接入 session-head 组件，但模拟器未实例化，已移除此尝试，页面配置恢复基线；交付采用实际验证可见的训练页内联结构，不宣称公共组件挂载成功。
