## 采用辨析题的主题

- market-failure-meaning：单一定义较短，直接理解优于另造口诀。
- civil-principles-compare：原则判断依赖具体法律含义和案件条件，关键词口诀容易诱发机械套用；继续使用情境题与易混对照。
- minor-capacity：判断依赖年龄、辨认能力、主要生活来源及行为效力边界；数字压缩会丢失决定性条件，采用三例辨析。

## 扩充顺序

1. 先处理已确认来源中的有限主题，每组 3–5 个明确目标。
2. 每题同时核对解释、干扰项和边界；每条口诀核对所有分句与目标。
3. 待核来源先解决问题并修订正文，再解除派生限制；不通过移除限制或修改状态强行放行。
4. 各批审核与版本分别记录；医学、急救、安全及变化较快的法律/科技材料，先补相应权威核验资料。
