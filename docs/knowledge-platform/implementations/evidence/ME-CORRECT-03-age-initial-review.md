# 年龄例题独立核验（2026-10-23）

审阅范围：actual worktree `miniprogram/models/note-quantity/points/applied.json` 中 `age-problem` 的一条例题。此报告由独立子代理完成；未修改 actual worktree。

## 结论

原题不能继续把唯一答案 8 年作为没有附加解释的官方真题结论。存在两层真实歧义，均可通过明确标注为“原材料整理的讲解示例”并公开补齐采用的解释解决，不需要假造原题或请求用户凭偏好裁决数学事实。

1. “父亲7年前……孩子年龄6倍”没有明确孩子比较时点。按双方都取7年前，孩子今年12岁，父亲37岁；按孩子今年，孩子6岁，父亲43岁。两种解释都满足其余同样的平方数与年龄和条件。
2. 即使双方都取7年前，如果时间可以是实数，最近一次整数倍是在 8/5 年（1.6年）前，6倍。只有过去正整数年时点才得到8年。整数倍不意味着所求时间必为整数年。

## 有限穷举与精确计算

使用 `fractions.Fraction`，枚举所有正整数年龄、平方数边界由总和149直接限定；未用父母/外公的预设常见年龄范围。

外公>母亲时，正平方数 G、M、G+M 且 G+M<149 的全部组合仅 `(16,9,25)` 与 `(64,36,100)`。若双方都取7年前，F=6C-35；第一个组合得 C=159/7，不满足现年龄为正整数；第二个得 C=12、F=37。若不使用外公>母亲这个明确条件，还存在反置外公36、母亲64，故拟修订题干应明示外公年长。

取G=64、C=12，过去t年倍数为 `(64-t)/(12-t)=1+52/(12-t)`。整数t、0<t<12时，所有成立的t为8、10、11，最近是8。连续t时倍数k必须大于64/12，最小整数k=6，t=(12k-64)/(k-1)=8/5；随k增加t递增，故这是最近一次。

字面取F-7=6C，G64、M36仍成立，F43、C6。整数t且0<t<6时，所有成立的t为4、5，最近4；连续t最小整数倍数k=11，最近t=(6*11-64)/10=1/5年。

证据：`/private/tmp/notes-age-independent-20261023/enumeration.json`。其中不满足亲属年龄顺序/整数条件的分数年龄只作为排除项，不作为可行历史求解。
