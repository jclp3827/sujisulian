## 生成起点

先确定考试中要调用什么，再选择出题形式。目标卡必须回答：

1. 主模块与子专题是什么；具体考查的是哪一条规则或哪一步判断。
2. 考生在怎样的公考任务中会用到它；不能只写“提高能力”“帮助理解”。
3. 需要快速回忆的内容是什么；写出确定答案核心和必要条件。
4. 容易忘记或混淆在哪里；误用会导致什么具体判断错误。
5. 题目实际要求的动作是否恰好检测这个目标，是否可通过无关常识、词面或选项荒谬程度绕过。
6. 结论与边界来源在哪里；主归属与来源目录不同时如何显式关联。

不强制给每段正文、每个目录点都造题；同一点可以没有快练，或有多个有不同用途的目标。不以“题目简单”代替“目标具体”，也不以“题目难”代替“价值高”。未有可靠频率依据不标“高频”“必考”。

## 三类任务

| 入口 | 适合检测 | 应排除的生成方式 |
|---|---|---|
| 基础快练 | 作答时可立即调用且易混易忘的公式、逻辑变换、具体概念边界、词义／搭配限制、口诀展开、方法触发条件及关键步骤 | 给正文标题作定义；用来源口吻考一般建议；字面同义复述；具体数值求解；为了三类齐全凑基础题 |
| 方法判断 | 同域易混分界、条件判定、信号识别、错误诊断、某一步选法或列式；可直接给公式比较，也可用最短充分任务试用 | 只问“应认真审题／结合语境吗”；用空泛标签替代具体决策；要求算完整题；没有差异依据的对照 |
| 完整题应用 | 完成原笔记既有例题的完整任务，并明确它检测何种考试目标 | 新编完整题填原题导入配额；缺图缺任务仍导入；原题实际检测目标与挂接目标不符 |

一道题只保留一个主要目的。图8虽有多个逻辑选项，其主目的仍可为合取命题逆否规则的快速调用，不因有干扰项就强行迁为方法题。概念定义并非一律禁用；必须说明它在具体考试任务中的直接作用，不能自动按一页一个定义生成。

## 全部必须满足的内容规则

| 规则 | 要求 | 判断依据 |
|---|---|---|
| EXAM-01 | 考试用途明确 | 回答“考生在哪类公考作答步骤会用到这条记忆”；泛化的好习惯、教学标签或字面释义不能代替用途。 |
| EXAM-02 | 主归属准确 | 考试模块、子专题、具体目标分别登记；来源目录不是主归属充分证据。 |
| EXAM-03 | 记忆目标具体 | 记录可直接调用的概念边界、公式、逻辑变换、口诀展开、触发条件或关键步骤；说明遗忘或混淆如何影响解题。 |
| EXAM-04 | 考察与目标一致 | 题目正确选项必须命中所登记目标，不能挂比例论证却只考一般分数分母。 |
| EXAM-05 | 表达独立清楚 | 题干与选项、解析不以“笔记说／笔记要求／本节介绍”为权威，不复述未展开的教学标签；来源留在引用字段与查阅入口。 |
| EXAM-06 | 干扰真实可辨 | 干扰来自同一目标下的实际误用、反向、条件漏项或相邻概念，不能混入无关领域或靠荒谬表述送分。 |
| EXAM-07 | 形式服务目标 | 基础不计算、不塞完整故事；方法以区别、识别或某一步决策为终点；应用保留原完整任务，不按三入口硬配额。 |
| EXAM-08 | 口诀可展开且有边界 | 口诀绑定每字实际含义及可提示的观察方向，不只考谐音拼写；“考虑／优先”不能变成唯一或必然规律。 |
| EXAM-09 | 来源与答案有效 | 逐项核源、必要条件、唯一答案、图片完整性和暴露；块哈希正确不等于语义正确。 |
| EXAM-10 | 审核事实独立 | 自动结构、语义专家判断、用户方向认可、正式内容批准分别记录；不把review候选和source点数量充作合格覆盖。 |

来源允许出现在引用元数据、审核证据及“对应笔记”导航中；禁止的是把“笔记要求／本节说过／文中介绍的原则”作为题干或答案权威。题中若来源文本本身是原应用材料，保持原题语义；词面扫描只报疑点，不静默改写原题。

## 干扰项与表达

每个干扰项登记对应的具体误解：公式符号位置颠倒、增长率与倍数混用、且或变换错误、肯定后件、词语对象或色彩误用、口诀所指考点混淆等。同题各选项处于相同问题范围，句法尽量平行，不能用正确项独有的长解释或绝对化荒谬选项提示答案。

“过去现在将来／褒贬中性／分子分母整体”这种跨领域拼接应直接拒绝。逻辑题把“非P或非Q”与“非P且非Q”、逆否与倒转相比较，能体现真实知识错误，可以作为方向样板。自动检查可以提示长度或词面异常，但不得据此自动判语义合格。

## 模块侧重点

| 模块 | 基础优先目标 | 方法优先目标 | 低价值风险 |
|---|---|---|---|
| 判断推理 | 命题翻译、逆否与否定规则、量词／条件边界、论证典型漏洞及适用限制 | 根据论证选削弱／支持方向，识别基数或因果缺口，判有效推出 | 挂逻辑点却只问一般算术；背“某方法是什么”的标签 |
| 图形推理 | 口诀的实际展开、考点清单、提示特征与检查维度 | 选择观察方向，辨析相邻方法及使用边界 | 全直释义、只考几何名词、无图猜具体图形、只背口诀字形 |
| 言语理解 | 具体词义、常见对象、使用限制、确有来源的易混词差异 | 短语境限制词义／搭配／程度／色彩，判断关系与选词依据 | 给“上下文解释对应”等组织标签下定义；只背褒贬分类名 |
| 数量关系 | 有条件的模型关系、公式、关键方法触发和易误用步骤 | 最短题干识别模型、未知量／基数、适用条件和列式 | “做题要检查”的一般建议；强行把所有技巧改成计算快练 |
| 资料分析 | 量的口径与单位、具体增长／比重／平均等关系及易混边界 | 根据所求和数量结构匹配公式、比较或估算方法 | 问正文怎么说；用换数／换序冒充新目标；重复训练模块算术 |

本表为模块内容方向，不宣称已完成全部考纲或已经测定高频。每个具体目标仍须逐条核源和审题。

## 图形口诀和共享来源

口诀应形成“助记表达—各字对应考点—可提示的观察内容—适用限制”完整关系。可问某字对应哪类观察、补缺考点、回忆方法清单；不能只问谐音字怎样写，不能把特征提示写成必然唯一规律。

当前已有口诀正文在`logic/graphic-qualitative-quantitative/knowledge`，源写“屈臣氏整风”，用户例子写“屈臣氏整形”；语义映射先按来源逐条核验，名称待统一。当前源“氏”写“相同相似图形”，独立图形`similarity`页却叫“样式规律”，必须消除映射歧义后才能用于正式候选，不能猜词补断言。

主考试归属拟为图形，来源仍保持原JSON身份。现编译／运行契约要求资源来源同科，因此EV0须实现和核验显式共享来源关系后再选入；不能复制正文、改错source subject或取消来源校验来绕过。原目录、正文和历史状态不因这次归属设计自动迁移。[模块及来源登记](notes-learning-exam-modules-v3.json)列出三条历史图形来源。

## 生成和审核流程

模块目标清单 → 核验考试用途与来源 → 旧题保留／重写／撤下／隔离 → 按合适形式生成 → 逐题检查目标一致与干扰 → 候选构建 → 语义复核与运行回归 → 登记模块结果。任何一步无依据可以不出题。

生成指令必须先输出目标卡，缺明确考试用途、具体记忆点或源依据的对象返回“暂不适合生成”及原因，不编空泛题。每题交付主归属、考点、答案核心、任务类型、容易混淆之处、必要条件、来源、每个干扰项的误解和审核决定。自报字段齐全不能替代专家对内容的判断。

旧49道自编基础／方法全部进入考试适配重审；15道原例题核目标对应、题源和完整性，不因是原例题而跳审。7道截图否决题禁止作为新模板；图8只用于正向校准，保留review。自动、方向认可、语义审核和正式批准分别记录；本轮批准数仍为0。

## 批次与覆盖

以五个考试模块为生成与验收批次，模块内部按专题分组；每次审阅切片最多12题，切片不是跨模块批次，也不是题量配额。取消每科平均配3基础3方法等做法，不给每个知识点硬配三入口。一个模块完成目标清单、旧题处置、新候选和验收后，再按计划进入下一模块。[批次](notes-learning-exam-v3-batches.md)。

统计分别记录工程候选数、语义审查合格候选数、正式批准数、已审核考试目标覆盖数及来源点涉及数。162个来源点不能直接充作162个有效考试目标；先前16/162只表示来源涉及，不代表考试内容有效覆盖。
