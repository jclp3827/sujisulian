## 产品目标与范围

笔记是面向行测的公共积累知识的系统精炼与整理。它吸收多年网友及机构的总结，帮助用户面对判断、图形、言语、数量、资料等庞杂知识，迅速建立框架、整理思路、关联知识、复习易混易忘点，并进入应用。它不是用户个人记录工具，题库数量也不是其全部价值。

笔记本体负责清楚、精炼且保留必要条件的知识框架、概念、方法与关系；练习负责检测知识调用、辨析与应用。本版准入只约束练习：某项内容只适合解释、梳理或关联，依然保留，不为凑题删知识或强行设题。每模块应核框架与关系、记录内容缺口；本轮不自动扩展为重写50个原JSON或重新设计导航。

首页继续搜索、全部笔记与三个练习入口；全部笔记沿用常识式科目／专题／知识点定位。练习可精确查阅相关知识，并回到同一题组。计算技能继续使用既有训练链路。政治、常识和训练状态独立。

## 本轮执行目标

| 目标 | 可验收结果 |
|---|---|
| GOAL-01 知识有序 | 5科40专题162个唯一来源点逐项有框架、必要条件、关系与去向核对，不把来源点数当考试目标数。 |
| GOAL-02 练习有用 | 每题有具体行测作答用途、答案核心、易混易忘原因、主要动作和可靠来源；不从标题或一般建议直接造题。 |
| GOAL-03 旧题有结论 | 64项冻结台账逐题处置；7个否决当前形式先隔离，正例仍复审；49道自编与15道原应用均不过继合格。 |
| GOAL-04 审核可追溯 | 独立语义回执绑定有效题目、目标、来源及规则版本；不能用自报true或旧回执通过新内容。 |
| GOAL-05 更新可恢复 | 目标或相关来源实质改变，只使受影响活动会话失效，保留历史作答和无关会话；共享来源能准确选题、回源和返回。 |
| GOAL-06 交付分层 | 工程候选、语义合格、正式批准、启用、设备体验及发布分别登记，不互相替代。 |

不设扩题总数、模块平均配额或三入口比例。先清点和审核，再按有效目标补缺。没有可靠频率依据，不标“高频”“必考”；采编来源不自动等于官方考纲或真题出处。

## 三类按作答动作划分

| 入口 | 主要动作与可纳入内容 | 边界 |
|---|---|---|
| 基础快练 basic | 直接回忆可立即调用的具体规则、公式及条件、概念边界、逻辑变换、词义／搭配限制、口诀展开、关键步骤。 | 不做具体数值计算；排除标题释义、字面复述、一般建议和无明确解题用途的分类名。 |
| 方法判断 method | 在同域概念、公式、条件、方法间区分、识别、诊断，或完成一步选法／列式。可以直接辨析，也可用最短充分情境试用。 | 终点是判断依据或一步决策；不要求新故事，不把完整题拆短后仍要求全程求解。 |
| 完整题应用 application | 完成原笔记既有例题的完整任务，包含必要材料、提问、选项、图像。 | 沿用原题内容并核目标；缺图、任务不完整或图上暴露答案时不独立入题，不用新编完整题填原题导入配额。 |

同一知识可以支持不同入口，按该题主要动作归类，不按“公式／概念／方法”这些内容名词分栏。有干扰项不自动成为方法题，有公式不自动成为基础题。

校准例（只说明设计，不是已生成合格题）：合取命题逆否式的直接回忆属于基础；给出推断，区分逆否、倒置、肯定后件属于方法。已明确A=B/C后直接回忆比值增长率公式属于基础；识别“收入=单价×销量”和“人均=总量÷人数”的结构并选乘积／比值模型属于方法，终点不求数值。沿原材料算完并选出答案属于应用。

图8是有价值的方向样板，仍须独立复审；图5/6支撑概念可在正文保留，不能由当前题形式不合格推导几何知识无用。定义可入基础，但必须证明确切调用价值。

## 生成前先清点知识与目标

来源点台账先记录框架、必要条件和关系依据，去向可为：发现可出题目标、仅框架／解释、仅关联、来源／归属待核。无独立出题价值无需伪造目标。

在既有targets上扩充目标卡，不再建立第二套独立目标身份：明确主模块／专题、考试用途、需要回忆的知识、答案核心、必要条件、易混易忘点、任务动作、相关概念或方法关系及来源绑定。一个来源可零或多目标，一个目标可关联多来源。目录归属不能替代目标归属。

每个模块生成前冻结目标清单版本；增加、合并或撤销目标均保留变更原因和前后映射，不从统计分母中静默删除hold或无题目标。先审旧题，再补未覆盖的有效目标。替换措辞、数字或选项顺序不自动形成新目标或新题族。

## 练习准入规则

通用规则全部适用；条件规则只在条件成立时适用。每条评审记录pass／fail／hold及证据；仅EXAM-08在无口诀时允许not-applicable并说明原因。全部适用项pass才可接受候选，字段齐全不等于内容合格。

| 规则 | 要求 |
|---|---|
| EXAM-01 考试用途明确 | 回答“考生在哪类公考作答步骤会用到这条记忆”；泛化的好习惯、教学标签或字面释义不能代替用途。 |
| EXAM-02 主归属准确 | 考试模块、子专题、具体目标分别登记；来源目录不是主归属充分证据。 |
| EXAM-03 记忆目标具体 | 记录可直接调用的概念边界、公式、逻辑变换、口诀展开、触发条件或关键步骤；说明遗忘或混淆如何影响解题。 |
| EXAM-04 考察与目标一致 | 题目正确选项必须命中所登记目标，不能挂比例论证却只考一般分数分母。 |
| EXAM-05 表达独立清楚 | 题干与选项、解析不以“笔记说／笔记要求／本节介绍”为权威，不复述未展开的教学标签；来源留在引用字段与查阅入口。 |
| EXAM-06 干扰真实可辨 | 干扰来自同一目标下的实际误用、反向、条件漏项或相邻概念，不能混入无关领域或靠荒谬表述送分。 |
| EXAM-07 形式服务目标 | 基础不计算、不塞完整故事；方法以区别、识别或某一步决策为终点；应用保留原完整任务，不按三入口硬配额。 |
| EXAM-08 口诀可展开且有边界 | 口诀绑定每字实际含义及可提示的观察方向，不只考谐音拼写；“考虑／优先”不能变成唯一或必然规律。仅涉及口诀时适用。 |
| EXAM-09 来源与答案有效 | 逐项核源、必要条件、唯一答案、图片完整性和暴露；块哈希正确不等于语义正确。 |
| EXAM-10 审核事实独立 | 自动结构、语义专家判断、用户方向认可、正式内容批准分别记录；不把review候选和source点数量充作合格覆盖。 |

每个错误选项必须对应同域具体误解，如符号位置、条件漏项、且或变换、词语使用对象或相邻方法混淆。不得拼接时间词、褒贬词、分子分母等跨域干扰，不用荒谬绝对项或正确项独有长解释送分。词面扫描只提示待核；原应用材料中的来源文字不能被扫描器静默改写。

题干、选项、解析不能把“笔记说／本节要求”作为知识权威；引用元数据与“对应笔记”导航可保留。删去“笔记”二字不等于修复一般建议或目标错位。

口诀须形成助记表达—各字含义—可提示观察方向—限制的关系。源写“屈臣氏整风”，用户例写“屈臣氏整形”；“氏”的相同相似与独立graphic/similarity的“样式规律”尚有映射歧义。只暂停依赖该歧义的目标，不暂停全部图形；不凭英文ID猜同义，不把提示写成唯一规律。

## 两项审计问题的落地契约

### AUD-01：独立语义回执与状态

回执为追加式审核事实，字段和枚举见[结构化契约](notes-learning-exam-rubric-v4.json)。必须记录回执ID、规则版本、评审者身份／类型／角色／范围、带时区时间、问题ID与revision、有效内容摘要、解析后的依赖清单及摘要、逐条规则结论、干扰误解、决定、理由、证据和被替代回执。agent复核如实标识，不冒充人工专家或正式批准；生成自评不能充作独立复审。

摘要在原例题解析、展示补全和图片依赖解析后计算，覆盖实际看到和检测的内容。沿用既有targets、知识原子、辨析关系、来源哈希及approvalDigest；独立回执补充证明语义审核，不替代现有内容批准。原题任务已verified仅证明任务完整，不能证明真题身份。

回执绑定题目有效内容及主／辅助目标、知识／对照、来源块／原题／材料组／图片和共享绑定的实质版本。有revision的实体记录其revision与摘要；原正文页签／块和图片无原生revision时用精确身份和源／资产摘要，revision为null，不编造版本号。首条回执接替值为null，之后须显式接替当前head。共享关系摘要排除自身摘要和审核回执关联，避免自引用；回执另行校验。任一实质变更或规则版本变化，旧决定失效；不能搜索较旧accept绕过新rewrite/drop/hold。回执分支冲突须hold。相同语义的重新审核日期或回执ID变化不单独清空会话。

| 当前语义决定 | 既有状态 | 后续V4入口 |
|---|---|---|
| 缺失、过期、rewrite、drop或hold | 任意 | 不新建、不恢复或继续该题所在的活动题组；保存历史。 |
| 有效accept-candidate | review，依赖有效 | 可作为开发版已审候选，仍不是正式批准。 |
| 有效accept-candidate | approved且既有批准、来源及依赖批准全部有效 | 满足非开发入口内容条件；上线还需相应体验与发布门。 |
| 任意 | blocked或来源／任务／依赖无效 | 禁止准入；不阻断无关题。 |

旧题和历史目标可以保留存档，未补V4字段不等于必须先伪造全64审核才能开工。EV0-B切换唯一活动entryPlans时，剩余未审ID也移出清单，原记录及旧入口成员关系保留在冻结台账；运行再做准入校验。第一批真实合格候选出现前可以暂为0题，给出全部笔记入口，不回退坏题或另开未审旧入口。被选入的无效资源不能输出为V4活动资源；未选存档不阻塞已审独立模块。

### AUD-02：目标依赖、会话及兼容

新冻结实例保存解析后的主／辅助目标快照或不可变版本摘要清单，以及版本化semantic signature。目标用途、结论、必要条件，关联知识／对照、原题、来源、图片或绑定实质变化时，重新审核相关题，并使相关活动会话失效；旧作答、曝光事实、偏好、无关会话继续保留，不自动改判成绩。

现有整资源指纹不足以证明目标修订安全；EV0应在既有会话链扩充依赖证明，不新建用户历史。不得只拿整包版本使所有会话失效。独立导航别名、标签或审计时间可列展示字段白名单；题干、选项、解释、条件、口诀与源正文均不在白名单，来源全页／块校验仍严格保留。

无新依赖清单的旧实例必须与冻结基线逐项证明兼容，且该题已有当前有效语义接受；无法证明则仅让受影响活动组过期并保留记录。原7道应用曾通过旧兼容检查，不等于全部15道应用自动兼容或获准继续；新增8道也须覆盖。材料组任一必要子题不合格时暂停该组。

### 共享来源

主模块与原来源身份分别记录在显式、版本化共享绑定中。原logic的3条图形内容保持来源身份，图形批承接主目标，不复制正文。适配须贯通编译校验、主科目／专题选题、原来源点回练、精确页签／锚点回源、返回同一会话及绑定变化失效。选源用subjectId+pointId+tabId，不仅凭pointId。不能全局放宽同科约束来绕过。

## 生成、复审和旧题处置

知识框架清点 → 冻结来源／目标 → 逐题处置旧候选 → 选择合适形式生成或改写 → 结构和来源检查 → 独立语义复审并出回执 → 构建／运行回归 → 登记模块结果。

旧64项逐条冻结于[处置台账](notes-learning-exam-v4-candidates.json)，操作和7个具体案例见[候选处理方案](notes-learning-exam-v4-candidates.md)。已否决题先退入口，内容和历史保留；全部64项随后按模块复审。单纯编辑且目标、任务、答题空间不变可升revision并重审；改变主要目标／模式／原任务则新ID，旧ID保留退出与替代映射，旧作答不计入新题。若判断改变不得回头覆盖旧用户评审证据。
