# 笔记题型公考目标专家评审

日期：2026-10-22。依据用户提供的8张实测截图重新校准内容目标。结论：图1—7当前题型不合格，图8保留为用户认可的方向样板。上一轮工程自动检查没有评估“记住它能否帮助公考作答”，将正文可出题误当成教学价值准入，不能继续沿用这一生成依据。

本次只更新规则、评审记录和模块生成批次；不重生成题、不改开发入口或用户状态。当前包仍有64道工程候选，全部review、正式批准0；这不是64道考试适配合格题。8个样本也不支持判定其余56道全部合格或全部不合格。

## 逐图判断

|---|---|---|---|
| 1：普通方程选未知量 | 数量关系／方程 | “笔记给出的原则”是来源口吻；一般建议配荒谬干扰，没有具体记忆增益 | 撤销当前问法；具体目标重建，不能只删“笔记” |
| 2：上下文解释对应 | 言语理解／逻辑填空 | 是教学组织标签，被题干当成待记知识；答案近乎复述名称 | 基础改考具体词义／使用限制；短语境解释线索放方法试用 |
| 3：内部发生率分母 | 判断推理／逻辑论证／比例类论证 | 只考数学分母；与识别比例论证缺基数的目标不一致 | 考“用事件人数或事件构成推风险”的漏洞与所缺群体基数 |

图3的“知识来源”确实挂在比例论证，问题出在实际测量目标被缩成了分母定义。图4则实际属于言语理解。两者都不能仅凭页面归类或题目标了某个pointId便算归属清楚。

## 应采用的规则

先写清“考试模块—子专题—具体考试目标—需要快速调取的内容—易混易忘点—本题实际动作”。只有这些能对应，再选基础、方法或应用形式。基础可包含定义，但该定义必须对应具体的作答用途和记忆必要性；题短、答案正确、来源存在都不能单独证明有价值。

来源口吻应退出题干、选项和解析的权威表达；“对应笔记”可继续作为查阅入口。不能只做删词、换标题等表面修改。对于“上下文解释对应”一类标签，应识别其背后的具体词义约束或语境选择动作，而不是强迫用户记住这个标签的定义。

图形先帮助调用“口诀—展开考点—观察线索—后续检查”；不能用基础几何名词解释填满快练。当前源写“屈臣氏整风”，用户举例写“屈臣氏整形”，名称应核对后统一，出题重点不是谐音字写法。源明确给出的含义为曲直性、对称性、相同相似图形、整体部分、封闭开放。其中口诀源在判断目录，图形自身similarity页却叫“样式规律”，需明确主归属与来源关联，不能只凭相似英文ID自动合并。

## 改写方向校准

这些是规则示意，不是已新增运行题：

- 图3：围绕“仅凭事故者中某类人较多，就认定该类人风险更高”的论证，回忆应核对各群体内部比例；方法题让用户判断缺失的是哪一组基数。避免改成纯比例计算。
- 图2：使用足够短语境，要求识别空格需表达“信息不完整”等具体含义；不要再问术语是什么意思。基础则回忆来源可核的具体词语含义和使用限制。
- 图形：回忆“点线面角素”中某项对应的实际观察内容，或对称性分析要检查的维度；方法题再让用户根据给定特征选择观察方向，具体图形判断仍须有图。
- 图8：保留“(P且Q)→R的逆否是什么”这种直接调用；干扰可来自把“或”误写成“且”、把逆否误写成简单倒转，而非混入无关常识。
