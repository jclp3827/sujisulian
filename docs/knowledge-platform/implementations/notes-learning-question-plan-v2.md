## 三个入口的分工

| 入口 | 学习目的 | 纳入内容 | 作答终点 |
|---|---|---|---|
| 基础快练 | 明确并记住单项知识 | 定义、术语、符号含义、单项公式、明确方法的条件与步骤、单一词义或典型对应 | 说清或认出这项知识，不做具体计算求值 |
| 方法判断 | 辨清差异、关系和适用性，并试用方法 | 概念/公式/条件/方法对比，量与符号角色匹配，错误原因辨析，小任务选法或列式 | 给出区别、匹配、适用判断、错误原因或某一步方法选择 |
| 完整题应用 | 在真实完整任务中运用知识 | 原笔记已有、题干材料提问选项答案齐全的完整题 | 回答原题所问，允许计算、语义判断或逻辑推理 |

三类按主要作答动作划分，不按字数、题目难度、是否含公式、是否出现数字或选项个数划分。基础题有多个干扰选项，并不因此成为辨析题；方法题应把差异、关系、适用性或步骤判断作为主要目标。完整应用也不一定需要数值计算。

同一来源可派生基础题与辨析题，并共享知识身份；题目保留一个主要检测目的，显式选入入口。题型重分类不复制题目成两道，不凭入口数量增加知识覆盖。

## 基础记忆与方法辨析的边界

| 内容 | 基础快练 | 方法判断 |
|---|---|---|
| 概念 | 记住百分数、百分点各自的含义 | 区分两者回答什么、判断表达是否混淆 |
| 公式 | 回忆某一公式及符号定义 | 比较乘积与比值公式、精确与近似关系、增长率与倍数 |
| 条件 | 回忆某已明确方法的适用前提 | 比较不同方法的前提，判断哪个适用或哪个条件不满足 |
| 步骤 | 回忆某方法的标准步骤 | 比较方法路径，找步骤错误或选择下一步 |
| 词语 | 回忆词义、单一典型搭配或色彩 | 辨析近义词在对象、色彩、程度及语境中的差异 |
| 图形 | 回忆轴对称、中心对称等定义与观察规则 | 直接比较性质或规则；有完整图像时再做依图的判断试用 |

“主动区分易混知识”归方法判断。基础保留各自知识的记忆，不再把易混辨析笼统放入基础。方法判断可以直接比较已给出的公式、概念或方法，不必把每题包装成新故事。

计算技能继续归训练。常用分数百分数对应、比例感、四则与估算等已有操练不由笔记重建；公式常量和固定单位关系仍可作为知识记忆，不能用禁止数字的规则代替任务判定。需要图像的题缺图时暂停该题，文字定义和规则对比可以继续。

## 方法判断的内容组织

方法判断复用其他模块易混辨析的学习思路，在笔记内组织为两种任务：

1. 对照辨析：围绕一组有真实差异的概念、公式、条件或方法，提出比较问题；反馈展示对应知识、关键区别、适用边界和误区。
2. 小任务试用：给出足够但有限的信息，要求匹配关系、选择方法、判断条件、选一段列式或诊断某一步，不要求把整题算完。

两种任务使用同一方法判断入口，不新增首页入口。对照内容和相关题目共享来源与关系组，不能各自维护一份知识结论。提交前不自动展开本题答案；用户可主动查对照或笔记，阅读与作答分别记录。阅读后完成可标辅助完成，直接阅读不计为独立答对。只有确实显示了某题答案的关联才记答案暴露，不能把整专题所有题一并判作已暴露。

## 用户截图对应的首个样板

来源：`data-analysis/abrx-system/knowledge`。乘积增长率为`Ra = Rb + Rc + Rb×Rc`，适用于业务关系`A=B×C`；比值增长率为`Ra=(Rb-Rc)/(1+Rc)`，适用于`A=B/C`；比值倍数等于比值增长率加1。此处A是业务变量，不能与同页ABRX四量关系中A表示基期量的符号语境混用。增长因子及分母非零等条件随对应知识登记。

| 类型 | 任务样例 | 依据或反馈重点 |
|---|---|---|
| 基础 | 单独补全乘积增长率公式 | 确认交叉项与符号含义 |
| 基础 | 单独回忆比值增长率公式 | 确认分子、分母的形式 |
| 基础 | 比值倍数与比值增长率是什么关系 | 确认加1关系及各自含义 |
| 方法对照 | 乘积公式、比值公式分别对应哪种量的结构 | 区分相乘与相除的业务关系 |
| 方法对照 | 比值增长率与比值倍数回答什么不同问题 | 变化比例与两期比值的区别 |
| 方法对照 | 比值公式分母应对应哪一个量的增长率，为什么 | 分母量C的增长因子来自量的比值结构 |
| 方法对照 | 乘积精确关系为什么不能只把两个增长率相加 | 区分精确式与忽略交叉项的近似 |
| 方法试用 | 收入=单价×销量、人均收入=收入÷人数，应分别选哪种关系 | 在小任务中匹配数量结构，不做数值计算 |
| 应用 | 原有旅游收入增长率、亩产增长率题 | 从现有例题导入，完成原题所求 |

以上是任务样板，不是已新增运行题。先完成同一主题的三类映射，再推广到其他科目，不按换选项顺序批量增加“新知识”。

## 内容依据与生成规则

基础题从逐条核验的知识原子出发：稳定目标ID、来源页签与块/行定位、确定结论、必要条件和单项回忆任务。可生成有限的回忆、缺项、定义确认候选。正反问法与换序沿用题族，覆盖数按目标统计。来源哈希负责检测漂移，不充当长期题目身份。

方法题从有意义的比较关系或试用步骤出发。对照组登记比较对象、共享点、关键区别、适用条件、错误理解及来源；比较对象可以都正确但适用条件不同，也可以将明确误区作为待诊断表述，不能把错误选项当作知识结论入库。小任务登记输入、当前目标、决策点、正确判断依据与干扰项理由。对照题不要求新情境、隐藏名称或必须有故事背景。

应用题本轮以原笔记已有完整内容为范围：原样读取题干、材料、提问、图像、选项和答案依据，逐题审题源身份与解析。缺少提问时先核验原作答任务；仅能补中性说明且不改变原任务时，单列展示补全或改编记录，不能仍声称原样导入。无法确定原任务、缺关键条件、缺图或答案矛盾的题隔离，不能通过自行补题凑数。新编完整应用题和自绘完整图题不属于本轮既有例题导入任务。

现有生成链路继续负责正文与镜像、例题导入、候选构建和入口组题；新增的专用能力是知识原子编写、对照关系编写与小任务模板，不复制训练计算生成器。候选离线生成、校验与审核后显式选入；运行时不生成未经审核的新断言。词语不能随机拼接，逻辑符号模板只在其明确形式域内校验，图形规则不能从无字体条件的字母例子推广为普遍几何结论。

按当前知识来源、关系组、题族和版本逐项审核。源码存在或旧ready状态不等于知识结论已批准。尤其不能把“优先”“通常”扩成“必然”，不能从过度泛化口诀整页造题。
