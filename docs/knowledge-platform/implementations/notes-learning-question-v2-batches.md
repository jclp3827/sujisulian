## 产品行为

基础快练只检测单项知识回忆，保留数字、公式和方法名称，不做具体数值求解。方法判断既可直接比较已给出的公式、概念和方法，也可在小任务中选法、判断条件、诊断或列式，不要求包装新故事。完整题应用读取原例题块，题源身份仍待核，不能用新编题填满原题导入配额。

编译与运行同时约束任务、入口、来源块及知识关系。方法对照只维护一份共享知识，提交前主动查看标记查阅，阅读不计独立答对，答对记辅助完成；原例题实际揭晓才按对应原块记答案暴露。原7道未变应用保留旧会话，实质变更或退出入口的题显示内容更新，不清空训练或其他模块记录。

NQ5的两例分别具备单空/双空、四个选项及逐空解析，足以核定本地选择任务；补充说明单列`originAdaptation`，页面及审核单提示，不声称复原考试原问句。`originTask.verified`只表示本地作答任务核验，不等于题源核实或内容approved。
