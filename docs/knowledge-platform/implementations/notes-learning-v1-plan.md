## 页面与学习过程

### 首页与全部笔记

首页保留笔记现有视觉体系，以搜索、全部笔记和三个练习入口承载任务。入口数量和层级先固定，不顺带改全局 Tab、综合首页或政治风格。

全部笔记使用一个目录页面：顶部切换科目，页面内切换或展开专题，展示知识点；分类较少的科目直接分组显示。科目、专题、知识点是语义层级，知识点详情继续原生打开。结构为：

```text
笔记首页
├─ 搜索 → 命中知识点及具体页签
├─ 全部笔记 → 同屏科目／专题 → 知识点详情
├─ 基础快练 → 当前范围题组
├─ 方法判断 → 当前范围题组
└─ 完整题应用 → 当前范围题组

练习 → 查对应笔记 → 原生返回同一题和作答状态
知识点详情 → 练本知识点／本专题 → 三类方式中实际可用的一类
```

全部 162 个知识点在新目录中各有一个主归属；跨专题引用用关联入口表示。现有深链和原 ID 保留，旧模块／分类页可作为兼容入口。图形交叉分类先登记，不自动删点或合并。

搜索范围限定笔记五科，可按科目、专题收窄。命中应带实际匹配页签；不能定位更细位置时落到该页签，不伪造段落锚点。未知科目、知识点或页签显示明确降级，不能跳到另一科的首条内容。

数量关系当前会合并部分例题页签，笔记详情默认只先渲染 8 块。来源适配必须保留源页签到显示页签的映射；确有稳定段落锚点时先加载目标块再定位，不能把 `note-anchor-N` 渲染下标当成永久来源 ID。

### 三类练习的首期交互

| 方式 | 学习目标 | 首期作答 | 解析内容 |
|---|---|---|---|
| 基础快练 | 概念、公式、单位、适用条件及可单独训练的计算技能 | 单选、已有生成器支持的数值输入 | 正确依据、必要条件、具体笔记入口 |
| 方法判断 | 从问法和材料识别题型，选方法或辨析关键步骤 | 单选；先不引入拖拽排序和开放文本自动评分 | 识别信号、为什么选该方法、其他方法何处不适用 |
| 完整题应用 | 在完整题干、材料和图像中解题 | 首批为完整单选题；其他形式另列适配批 | 解题链条、关键步骤、主要与辅助知识入口 |

点练习入口时，优先恢复该方式最近的有效题组；无有效题组则使用该方式保存的范围与数量创建一组。设置只保留范围和数量，变化对下一组生效。从知识点或专题进入时显式限定该范围，不被首页保存的其他范围覆盖。

首期普通题组采用 5／10／15 道配置，默认 5 道；内容不足时按实际数量出组并说明。共用材料题不因凑题数而截断，整组超出当前非空题组的剩余预算时留到下一组。单个材料组本身超过所选题数时，在空组中展示“完整材料共 N 题”，由用户点击“练完整组”后整体纳入，或调整范围；不静默改数量，也不无限延后。首批试点不承诺固定完成分钟数。

提交后显示解析，再由用户进入下一题。未作答可以跳过；主动揭晓与提交错误分开。完成页报告本组独立答对、辅助完成、答错、揭晓、跳过及实际题量，提供同范围下一组、调整范围、返回首页。

### 练习与笔记往返

每道题至少关联一个明确知识点及页签，可区分主要方法和辅助知识。方法判断和综合题的答案标签不提前自动展开；用户始终可主动查笔记。

查阅前保存会话和题内位置；成功保存后通过原生页面栈进入详情。返回保留当前题、选择、提交与揭晓状态、材料位置和整组顺序，查阅不会自动推进题目。保存失败时停在原题并给出重试，避免跳转后伪称进度已保存。

提交前查过笔记记录为 `consultedBeforeSubmit`；查到当前原题解析另记 `answerExposed`。后续答对列为辅助完成，不能汇入独立答对。提交后查阅只记录复盘行为。关联多个知识点时提供显式链接，不由一次答错推断全部知识点薄弱。

原例题及其改编题另有题族／答案暴露组映射。已看过同题解析后再遇到同题，保留暴露事实，不能只因本次未点查阅就算独立作答。未能追溯的历史阅读不推定为未暴露，统计只陈述当前可记录的行为。

若页面栈丢失或从外部深链进入，详情只在本地存在同一有效返回令牌时展示返回原练习；否则回笔记目录。URL 不携带答案或完整题目。失效知识来源保留错误说明和可用目录入口，不静默替换为其他知识点。

## 内容与运行时契约

### 唯一事实源

正文继续使用既有 JSON 源。新增派生内容建议位于 `docs/knowledge-platform/content/notes/`：独立目标、题目、入口计划、生成配方、来源核验和批次清单分别维护，通过新增笔记学习构建器输出笔记分包运行包。

```text
既有笔记 JSON → build-note-runtime → 原正文及现有阅读器
        ↓                         ↑
目标／题目／生成配方 → 校验与审核 → 练习入口编排
        ↓
笔记学习运行包 → 一套练习会话 → 三类练习页面
        ↑
现成训练生成器／判分器的适配输出；特殊题型的独立适配输出
```

复用例题时保存原例题与派生题的映射，避免两处人工维护答案和解析。导入默认进入候选状态；核验后才提升具体版本。正文修订回到 JSON 上游重建，不手改镜像或页面事实。

### 最小实体

| 实体 | 必要字段和约束 |
|---|---|
| 来源引用 | `subjectId + pointId + tabId`、所依赖内容的哈希；可选稳定段落锚点。数组下标只作为导入时定位信息。 |
| 学习目标 | 稳定 ID、版本、所属科目／专题、能力描述、正确依据、条件与边界、来源、审核状态。 |
| 题目 | 稳定 ID、版本、题干／材料／图像、作答形式、答案和判分配置、解析、主要／辅助目标、来源、原题／改编／自编标记、可用练习方式。 |
| 材料和题族 | 材料 ID、完整材料与图像引用、所属题目；原例题与变式共享题族和答案暴露组身份。 |
| 生成配方 | 稳定 ID／版本、调用的生成器及参数域、输出形式、目标和来源、判分方式、代表样例、审核记录。实例另存实际题干和答案快照。 |
| 入口编排 | `basic／method／application`、科目和专题范围、显式资源或配方清单、编排顺序与数量预算。 |
| 用户会话 | 独立会话 ID、方式和范围、冻结题序和题目版本／实例快照、当前题、作答与揭晓状态、查阅行为、返回令牌。 |

题目身份不使用题干哈希或数组位置。首次导入分配永久 ID 并建立导入映射，后续重排保留身份，内容变更提升版本；哈希只检测变更。同一题可被多个入口选用，入口不复制题目实体。

已有例题没有稳定块 ID 时，先按知识点和页签建立可靠引用；候选导入映射记录初始位置与内容指纹。映射变得不唯一或来源漂移时停用受影响题目，待重新核验。精确段落锚点在真实存在后启用。

### 题组编排和恢复

唯一会话所有者是笔记练习服务。基础、方法、完整应用三类记录相互独立；常识和政治的存储键及训练错题本保持原语义。建议笔记存储采用 `notesPractice:v1:*`，目录位置单独命名。

先进行内容准入，再按入口和范围筛选，最后编排和冻结。首期采用编辑顺序与较少练习优先的简单规则；组内题目不重复，同一原题的变式默认不在同一组连续出现。选项乱序仅在答案映射可同步且审核允许时启用。

生成器产出的题干、答案、有效容差、图像／材料引用和生成器版本在建组时冻结。现有生成器未提供可重放随机种子时，以实际题目快照恢复，不通过重新生成冒充原题。同一生成器返回的 `trainingId-index` 只在原训练内有效，笔记实例由本次会话分配身份。

来源或题目版本改变时核对受影响会话；未改变的记录继续保留。首期不做猜测迁移，失效题组提示重新开始，旧答题事实保留版本归属。存储失败、损坏数据和图片失败均有明确状态，不伪装为正常完成。

## 生成能力的复用与补建

| 能力 | 处理方式 | 实施边界 |
|---|---|---|
| 笔记正文与镜像生成 | 沿用 `scripts/build-note-runtime.js` 的单向构建，补笔记范围参数或独立入口 | 保持 JSON 权威源及双镜像一致，局部构建不得重写常识。 |
| 例题导入与学习包 | 复用常识“目标—题目—来源—入口”流程，新建笔记构建适配 | 笔记没有常识 `sourceUnitIds` 等字段，不强塞常识对象，也不复制其整套内容包。 |
| 基础数值生成与判分 | 调用 `services/train-generator` 与现有数值判分规则 | 使用适配器保存实际实例、容差和目标映射，不复制一套公式求解。 |
| 方法判断题 | 新增编写模板；有可靠生成规则时再加专用生成器 | 必须明确识别信号、条件、唯一答案与干扰项理由，先候选审核。 |
| 完整应用题 | 优先导入现有完整例题，核对原题或改编身份 | 缺材料、图像、答案依据的例题只供阅读，不能计分。 |
| 图形题及特殊交互 | 单独建设图像／选项／判分适配与内容批 | 不从缺图文字说明猜答案，不用文字选项替代缺失图形。 |
| 分配树、拆分估算、比例感 | 统一训练启动解析，进入既有专页 | 首期作为外部技能训练；笔记未消费完整结果前不计入笔记题组得分。 |

常识的 `topic-directory`、`learning-entry`、`learning-content`、`learning-engine` 和构建器是参考清单。本轮只登记可变参考文件的哈希；N0 保存所需最小依赖集合的原始字节归档、SHA-256 清单及对应行为用例，归档与运行包隔离。源树后续漂移时使用归档核对；需要采用新版本则重新审计和登记。按中性能力适配，不把常识领域、口诀、法律门禁和存储键带入笔记。政治 `route-progress.js` 包含政治存储键，直接复用其接口前必须保持模块参数化，不能读写政治桶。

可以局部复用的是入口清单取交集、来源查找、漂移检查和目录投影规则。常识整套 `learning-engine` 耦合五入口、口诀／对照流程及常识存储，不直接导入。笔记原数据也缺少常识的来源审核字段，应新增笔记来源核验账，不从现有 `ready` 状态推导新练习已获批准。

特殊生成链路都要经过“范围与目标 → 输入约束 → 生成／编写 → 答案与干扰项核对 → 来源核验 → 候选试用 → 人工审核 → 显式编入入口”。新生成能力只补缺失能力，不承担第二份知识依据或平行的数值求解器。

## 首批内容和扩展方法

首轮范围先固定为资料分析两个小主题：“现期基期辨识与求基期”（`period-terms`、`base-period`）及“增长率和增长量的识别与应用”（`growth-rate`、`growth-amount`）。四点共 7 个显式例题块，其中 3 个选择题结构完整候选；其中“假设增量求现期”偏综合，可后置。N3 和 N4 可分别新编不超过 12 道固定候选，N5 先核现有 3 个候选，数量不足如实成组。

后续 N7-C01 再扩展“现期比重”（`current-ratio`）和“比重趋势逆运用”（`ratio-trend`），两点共 4 个显式例题块、2 个结构完整选择题候选。六点是分批素材范围，不一次全部导入。

N3、N4、N5 分别交付基础、方法、完整应用闭环，每个内容小批最多两个小主题、最多 12 道固定候选题；生成配方单独逐个审核参数域和代表实例，不把可无限生成的题量算成固定题库数。

内容批覆盖数分别报告来源知识点、学习目标、固定题、生成配方、入口准入和人工批准数。162 个知识点不是原子目标总数，不能以题目数推算全科掌握或考点覆盖率。
