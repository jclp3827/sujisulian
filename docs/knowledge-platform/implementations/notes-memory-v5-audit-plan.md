## 执行步骤

1. **冻结原身份与版本**：记录文件、subject／point／tab、源摘要、原块序号、类型及子路径；原渲染和原页签展示映射分别记录。记录基础原文、运行镜像、公式组件和现有状态的保护基线。
2. **盘点结构**：公式的nodes／content及说明；表格列名、行组和cellNodes；导图父子与兄弟关系；对照两侧；规则／信号／提醒；图片、长图及原应用。结构盘点结果只描述格式，不标语义合格。
3. **按理解目标组合**：为每个候选组合写明确记忆对象、提示方式和最小必要上下文。检查单块能否独立使用，或需合并公式与条件、多行对照、多个原块或多个来源。
4. **核切片损失**：离开原页后是否丢主题、比较对象、符号、列标题、组名、前提、例示、图像或适用边界；是否把方法体系拆成无用标签。需总览时记录“总览—子卡—应用”关系。
5. **核重组冲突与重复**：同目标不同表述合并建议；不同目标即使同源也不误去重；跨科引用需明确主学习归属、来源身份和共享依据。不同归因方式必须保留适用差异及共同背景。
6. **核展示可复用性**：原公式是否直接复用；子表重排是否保留原坐标；导图抽支是否保留父上下文；云图、长图和失败占位是否可读；原高亮、对照结构是否仍有含义。只读审计不提取组件或修改原文。
7. **登记结论与问题范围**：每个来源有处置，每个候选组合有引用和重组依据，源疑点有受影响组合及恢复条件；样板建议限于既有来源，不编写批量新内容。

## 候选组合台账的最小字段

| 字段组 | 必填含义 |
|---|---|
| 身份与来源 | auditUnitId、主审模块、原sourceRef及sha、block／子路径、原页签与展示页签映射 |
| 记忆目的 | recallGoal、基础／方法建议、正面提示意图、适用范围 |
| 引用组成 | 原引用列表及顺序、必须带入的上下文、图像与公式依赖、列／组／父主题继承规则 |
| 关系 | 总览／子卡、易混同组、关联原应用、同源重复与合并建议、跨科依据 |
| 编辑边界 | 直接引用内容、拟补标题／前提／连接语及理由；补充语与原引文区分 |
| 展示检查 | 原公式两种输入、cellNodes、配图完整性、窄屏风险、共享展示改造需求 |
| 结论与问题 | 下列主结论、原因、状态、责任范围、恢复条件、原文待核项、样板优先级 |

auditUnitId是审计组合身份，不自动成为已批准cardId。不同候选组合可引用同一来源；同一原句不能凭换标题算新增覆盖。拟补充语只登记需求，未经审阅不得当作已核知识。

## 处置分类

| 主结论 | 使用条件 | 进入P2样板的前提 |
|---|---|---|
| 可直接引用 | 单元本身语义完整，公式／图像及条件齐全 | 核原页与卡片显示一致 |
| 补上下文后引用 | 核心内容可用，但需带入原列名、父主题、条件或原例示 | 明确列出原上下文引用及继承方式 |
| 需重组 | 多块／多源共同构成一个可理解记忆对象 | 顺序、比较维度、共同前提和来源逐项可追溯 |
| 需轻量整理 | 原内容过长、表达或组织需少量补充 | 补充内容与原引文分开，先审语义，不能暗改公式 |
| 暂缓 | 来源有疑点、缺图／图不清、重组后仍不可理解或条件不确定 | 记录具体问题与恢复证据，不以占位内容进入样板 |

整图保留、长图查看、总览关联等作为展示处理字段，可与上述主结论组合；不能把“必须整图保留”误标成不可学习。含已标答案的原图可以用于明确的知识讲解卡，但不得因此称为独立答题材料。

## 特别检查

- 公式卡：保留原nodes优先路径及content后备路径；文本空格、分隔符和括号可能影响轻量解析，不能预先统一清洗。表格引用需区分原单元格坐标与投影坐标。
- 方法卡：识别信号、适用条件和处理方向要共同可见。一般归因／对比实验／直接根本原因等按实际论证结构审，不只抽标题和术语。
- 言语卡：具体词义对照与短语境共同组织；常见搭配不自动变排他用法；字典／专业口径待核项保留局部暂缓。
- 图推卡：检查方法与原图是否对应，示意图、图组和父节点说明不能拆散；无清晰图片时仅可保留确能独立理解的文字知识，否则暂缓。
- 原应用：可作为关联阅读例示，保留原来源性质与完整任务；本批不新增题、不自动修复3道V4原应用的选项／核源hold。
