## P2有限样板约束

先由P1确认可用来源，再覆盖这些结构：单公式及条件；结构化公式与文本公式；表格cellNodes及行组继承；方法体系总览与关联子卡；言语具体对照；图推原配图与观察方法；多源关联及原应用返回。一个样板可同时覆盖多个结构，不按五科配额堆数量。
