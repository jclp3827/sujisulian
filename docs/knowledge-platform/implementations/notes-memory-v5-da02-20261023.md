## 切片与重组规则的实际应用

- 精确公式和符号优先：增长量只取两条精确关系及正负提醒；间隔增长保留乘积项和下降符号；年均增长保留n的间隔含义；基期比重保留修正项角色和给定条件。不纳入固定百分比阈值的误差保证。
- 方法识别保留共同背景：年平均量／年均增长量保留两公式和完整对照；年均量／率对照按问法、答案单位和复合关系识别，不要求再默写基础卡公式。两者目标有实质区分，不能按同来源或出现公式就视作重复。
- 单位与口径保留原四项完整清单；百分点取概念、信号及左右对照，不取“任意两数相除才是增长率”。数字仅作为原解释，不要求计算。
- 混合增长限定两部分、互不重叠和正基期；必要前提明确写在作者提示中，作为待审补充语，不冒充原文。多方“最靠近最大权重方”捷径不带入。
- 容斥拆为“最大交集”基础记忆与“占比和超过100%的充分信号”方法判断；共同总体条件保留。最小值缺非负截断的问题片段及原例题不带入。
- 原JSON、nodes／content／cellNodes、结构和渲染组件保持原样。新文件仅保存目标与引用，冻结包用于对照，不作为第二正文权威；没有新增选择题或完整题应用。
