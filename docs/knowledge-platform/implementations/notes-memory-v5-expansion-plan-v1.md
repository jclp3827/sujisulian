1. 冻结原源和按条分类观察：确认错误／需限定／排版／待核；范围定位至块或子路径。没有既有观察不代表语义批准。
2. 选目标与原引用组合：公式带角色、条件；方法带信号、范围和对照；词表带表头、词义／误用两侧；导图带父主题和必要图像。先复用已有样板，不以改标题制造重复。
3. 编写引用草稿与回忆提示，原文字／公式只引用不抄改；提示、连接语和组合理由单列。基本公式可记忆，不让基础快记做具体计算。原有数值讲解与新计算题分开。
4. 内容核验和共用展示检查分开记录。开发候选、独立审阅、正式准入各有状态；保存失败、版本历史、原生返回、按钮操作、全量逐卡入口沿用现有能力。
5. 应用题仅从笔记已有完整题目承接，沿原题目导入／origin及曝光链路，保留材料、选项、答案、解析和来源标签；不凭笔记例题字样认定真题。题源或答案未决的原hold仍局部暂缓。
6. 模块交付报告分别列来源数、目标草稿、重复复用、待核、开发可达与正式批准数。原知识未用作卡片的部分留在正文，不为了覆盖率删内容或乱切。

数量批重点是公式前提和等时／等距等方法边界；判断批先方法总览再关联子卡；言语批按具体对照与必要语境；图推批必须图文共同理解。原logic3个图形来源保留原身份，未有精确主归属与导航证据时只暂缓对应组合。首批采用单来源重组，多来源逐项导航另作局部补证，不默认第一来源足以覆盖所有引用。
