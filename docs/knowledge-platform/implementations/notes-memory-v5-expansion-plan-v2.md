## 一、目标与内容边界

笔记承载系统精炼的行测知识，目标是理清结构、关联、快速回忆、易混易忘复习，再以原题应用。基础快记主要记具体关系／公式／概念和必要条件，不要求数值解题；方法判断识别信号、适用范围和具体方法差异，允许公式／概念的对照。分类按目标，资料／数量不是只能基础，出现公式也不自动归基础。图推统一方法判断，保留理解所依赖的原图。

考前速记只是同一批卡片的弱项路线，不另造内容。完整题应用作为首页独立入口保留，使用笔记已有完整题目，判分／解析／历史及原题曝光沿原链路。原文只保留原知识与既有技能训练；卡片只有查看原文，通过顶部原生返回；所有换卡由按钮操作，滚动不换卡。

原JSON与原轻量公式组件仍为权威，保留nodes／content／cellNodes、表头、父主题、对照和必要前提。卡片只存精确原引用与编写字段；新增说明和提示单列核验。不以原样引用替代正确性核查，不静默更正原源。

## 二、来源处置与0..N目标模型

来源工作单元是盘点／核源单位，卡片目标是记忆单位，两者分开：一个来源可零卡、多卡、复用已有目标或合并；一原块也可承担不同目标。没有固定卡片配额，来源和行数不作为卡片数。当前首批仍采用单来源组合，多来源导航与跨科绑定没有证据时只暂缓对应组合。

- 编写范围先冻结batchId、主模块及来源workUnitIds，不能由草稿自己声明越界来源。
- 来源处置台账必须覆盖该范围每个来源，状态为目标已提出／仅正文／复用／合并／暂缓；需要理由、关联目标或去向及必要恢复条件。
- 每个目标有稳定targetId，卡片有稳定id／revision、workUnitIds、kind、目标、归类理由、原引用及作者身份。来源任务反查subject／point／category，实际refs必须指向对应原源和允许原块。
- 来源台账的targetIds与实际目标关系必须一致；允许一源多目标，不以重复workUnit本身判错；遗漏来源处置或伪造来源匹配会失败。
- 旧来源级分类保留为historicalSourceKindHint，不是准入依据；targetClassifications记录当前目标的类型与理由，同一来源可有不同类型目标。
- 标题不同不等于目标不同；设计需登记重复、复用或不同目标的实质理由，独立审阅继续核实目标及组合，而非只检查ID或摘要。

“无既有来源观察”不等于内容通过。已知问题按具体块／目标暂缓；不依赖问题片段的其他组合可继续核源，不将整个模块冻结。

## 三、完整题应用独立工作账

本版逐一登记218份原example素材，沿既有sourceExampleRecordId定位原JSON／页签／块及摘要，不用块序号或新标题替代运行题身份。每项关联既有问题版本、当前开发可用题、原hold和历史来源警示；模块交付必须报告去向，不再只写一句“从原题承接”。另登记9份非knowledge页签image-note材料，当前不是题目，须核完整任务后决定用途；讲解图不能冒称未标答案的独立测试。

每项原题应分到：保留既有开发题、可导入待核、仅讲解、重复合并、缺题干／选项／答案／材料、核源hold等有证据的去向。当前字段中的待核类别只是工作队列，不是语义结论或导入授权。

应用任务必核完整题干、材料组与图、选项、答案、解析、每项干扰依据、实际考查目标和考试来源性质；不凭“真题示例”字样认定真题。不合格原题保留原文／讲解或局部hold，不用自编题替代并冒称原题。导入沿原origin、曝光与作答历史、V4精确版本决策链路；旧3道应用hold与旧22草稿不自动放行。新卡片不能继承旧选择题接受回执。

每模块在机器清单中有上述阶段与独立证据路径。按卡片版本局部通过，未决项只阻断对应范围；不能用草稿数或原8张样板通过的检查替代新内容消费验收。模块报告分别列来源、目标、复用／合并、hold、开发可达、内容接受、正式准入、设备和发布，不用单一“已完成”覆盖全部阶段。

独立回执应有审阅者种类和任务身份、作者身份、规则版本、源摘要、实质检查、结果、问题及时间。记忆卡另绑定cardId、targetId、revision、learningSemanticDigest；应用题沿原questionId、revision、effectiveContentDigest、原例题身份／摘要与曝光组。revise产生新版本重新核；reject/hold不能由普通字段改成accepted；代理审阅如实标注代理，不冒充人工。正式启用授权及发布与内容接受分开，不因本轮计划优化制造回执。

## 五、学习版本稳定性工程（EXP-A05，待G0实施）

源快照摘要证明引用准确，学习语义摘要决定评价能否继承，二者不能混为一个版本。G0须在保留原源校验的同时，按所选知识、回忆提示、目标和必要语义依赖计算学习版本，排除未引用块和纯展示元信息。源快照失效时先关闭对应内容，明确更新引用并复核所选依赖后再恢复，不静默重写源摘要或接受凭证。

必做回归：未引用块修改不改变未变卡片的学习版本；纯展示修改保留评价；所选知识／条件／提示实质变化才待重新评估；旧评分历史不删；冻结轮次与弱项仅影响对应卡；读取／保存失败不覆盖记录。此处是已排定的工程任务，**本轮没有修改运行中的semanticVersion或迁移既有评价**。
