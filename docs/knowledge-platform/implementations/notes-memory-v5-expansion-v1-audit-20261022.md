## 需要修正的6项P2

### EXP-A01：来源工作单元和候选卡片仍被强制一一对应

依据：产品定义34行：一原块可有多目标组合；来源数不作为卡数配额。定位：[相关文件](/Users/jmac/.codex/worktrees/notes-learning-exploration/miniprogram-1/scripts/validate-notes-memory-expansion-drafts.js:8)。

cards.length必须等于allowed.size。隔离增加第9个同来源待审目标后直接以9!==8拒绝，尚未进入目标独立性或重复审阅。

影响：后续不能自然表达一个来源零卡、多卡、合并到其他来源或整体暂缓；与方案不按来源数凑量的规则冲突。

最小修正：将来源处置台账与目标候选表拆开；来源记录0..N候选／复用／合并／暂缓／仅正文，每个候选有独立稳定目标身份。验证来源处置覆盖，不固定卡片数量。

停止范围：扩大草稿生成前修正模型；不阻塞既有源核对。

### EXP-A02：工作单元只验标识存在，未绑定实际来源和目标类型

依据：目标与原源、实际归属及来源版本必须可追溯。定位：[相关文件](/Users/jmac/.codex/worktrees/notes-learning-exploration/miniprogram-1/scripts/validate-notes-memory-expansion-drafts.js:10)。

将拉动贡献率草稿换为不在首批范围内的基期量原引用、保留原workUnitId，仍passed；漏记一个任务改成重复标识仍passed；kind改非法枚举也passed。

影响：摘要正确不能证明在约定范围内，也不能保证每个来源任务有处置；错误标签可被当作有效模块交付。

最小修正：workUnitId反查sourceIdentity/primaryModule/category并核每个ref允许范围；kind只许basic/method、图推强制method；用来源处置台账核全覆盖，允许合法一源多目标，不把重复workUnit本身一概判错。

停止范围：扩大自动生成前补机械校验，不要求人工审核这些字段。

### EXP-A03：草稿之后的接入、独立回执与模块验收没有排成执行子批

依据：产品定义82、94、98行：版本弱项、逐ID可达和精确内容准入分别有证据。定位：[相关文件](/Users/jmac/.codex/worktrees/notes-learning-exploration/miniprogram-1/docs/knowledge-platform/implementations/notes-memory-v5-expansion-plan-v1.md:26)。

方案仅声明开发候选／审核／准入分开；exitRule只退出来源设计。现build-notes-memory.js只构建固定samples，memory-content.js只消费开发sampleOnly+preview-pending，尚无新模块候选注册或正式卡消费路径。

影响：可以不断完成草稿，却没有约定何时及如何成为可审、可用内容；现8张样板检查不能代替后续新增卡片验收。

最小修正：补接入基础子批：候选注册→逐卡冻结评审包→独立回执绑定cardId/revision/语义及原源摘要→按结果修订/暂缓→准入编译→全部/科目/专题逐ID可达、原生回源、弱项/版本更新回归。区分设计完成、开发接入、正式准入和发布完成。可沿用成熟治理模式，不能由作者换名自签。

停止范围：不阻塞受控草稿；开发/正式接入前须补契约和退出证据。

### EXP-A04：完整题应用只有承接原则，没有原题逐项任务与覆盖账

依据：首页四个入口中的完整题应用独立保留，使用笔记已有题目。定位：[相关文件](/Users/jmac/.codex/worktrees/notes-learning-exploration/miniprogram-1/docs/knowledge-platform/implementations/notes-memory-v5-expansion-plan-v1.md:27)。

影响：五模块知识草稿即使全部完成，也不能据此宣称应用题扩充完成；容易再次只建设记忆卡。

最小修正：每模块增加原应用承接子任务：关联原身份、已导入、可导入、仅讲解、重复、缺材料/任务、核源hold，保留origin/曝光/历史；或明确本版只扩记忆，并为应用给独立后续批次。218只是素材块，不是218道合格真题。

### EXP-A05：学习语义版本被同页签无关原块的展示修改牵连

依据：产品定义82行：只暂停受影响卡，纯展示变化不清空评价。定位：[相关文件](/Users/jmac/.codex/worktrees/notes-learning-exploration/miniprogram-1/miniprogram/subpackages/note/services/memory-content.js:13)。

影响：后续源维护会让未变卡片无谓失效，并把旧弱项转入更新待评；并非删除历史，但会干扰用户已记录的记忆状态。

最小修正：保留原源快照校验，分开计算学习语义版本：只包括选中知识、提示与必要语义依赖，展示元信息另记。补无关块/纯展示不改评价，所选知识实变才更新的回归。

停止范围：涉及原文维护和接入新版本之前修复；不阻塞只读核源。

### EXP-A06：平均类方法卡的提示超出引用能独立回答的范围

依据：产品定义39、61行：方法有核心做法，提示唤起具体对象。定位：[相关文件](/Users/jmac/.codex/worktrees/notes-learning-exploration/miniprogram-1/docs/knowledge-platform/content/notes/memory-v5-da01-drafts.json:18)。

最小修正：收窄提示与目标为已有的口径核对要点并重新核定归属，或补可追溯的具体表达/短例并独立核验；补齐前对此卡局部返工，不冻结其他草稿。

停止范围：该卡进入待审接入前返工。
