## 1. 用户目标与本期边界

用户应能：按体系找到知识；先回忆再揭晓、阅读原知识；看清方法适用范围及相近方法差别；对当前卡片作四项自评；针对模糊和没想起的卡片再记一轮；随时查看原文，并通过原页承接例题及既有训练。

定义阶段交付产品定义、原内容适配审计、有限样板和闭环工程规格；此后开发草稿依据独立的模块扩充批次。样板仅选择既有来源验证表达与交互，不作为批量扩充，不编造新题、口诀、配图或释义。原50份JSON正文、训练、政治、常识与真实用户记录保持原归属。提交、合并、上传、发布不随文档完成自动发生。

## 2. 首页及内容分工

首页顺序：搜索 → 全部笔记 → 基础快记／方法判断／考前速记／完整题应用。基础入口正式更名为基础快记，以副说明明确“公式与知识记忆”“方法识别与适用辨析”；前三项以知识卡呈现；完整题应用为独立做题入口，沿用笔记已有题目的选答、判分、解析及原答题记录。图推统一放入方法判断。

| 入口／位置 | 目的与内容 | 主要呈现 |
|---|---|---|
| 基础快记 | 直接回忆具体公式、符号、定义及必要条件；资料、数量为重点 | 公式／知识卡；不计算具体结果 |
| 方法判断 | 识别信号、适用范围、关键做法、方法间区别；判断、言语为重点 | 方法卡、对照卡、必要的短例示；不要求选择选项 |
| 图推内容 | 图文共同呈现观察信号、方法、顺序和边界 | 统一纳入方法判断；依赖图的知识必须同时保留原配图 |
| 考前速记 | 定向再回忆当前范围内“没想起／有点模糊”的已有卡片 | 同一批卡片的状态筛选路线，不是第三份内容库 |
| 完整题应用（首页独立入口） | 用笔记已有题目检验完整解题能力 | 使用既有practice application链路，保留题源、判分、解析和历史；不改成记忆卡 |
| 原知识页的应用／训练入口 | 承接已有完整例题、讲解与训练 | 与首页完整题应用并存，保留原任务及来源性质 |

两类记忆内容按目标归属，科目只表示侧重。判断的逻辑公式可入基础，数量的等时／等距平均速度区别可入方法。一个记忆对象保留稳定身份；同一张卡可出现在不同筛选路线中，不复制成多个学习记录。只有记忆目标确实不同才建立不同卡片，必要时关联同组。

全部笔记继续采用科目／专题／知识点定位，保留现有五科及原来源身份。图推中的原logic来源不改名搬家，继续显式记录主学习归属与原文位置。

## 3. 切片与重组的产品单位

卡片的单位是“能独立理解、回忆并用于辨别的最小完整知识组合”。一个原块可产生多个候选组合，一张卡也可引用多个块或来源；二者都需语义审阅，不按句数、表格行数或知识点数计算合格卡片量。

| 内容 | 必须共同保留的要素 |
|---|---|
| 公式 | 所求／量的角色、原公式、必要符号定义、使用条件、关键易错点 |
| 方法 | 对象与识别信号、适用范围、核心做法；理解需要时附原短例或原图 |
| 易混对照 | 共同背景、比较维度、两侧内容、适用差别；不把两侧拆成互不关联的卡 |
| 表格切行 | 原列名、必要组名／继承内容、单元格公式结构、相邻对照依赖 |
| 导图分支 | 父级主题与必要前提、当前分支、相关兄弟区别、配图与说明 |
| 图推 | 原图及可读性、观察对象、观察方法及边界；长图／整组对照按完整组合处理 |

复杂方法体系采用“总览 → 关联方法卡组 → 原应用”组织。如归因内容先保留结构总览，再组织具体方法的适用范围、削弱／加强方向及例示；只抽术语释义或孤立一句口诀不算语义完整。

卡面允许必要滚动，不强求每张内容压到一屏。默认突出当前记忆对象，展开补充背景和关联总览；不能通过折叠隐藏理解所必需的条件。长图允许查看完整原图，返回时保留当前卡片和阅读位置。

### 3.1 简洁提问（NOTE-V5-016，2026-10-23用户明确补充）

快闪卡用简短、可理解的单一核心问题唤起知识，不写成多小问或作答清单。直接问“某公式是什么”“两者有什么区别”“什么条件适用”；不在提问中提前罗列分子、分母、是否含1倍等答案维度。必要的共同背景或会改变答案的前提仍须保留，其余说明、对照和公式在揭晓的原知识组合中呈现。

用户指定示例：

- “是几倍与增长几倍的区别”。
- “拉动增长率与增量贡献率怎样区分？”。

扩充时逐卡核提问对象明确、单一目标、无多余追问、不提前提示答案、必要条件未被删。不能只靠字数判断好坏，也不为凑短问法把知识切碎；精确公式、必要符号定义、共同背景和对照内容仍完整保留在揭晓内容。已有提示发生修改，按现有revision／学习语义／注册规则更新，保留旧版本对照包和用户学习历史，不继承旧版本反馈为新版批准。该规则不改卡片schema、存储、判分或公共UI接口。

### 3.2 主知识与补充内容（NOTE-V5-017，2026-10-23用户明确纠正）

回忆提示、目标归类须与揭晓知识的主体一致。先确定卡片主要帮助回忆的公式、概念或方法，再选择提问；附加阈值、速算建议、易错提醒只作主知识补充，不能为了造题将其提升为主目标。增长量公式卡问增长量怎样计算，不能因附有10%判断而改问是否超过10%。若同一主知识已有活动卡，优先复用或归并，不用等价公式、标题差异或补充段再造重复学习记录。保留原公式、补充原文、稳定ID及历史；归并入口不可自动迁移旧评价为另一张卡的掌握状态。

## 4. 原内容、原样式与公式

原JSON及其单向构建仍为正文权威。卡片仅记录引用选择、组成顺序、记忆提示和必要补充语，不另存一套人工抄写的公式或正文作为第二权威。构建得到的投影必须能追溯回原引用，不能在运行包直接修正文。

公式继续使用现有`math-formula`：优先保留原`nodes`，文本公式沿用原`content`及原解析路径；原`cellNodes`、上下标、括号、分式和符号说明一并保留。不能统一转成纯文本／另一套公式语言重新渲染，也不能任意清洗空格后假定效果相同。

公式、表格、对照、导图、富文本强调及图片处理优先从详情页提取为正文和卡片共用展示能力，保留原视觉语法。当前`note-presentation`只承担部分页签展示映射，不是现成卡片渲染器；不能复制整页控制器生成第二套处理逻辑。

引用身份至少包含原subject／point／tab、原块及子路径、对应源摘要和必要上下文依赖。表格重排的展示坐标与原单元格坐标分开；数量例题的合并展示页签不改变原来源位置。补充标题、提示、连接语需区别于原引文并单独审阅。原文有疑点时局部暂缓，不因直接引用获得准入。

## 5. 回忆、按钮及四项反馈

页面采用上方进度、中间卡片、下方操作按钮。新轮次默认先呈现回忆提示，再揭晓原知识组合并自评；回忆提示须能唤起具体对象，不以模糊教学标签作题。按用户最新反馈，卡片下方仅保留一个“查看原文”，不再展示看原例题、常驻图片重试或浏览／回忆模式切换。原有开发浏览轮次可恢复其历史状态，新轮次统一回忆。只有图片实际加载失败时局部显示重试，不能把故障控制常驻为学习入口。

按入口分别恢复上次科目／专题及未完成轮次，空范围也保存选择；显式卡片／原文链接使用其指定范围。卡片阅读位置按轮次与卡片保存，目录滚动单独处理，不串到卡面。原文往返和恢复后立即离开均保留已存位置；存储读取失败可直接重试，不清除原记录。

取消所有手势换卡监听。横向浏览公式／表格、纵向阅读都只滚动，不改变卡片。卡片推进由揭晓、四项自评、跳过等按钮操作；回看使用“上一张”按钮，回看不改变既有自评，返回保留本轮揭晓状态。四项反馈在完整内容已展示后可用，点击反馈后保存成功再进入下一张；保存失败停留并提示重试。浏览反馈记录为学习后自评，回忆反馈记录为回忆后自评，均不能称客观掌握或独立答对。

| 反馈 | 当前卡片状态 | 对已有弱项的影响 |
|---|---|---|
| 记住了 | 更新为当前版本的记住自评 | 移出后续弱项筛选；历史保留 |
| 有点模糊 | 更新为当前版本的模糊自评 | 进入或保留弱项 |
| 没想起 | 更新为当前版本的没想起自评 | 进入或保留优先弱项 |
| 跳过 | 本次未评估，独立记录跳过事件 | 不覆盖上一次有效自评，不清除已有弱项 |

只看卡片、揭晓、滚动、点击上一张或返回原文均不更新记忆评价；所有四项反馈由用户明确触发。返回前一张可更正本轮自评，以后一次有效事件更新当前状态，保留历史并避免重复累计。不同卡片及不同语义版本的反馈不可串用。

## 6. 考前速记规则

默认范围沿用上次所选科目／专题，首次为全部；界面显示筛选范围和可复习数量。只取该范围中当前可用且版本匹配的“没想起／有点模糊”，按没想起优先、再模糊，同级按上次有效自评较早者优先，稳定身份作排序兜底。

开始时冻结当前一轮的卡片ID、语义版本和顺序，按同一身份去重，不按题族隐藏不同目标。新变弱的卡片在下一轮加入；本轮重评影响后续筛选，不在当前轮无限插入。记住后移出下一轮弱项，模糊／没想起仍保留，跳过不清除弱项。结束显示本轮自评、剩余弱项和“再记一轮／返回”；无弱项时显示空态，可去浏览全部卡片，不擅自混入未评估卡或生成新内容。

薄弱状态跨会话保存，不限于当前题组的临时回看清单。内容实质变更后，旧版本评价保留为历史，新版本为待重新评估；旧弱项在考前速记入口单列“内容已更新，待重新评估”提示区，可跳入新版浏览／回忆并重新自评；新版未评估内容不混入当前弱项轮次，取得有效自评后才按该状态进入下一轮或移出提示区，不假装已记住。已冻结轮次只暂停受影响卡，明确显示原因，无关卡可继续。样式、字体等纯展示变化不清空评价。

首期只采用明确状态筛选和再回忆；不增加掌握预测、自动判分、间隔重复算法或推送承诺。

## 7. 回源、应用与历史状态

卡片用单一“查看原文”定位当前主来源的原知识及页签，引用清单保留各组成部分溯源。当前8张样板各为单来源组合；多来源逐项导航暂缓，不以单按钮假装可逐项查看多来源。使用小程序顶部原生返回键回到原卡片，恢复位置、揭晓和反馈状态。正文页不再增加返回记忆卡／返回练习按钮或知识点／专题练习入口；原知识页签及技能训练保持原有功能。首页完整题应用继续独立承接已有题目测试；原例题及训练也可从原文页进入。卡片下方只保留查看原文的简化要求，不取消首页应用题板块。应用／训练继续使用原有记录，不与卡片自评互相覆盖；查看原例题涉及答案曝光时继续保留既有曝光记录。

V5卡片状态使用笔记独立命名空间，稳定cardId＋语义版本为评价对象。原V4选择题作答、assisted、曝光、偏好、历史会话完整保留；不把选对或看过自动迁成“记住了”。旧选择题会话链接应能识别并给出明确的历史／返回入口，不能静默当新卡片会话恢复。

## 8. 全量可见、准入与旧候选
