# 工程原文来源兼容修订建议（仅设计，待协调）

唯一目标：修正quantity/work-efficiency的knowledge块4最后一句，保持当前显示卡片的知识内容、稳定ID、原学习记录及判分协议。

原句：“剩余任务再除以剩余人员的效率和，得到剩余合作时间或某人的总工作时间。”

建议：“剩余任务除以剩余人员效率和，得到后续阶段时间；若求某人的累计工作时间，还须加上该人在此前各阶段实际工作时间。”

当前批次已经让注册工程卡只引用正确的原块3/8/9，旧样板引用0/2/3；两卡均不选错误块4。模拟替换原句并显式刷新两卡来源证明时，两卡projectedBlocks、learningSemanticDigest、semanticVersion均保持相同，而sourceSnapshotDigest必变。[精确只读对照](evidence/ME-REVIEW-02-work-source-migration-proposal.json)保留当前与建议的页签摘要及计算结果。这是可行性证据，不是已经完成迁移。

停止原因：普通批次必须保持既有准入／来源／存储／判分协议。G0将8张旧样板及兼容基线定义为不可改写，并校验整页来源摘要；就地修改会使旧样板和工程卡精确来源失效。不能跳过校验、伪造旧摘要、删样板或覆盖历史证据。

建议独立安排NOTE-G0-SOURCE-01兼容修订批次，范围仅这一处来源更新和必要的版本基线支持：

1. 保存旧样板定义、旧兼容基线、旧来源与G0证明原字节；记录新旧来源关系及这一句的内容纠错事实。
2. 明确采用新的当前来源基线，而非改写历史冻结事实。任何受影响的守卫/生成器实现变更先列出精确文件与新规则，单独复核；不放宽其他样板或候选的精确来源要求。
3. 当前工程注册卡按新来源追加注册与独立复核；旧决定和旧冻结包保留。旧样板在已定义的迁移规则下取得新的精确来源证明，稳定ID与已学知识身份保持。
4. 独立验证投影与学习摘要未变、旧自评/弱项/未完轮次/应用历史可恢复、错误来源无法绕过准入，以及新旧来源基线版本可明确辨别。重新取得受影响G0证明；不覆盖旧证明。
5. 只在内容、兼容、生成与回归门通过后写回当前worktree；不自动正式启用、提交、合并、推送、上传或发布。

本建议未实施任何协议或G0修改。需要用户裁定的是：是否允许进入这个单独的旧样板来源兼容修订批次；不是请用户判断公式事实，也不是请用户重复测试原讲解示例。
