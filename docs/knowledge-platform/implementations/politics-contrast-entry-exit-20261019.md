# 易混起始页一致性与完成出口

日期：2026-10-19。分支：`codex/politics-body-home-optimization`。

## 授权与本轮决定

用户要求易混结束后可返回主页或开启新一组，解决返回原知识后的迷失感；起始页与辨析页需要统一样式。本轮替代历史“末组返回原知识”的完成出口，保留此前原文确认、再次辨析、自评等过程。

## 实现

- 起始页直接复用ContrastSurface，增加仅用于呈现的preview状态。预览与初判／边界／再辨使用同一知识标题双栏、字级、底色、边框及内边距；“本组知识／换一组”和一句流程说明位于同一组件内。预览不显示答案、原文要点或作答按钮，不改变已保存的阶段事实。
- 完成页主操作“开启新一组”，次操作“返回主页”，返回政治理论首页；不再转到原知识或知识图谱。
- 新组目标由路线计划统一投影，控制器直接消费目标。按既有推荐顺序寻找另一组，最后一组回到其他可用组，不重复当前组；补入仍然有效的正式辨析关系并过滤无效或重复项。
- 若确实没有其他可用组，只提供“返回主页”，不显示无效的新组操作。
- 开启新组进入初判第1步，使用新会话，原始作答、两侧查看状态不带入新组；不触碰其他学习路线进度。
- 清理起始页原有独立知识标题布局与失效样式。正式资料、全局token和发布状态保留。
