## 1. 已确认的产品决定

1. 政治首页当前动态主卡改为“每日练习”。活动中的快速了解、系统学习、考前速记和易混突破不再争夺主卡，而是在各自入口内直接显示恢复位置。
2. 首页所有学习进度只使用短文本，例如“已学习 12/72 节 · 继续当前小组”；不显示路线进度条，也不使用进度视觉暗示掌握程度。
3. 内容版本变化不再占用一张独立的“内容已更新”主卡。需要提示时，在每日练习卡内增加一行轻提示，并让失效的旧会话按新内容安全重建。
4. “理解应用题专项”是内部内容建设与共享题目能力，不是新的首页板块。
5. 理解应用题主要由“每日练习”消费；“一问一答”作为每日练习内的二级自主练习能力，不与四个既有学习模块并列占据首页。
6. 快速了解不答题；考前速记继续使用主动回忆卡；易混突破继续使用完整的初判、对照、复辨流程。系统学习只可显式引用与当前小节精确对应的一道应用题，不自动把全部教学单元题库化。

## 2. 产品定位

| 能力 | 用户要解决的问题 | 内容责任 |
|---|---|---|
| 快速了解 | 这个知识体系大致讲什么 | 用最短路径建立全貌，不承担测试 |
| 系统学习 | 知识为什么这样组织、彼此怎样连接 | 围绕小目标连续解释，保持深度和边界 |
| 考前速记 | 我能否主动恢复关键表述 | 使用回忆卡，不改造成选择题流 |
| 易混突破 | 相近知识到底差在哪里 | 使用完整 ContrastPair，不拆散为普通题 |
| 每日练习 | 今天最值得练哪一小组 | 编排新知、到期回顾和个人待回顾 |
| 一问一答 | 我还想按主题继续练 | 复用同一题目与记录，由用户选择范围和题数 |

每日练习是跨题目来源的编排入口，不是第五份知识副本；一问一答是练习方式，不是新的知识路线。

常识候选实现已证明以下产品结构可以成立：

## 4. 首页与入口合同

### 4.1 每日练习主卡

主卡只根据真实会话状态展示一种动作：

| 状态 | 标题与辅助信息 | 主动作 |
|---|---|---|
| 首次或今日未开始 | 每日练习；今天练一小组，最多 5 题 | 开始今天的练习 |
| 今日未完成 | 今日已完成 `n/total` 题；显示当前小组名称 | 继续练习 |
| 今日已完成 | 今日练习已完成；显示答对数与待回顾数 | 查看结果 |
| 当前没有新题或到期回顾 | 今天暂没有需要安排的内容 | 按主题练习 |
| 内容更新导致旧组失效 | 每日练习；轻提示“内容已更新，本次使用新题” | 开始新题组 |
| 本地记录不可用 | 明确说明本次进度不能可靠保存 | 仍可浏览题目或稍后重试 |

卡片不显示百分比、环形进度或线性进度条。同日完成后不通过刷新、改范围或返回首页生成无限新组。

### 4.2 四个学习入口

四个入口始终保留，并直接显示简短恢复信息：

- 快速了解：`已完成 4/6 节 · 继续导读`
- 系统学习：`已学习 12/72 节 · 继续当前小组`
- 考前速记：`本轮 2/4 张 · 继续回忆`
- 易混突破：`已练 5/14 组 · 继续辨析`

这些数字只表达阅读或处理位置，不表达掌握率。进入动作继续由各模块自己的会话持有；首页不复制进度所有权。

### 4.3 一问一答的入口位置

第一版不在首页增加“一问一答”卡片，只在以下位置提供：

1. 每日练习完成页的“继续练几题”。
2. 每日练习设置或空态中的“按主题练习”。

一问一答可选择当前已开放范围、主题和 5/10/15 题；题目不足时显示实际数量，不重复补齐。未完成会话冻结顺序并可恢复。

## 5. 理解应用题内容合同

### 5.1 首批题型

首批目标为 24 道候选，不以数量配额强制凑题：

| 题型 | 目标数量 | 要验证的认知动作 |
|---|---:|---|
| 关系归类 | 8 | 判断多项表述各自承担什么职责、属于哪一层关系 |
| 条件变化 | 8 | 改变一个成立条件后，判断原结论是否仍成立 |
| 材料或情境判断 | 8 | 将简短材料映射到已学概念，并说明决定答案的线索 |

必要的核心确认题可以作为应用题组第一题，但不得把 136 张速记卡批量转换后冒充新题。

### 5.2 最小题目结构

每道候选至少登记：

- 稳定题目 ID、版本、审核状态与题型；
- 对应小节、主要知识目标和必要的辅助目标；
- 题干、选项、唯一正确答案；
- 答案解释、适用边界；
- 每个干扰项为什么错误；
- 直接支持答案的正文块 ID；
- 可返回的补救小节或正文位置；
- 难度、顺序和运行准入状态。

### 5.3 准入规则

候选只有同时满足以下条件才能进入运行题库：

1. 相比现有回忆卡增加了新的判断动作，而不是同义改写。
2. 在题干提供的语境内只有一个正确答案。
3. 每个干扰项都有来源支持的错误理由。
4. 解释和边界可以回到当前正式正文块，不依赖范围外时政或临时常识。
5. 不通过文字陷阱、绝对化修辞或生僻细节制造难度。
6. 与速记卡、易混组和系统学习自测的重复有明确学习阶段理由。

## 6. 每日编排规则

每日题组为 3—5 道的目标，不强制补满：

1. 先选 0—2 道到期回顾。答错、直接揭晓或主动标记再看的题可以进入；普通跳过不自动推定不会。
2. 再选一个新知识组，包含 2—3 道围绕同一小目标递进的题。
3. 推荐顺序为“必要关系确认 → 条件或边界变化 → 材料情境判断”；某目标不适合其中一步时可以缩短，不造题补齐。
4. 同一每日组内错误纠正题最多一题，同一知识目标不以不同措辞重复评分。
5. 选择全部范围时在两篇当前内容之间轮换；指定范围时只从该范围选择。
6. 以北京时间日期冻结当天组。跨日仍未完成时先恢复旧组，完成后才建立当天组。
7. 没有新组且没有到期回顾时显示真实空态，并提供按主题练习，不提前抽取未到期题目。

## 7. 与现有模块的投影边界

| 模块 | 是否消费理解应用题 | 规则 |
|---|---|---|
| 快速了解 | 否 | 保持连续导读，不增加答题门槛 |
| 系统学习 | 有条件 | 只有精确映射当前小节且比现有自测更合适时，显式替换或引用一题；仍可跳过、不计掌握 |
| 考前速记 | 否 | 保持主动回忆，不混入选择题 |
| 易混突破 | 否 | 保持完整 ContrastPair，不拆成普通题 |
| 每日练习 | 是 | 主消费入口，按新知与到期回顾编排 |
| 一问一答 | 是 | 自主连续练习，复用同一题目与记录 |

用户在每日练习答错某个易混目标时，可以被引导回完整易混突破；这是补救链接，不是复制易混题。

## 9. 首版开放与停止条件

### 9.1 首版开放条件

每日练习主卡进入首页前至少满足：

- 形成不少于 6 个完整新知识组，每组 2—3 道；
- 当前两篇内容均有真实可用组，不把单一分支描述成全范围；
- 每题通过来源、唯一答案、干扰项、重复和补救落点检查；
- 同日冻结、跨日恢复、到期回顾、内容更新与存储失败通过运行检查；
- 现有四模块的会话与入口恢复不被重置。

数量不足时可以继续保持首页筹备入口或真实空态，不以低质量题补齐。

### 9.2 内容扩库停止条件

每批最多审核 12 道。出现以下任一情况时停止对应方向并登记拒绝原因：

- 单批合格少于 3 道；
- 超过一半只是现有题换说法；
- 无法在当前来源内形成唯一答案；
- 新增内容继续集中为已经过量的错误纠正；
- 题目必须依赖范围外时政、未审核事实或新增完整课程才能成立。

新来源、正文修订、用户错误数据或新增知识目标可以作为以后重新打开扩库的事件；“尽可能多”不能覆盖质量与边界门禁。

### 9.3 实施停止条件

发生以下情况时停止依赖批次，不继续暴露入口：

- 题目评审制品与运行制品无法确定性对应；
- 每日记录会覆盖或误读快速了解、系统学习、速记或易混进度；
- 内容更新无法只失效受影响题目或会话；
- 首页为了显示每日练习而制造不可用主动作；
- 自动通过但真实页面无法完成答题、查看解释、回原文和返回恢复。
