# E3 主持与记录说明

日期：2026-10-22。当前验收：**按用户确认，抽样测试通过**。完整协议的逐题数据和24小时复测未提供；以下严格流程保留为后续可选验证，不再阻塞本轮抽样验收。对应[任务包](evidence/politics-exam-alignment-e3-tasks-20261022.json)，本文件含测试设计，不能整份提前发给参与者。

## 验证目标与边界

验证独立回忆、对新材料的概念/条件判断、至少24小时后的保持。题目均为自编诊断任务，不是真题；3—5人用于发现障碍，不估计普遍提分效果。范围是八个代表主题与九张新速记卡的补充抽样，不等于145卡、72节或完整考试的覆盖验收。快速了解是否形成全貌仍使用[B6第二节](politics-learning-content-b6-user-effectiveness-tasks-20261021.md#2-快速了解能否形成全貌)，不能用材料题成绩替代。

## 每名参与者如何进行

1. 主持人分配两个未练过的主题，记匿名编号、基础和实际运行版本。P01—P05只是排班槽位，不能登记为真人。每次建议预留约15分钟，实际耗时另记；不得为了完成八题要求每个人连学八个主题。
2. 可在学习前问对应回忆问题，原样记录为起点。这个起点只说明已有知识，不把旧版泄漏选项的答对率作为有效基线。没有同口径起点的结果不宣称提升量。
3. 进入分配的小目标学习；离开正文后先独立口头回忆，再逐题出示A材料。主持人先记录完整回答，随后再提示或讲解；不得在独立回答过程中逐句追问答案。
4. 仅出示该名参与者当前被分配的题干，不展示requiredMeanings，不提前展示B材料。若看过题干或参与过建设，标记exposed并停止将其作为未见材料样本；换题须先登记同目标新材料与评分点，不能临场随意改题后混算。
5. 约定至少24小时后的复测，记录即时与延迟作答的实际时间。先问期间是否复习，再提供B材料，不提前反馈A答案。B改变比较对象或条件，不能仅凭记得上次答案作答。
6. 如安排速记补充，每人额外抽一个序号范围，先口答再揭晓；延迟测同一范围的恢复，用另一份B材料测迁移，两类结果分开。无需每人背完九张新卡。
7. 只记录匿名编号和学习回答，不收姓名、联系方式。中途不想继续可结束；缺席、未到时间或材料暴露记not-tested，不算答错。

## 分配与覆盖

| 槽位（不是参与者） | 主题 |
| --- | --- |
| P01 | 两个结合、主要矛盾/主要方面 |
| P02 | 新时代变化/不变、量变/质变 |
| P03 | 四组表述、认识两次飞跃 |
| P04 | 现代化方式/阶段、生产力/生产关系 |
| P05 | 两个结合、生产力/生产关系，或优先复核已发现共同障碍 |

只有前三人时，标注实际覆盖六主题，其余两项待测；不能把未测试记为通过。A/B尚未做等难度校准，不直接用两份分数差计算学习增益或保持率。不同人不交流材料或答案。每个模块分别登记，不用一项材料判断正确代替快速了解全貌、速记恢复或易混原文交互的验收。

## 评分与记录

任务包的每题A/B评分点均须由题干明确提问。允许等义表达；固定表述的必要限定词不能遗漏。术语正确但比较对象、条件或材料理由错误不能算独立完成。提示/回看后才补出理由记prompted，保留首次原话；独立尝试仍未完成记failed。补问、答案反馈与自评均不得覆盖首次记录。

延迟记录必须包含真实间隔、B材料暴露情况和期间复习情况。复习后答对可记录，但不能当作无复习保持。八题A、八题B及九卡补充的结果都保持null，等待真人记录。

记录模板见[空白JSON](evidence/politics-exam-e3-observation-template-20261022.json)。每个attempt是一名参与者某一题某一阶段的记录；模板中的空数组和null不是实际参与者或测试结果。逐项填写任务包recordFields；criterionJudgments由主持人按语义人工判定，校验脚本不能自动判学习正确。

## 何时修订、何时停止

同一位置出现两名参与者同类障碍时，先复核题干、解释或交互；严重事实错误即使一例也暂停对应题。任务理解问题、概念遗漏、边界错误、材料线索误判和操作障碍分别记录，不平均成一个“掌握率”。样本、主题或延迟数据不足时，只交付已观察事实与缺失项。

缺少真实参与者、未到复测时间、材料已暴露、构建改变或缺少对应可靠来源时停止相应结论。版本改变须另记，禁止把不同题目版本的成绩直接合并。完成本准备包不授权提交、上传、发布，也不证明用户效果。
