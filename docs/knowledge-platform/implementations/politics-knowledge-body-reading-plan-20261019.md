## 1 产品结果与范围

正文应让首次阅读者看清知识如何展开，让已理解者通过扫描章节、关键判断与适用边界快速恢复理解。同一份完整正文同时承担这两种阅读速度，不新增速读与精读两套内容，也不把浏览或一次自评称为掌握。

本轮完成四件事：恢复真实章节层级；把重点落实到句内；让定义、关系、条件与对照获得合适版式；统一所有入口的正文表达。标签是否出现，以它能否帮助读者理解、判断或操作为准。

不包括新增知识摘要、自动生成重点、推断新关系、分页、隐藏普通正文、拆分知识实体、重建管理后台、改写四条学习路线、迁移常识和笔记、提交推送或发布。政治的 candidate、review、release=0 及 S6 状态不因本方案改变。

## 3 正文阅读规则

### 3.1 同一正文的三层表达

| 层次 | 表达方式 | 约束 |
|---|---|---|
| 文章骨架 | 页标题、小节、子节与嵌套目录 | 从正式标题或人工确认的结构标注生成；不以定义数量补目录，不按段落长度或编号正则猜章节 |
| 核心判断 | 完整句子中的必要关键词、关系词、判断条件 | 加粗关键判断；用克制的强调突出范围、否定与例外；重点固定呈现，全部文字持续可读 |
| 完整解释 | 连续段落、原有清单、表格、论证 | 保持可读字号与对比度，不折叠、不灰化，不用卡片把每段隔开 |

语义类型与重要程度分开。definition、conclusion 等类型不再自动意味着整块高亮；默认重点来自经过复核的句内标注。条件和例外无论是否标为重点，都必须持续可读。

篇首保留正式标题、路径和已有一句话理解；没有可靠摘要时省略。摘要不另配泛化标签或大色块。重复的整篇自标题只显示一次，但保留原块锚点映射。目录展示结构名称，不展示长段解释；一级主题全部展示，不限前三项；子节通过展开入口呈现，三级以内按真实归属缩进并使用层级编号，不伪造层级。

### 3.2 标题与句内强调

小节标题与正文在字重、字号和段前留白上形成稳定差异；标题后紧跟其正文。保持现有主题令牌与字号设置，长文正文基线沿用 34rpx 等价值，不低于上层规格要求。颜色不单独承担意义。

重点以能独立恢复正确判断为准。例如“量变达到一定程度必然引起质变”必须连同“达到一定程度”呈现，不能只突出“必然”。每段通常标一至两处作为编辑建议，不设机械字数或百分比门槛；多个必要条件必须一起保留。

2026-10-19 用户明确调整：经复核的句内重点是政治正文的固定产品表达，不提供关闭按钮，也不增加阅读模式。旧存储中的关闭偏好不再影响政治正文强调；不清除用户设置、不迁移其他模块。所有入口使用相同的重点，显示菜单继续提供字号设置。

### 3.3 内容形态

定义优先呈现为术语及完整解释；并列知识采用清单；真实先后步骤才使用编号路径；有正式比较维度与依据时使用对照。短定义不自动套卡，普通结论不自动染色。窄屏对照按同一维度上下配对，避免把 A 的全部内容与 B 的全部内容分别堆成两篇长文。

长段中的已有并列项通过人工标注原文起点拆成阅读行；引导语留在列表前，不按正则猜条目、不增删标点。短项可显式设为双列，窄屏和最大字号回到单列；长解释保持单列。行内重点帮助识别术语及判断条件，不能把整段重新涂成重点。

同篇的比较只引用现有块和原文片段，不生成另一份答案。没有可靠对应维度时先保留原文与边界，不为了凑表格创造结论。把散文重新编成对照的新增结构须进入样板编辑复核。

## 4 标签和管理信息处置表

| 信息或标签 | 业务意义 | 正文默认规则 | 交互及保留位置 |
|---|---|---|---|
| 知识标题、所属路径、小节名 | 建立位置和结构 | 保留；长路径弱化但完整可查看 | 目录跳到真实章节，保留原块锚点 |
| 定义、结论、理由、层级、步骤 | 内容分类元数据 | 默认不显示通用胶囊标签；由术语、标题、清单或路径表达 | 语义字段继续保留在源和运行时数据 |
| 条件、例外、范围、否定 | 决定判断正确性 | 保留实际条件和边界；仅在句意不自明时加“适用条件”“例外”等短提示 | 不折叠到关系面板，不只留一个“条件”标签 |
| 时间、实体、来源证据 | 可能是正文事实，也可能只是元数据 | 人物、日期、原文证据属于正文时完整保留；仅描述数据类型的“实体／证据”标签不显示 | 时间线和实体表达仅消费现有结构 |
| 易混、辨析、易混边界 | 提醒差异，可能影响正确理解 | 按第 5 节区分本地边界与可选跨篇比较 | 明确比较对象及维度，不能只留“易混”两个字 |
| 前置、相关、后续、关联线索 | 解释知识关系或后续去向 | 改成带目标的入口，如“先了解 唯物辩证法的总特征”“与量变质变规律有什么不同” | 点击先展开真实理由，再由明确原文入口跳转 |
| 关联理由 | 说明为何连接 | 展开区直接显示理由正文，不在每段前重复“关联理由”标签 | “查看联系／收起联系”使用真实展开态 |
| 知识延伸 | 可选补充，或已经属于原文 | 辅助投影移至阅读收口后；原文中的延伸段保留原位置 | 无正式分类依据时并入“相关知识”，不创造延伸类型 |
| 内容已终审、审核中、review、版本、协议、哈希、风险页、前置深度 | 编辑、构建与治理管理 | 普通正文不显示；不能把终审当作用户学习状态或可信度勋章 | 保留源、审计、调试追溯与发布控制；不新建管理后台 |
| 当前内容确有影响阅读的失效或不可用状态 | 影响用户能否继续 | 用一句可行动的说明，如“原文定位已失效，已打开完整正文” | 不因清理管理信息而移除访问限制、错误或真实风险告知 |
| 来源／反馈入口 | 已有调试与维护能力 | 延续已接受的普通正文不展示规则 | 保留底层来源绑定和既有调试能力，不新增学习入口 |
| 返回回忆题、返回搜索、当前学习步骤 | 任务上下文与操作 | 有真实任务时保留一条明确提示及最近一步返回 | 不堆叠多套返回栏，不重置题目与路线状态 |
| 已读、收藏、自评 | 用户自己发生的状态 | 原能力保留，在合适操作区展示 | 不由滚动到底、阅读时长或回忆一次推断掌握 |
| 本篇 N 处、关系 N 条 | 辅助统计 | 目录数量按真实小节计数；关系数量只用于多项展开入口 | 不用块数当章节数，不把数量当学习价值 |

术语内容与 UI 标签必须分开判断，例如“管理”如果是正式知识中的管理概念，不得当成后台信息删掉。治理只处理 UI 元信息及辅助投影，不按词匹配删除正文。静态标签不使用按钮样式；可点击项必须有动作、目标、展开态及无障碍名称。

## 5 易混与关联的出场规则

### 5.1 三种阅读职责

这里的阅读职责是辅助投影元数据，不改变 prerequisite、contrast、related 等正式关系类型。

| 职责 | 判定依据 | 位置和默认状态 |
|---|---|---|
| 本篇判断边界 localBoundary | 正式条件、例外或对照直接防止读者误解当前结论 | 原文持续可见；已有辅助边界在对应论述组末显示完整边界句，不隐藏在展开入口里 |
| 跨篇比较 crossPointComparison | 已有正式比较说明不同知识各自回答什么，但不是当前结论的成立条件 | 默认在本节结束或文末以概念对入口收起；点击查看完整差异与两侧原文 |
| 背景联系 background | 前置、相关或后续说明 | 默认放在文末相关知识；任务确有前置要求时可在入场显示一条真实前置入口 |

职责与位置由人工确认的阅读标注或明确任务上下文决定；不能依赖关键词、关系数量或“第一处证据块”自动决定。未标注的正式边界先保守保留原位完整展示，普通关系降为文末入口。缺少合法关系或依据时不生成关系提示。

u024 开头的“对立统一／量变质变／否定之否定回答不同问题”两组辅助比较归入跨篇比较，不在首段后默认展开。u024 主次矛盾与主次方面的区别、u025 量变引起质变的条件属于本篇理解边界，原文完整可见。正式正文中的易混块不能因辅助投影收起而被移动、删除或折叠。

### 5.2 展开和跳转

单项入口直接写目标与用途；多项入口写“相关知识 N 项”，展开后列出目标标题、既有类型的自然语言表达与完整理由。不临时生成短理由，不截掉决定含义的后半句。

点击展开不换知识，不写学习完成状态。用户点“查看某知识原文”后才按既有页面栈打开目标；有合法锚点则定位，无锚点到篇首。返回恢复原焦点、最近任务、展开项和阅读锚点。失效引用显示真实降级，不伪装成已定位。

同一处可以有多个合法边界；只合并容器，不机械限定为一条。可选关系采用一个局部展开组，避免每个段落后重复工具条。正文之后的主要学习收口仍是既有回忆／继续任务，普通探索放在其后。

### 5.3 去重与缺失处理

按关系 ID、比较 ID、方向、维度和证据锚点确定是否为同一辅助事实。重复入口可合并、全文默认只出现一次，但所有原文依据可达；同目标不同理由不可误删。正式正文原句不参与辅助内容去重。

已有正式 ContrastPair 才能作为易混路线中的比较对象。缺少对照数据的普通 contrast 关系可以显示“查看区别及原文”的关联预览，但不能伪造对照表、测试题或改变现有五组易混路线。

| 搜索结果 | 命中原文锚点、查询上下文及返回结果 | 搜索命中强调与教学重点可辨，离开搜索不污染长期重点标注 |

## 7 内容与运行时实施合同

### 7.1 唯一来源和最小扩展

以当前正式 Markdown 和既有块为唯一内容源。新增可选能力声明：源 frontmatter 使用 `reading_schema: 1`，运行时映射为 `readingSchema: 1`，并携带块级阅读标注；不改变现有数值型 `schemaVersion` 的表示方式，也不手改 generated 包。缺少该能力的内容继续完整降级阅读。

首轮采用紧跟 `kp:block-id` 的单行 JSON 注释承载标注，当前键白名单为 `heading`、`emphasis`、`relationPlacements`、`comparison`、`flow`。解析、校验、适配与四篇消费均已实现；第二轮补充 `flow` 原文分组及跨块标题父级校验。

```markdown
<!-- kp:block-id=b003 -->
<!-- kp:reading={"heading":{"level":1,"part":"text","quote":"1.量变和质变的区分标志：","occurrence":1},"emphasis":[{"part":"text","quote":"是否超出度的范围","occurrence":1,"role":"key"}]} -->
> [!condition]
> 1.量变和质变的区分标志：区分量变和质变的根本标志是事物变化是否超出度的范围。
```

`part` 指向解析后的 `payload.text`、`items/序号` 或 `rows/行序号/列序号`，数组序号从 0 开始；`occurrence` 从 1 开始，针对该 part 的原文按精确子串定位。禁止模糊匹配和全库同词替换。构建器生成范围和显示片段，片段拼回必须等于原始 part，包括标点、空格和换行。

| 标注 | 最小字段与约束 |
|---|---|
| heading | level 为 1 至 3，part、quote、occurrence 必须有效；一个块最多一个标题；同块标题片段只渲染一次，余文原序保留；标题级差与父节归属必须校验 |
| flow | kind=list，starts 为按原文先后排列的精确 part=text、quote、occurrence 选择器；columns 可选 1 或 2。起点不得重叠、逆序或切断标题／强调片段；未覆盖的前导原文完整保留。投影分组拼回必须等于原始 textRuns；运行时非法分组退回原文 |
| emphasis | 精确片段选择器，加 role=key 或 boundary；同一 part 内范围不得重叠；未知角色、空匹配、多义定位失败均报错 |
| relationPlacements | 每项含 relationId、readingRole、placement；placement 为 section-end 或 footer，本地边界须 section-end；标注放在合法论述组的最后一个正式块，关联关系及证据必须属于本篇；不改变证据锚点本身 |
| comparison | 只用于同篇经过编辑确认的对照，含稳定 groupId、rows；每行含 dimension 和两个单元，每个单元为 roleLabel、blockId、part、quote、occurrence；只引用本篇原文，没有复制正文值；显示在拥有该标注的原始边界块位置 |

heading/roleLabel/dimension 的新表述只允许结构性命名；含新增知识解释的文字需要内容审核。本轮优先复用原文已有名称。comparison 是已有块的阅读投影，不创建新 KnowledgeUnit、Atom 或跨篇 ContrastPair；原有块保持完整原序可读，对照不替换或删掉其依据。

本轮运行时映射为 `SemanticBlock.reading`，数据投影输出 `sectionOutline`、`textRuns`、`readingRows`、`relationSlots` 和可选 `comparisonRows`。字段名在 R1 固定并写入夹具；WXML 必须实际消费，不接受只增加源字段或仅令测试变绿。文本片段用转义后的原生 text 渲染，禁止把任意原文作为 HTML 注入。

### 7.2 版本与审核

新增标注、语义修正和构建器变化必须进入确定性包版本；不得复用旧 packageVersion 掩盖变化。阅读标注记录逐篇审核结果，旧正文终审不自动覆盖新标注。语义修正可能影响 Atom、primer、回忆及易混投影，需要列明受影响引用并重验，不静默丢对象。

将前后差异分成不可变事实与允许变更两份清单：正文文本、块顺序、ID、来源归属、关系与题目事实必须一致；包哈希、阅读元数据、已审核语义修正及其版本变化允许变化并逐项说明。不能把包括全部包版本的旧 factsHash 整体锁死，也不能删除事实保护断言来迁就变化。

新增标注无效时阻止候选构建并报告文件、块、字段；运行时面对旧包或未知可选标注时退回完整原文，不猜重点或空白。对照缺字段退回原文边界，不生成空表格。标注片段、锚点和比较依据的校验覆盖全部当前正文。
