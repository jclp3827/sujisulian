## 1. 专项结论

当前四个模块的产品分工成立，不需要推倒重来：

- 快速了解负责用最短路径形成当前知识全貌，不承担练习和记忆检验。
- 系统学习负责围绕连续小目标建立有联系、有边界的理解，不承担高频刷题。
- 考前速记负责主动恢复核心表述、条件和边界，并把未记住内容送回原文补救。
- 易混突破负责在同一判断维度上区分相近知识，并用双方来源解释差异。

专项要解决的不是“再生成四份内容”，而是建立一套共享的知识目标母表，再把同一目标分别投影成导读、教学单元、速记卡和易混辨析题。系统学习、考前速记、易混突破形成三条内容产线；快速了解只参加覆盖与理解审查，不建设题库。

## 3. 范围与非目标

### 3.1 本轮范围

1. 只处理当前37篇正式知识可以支持的学习目标。
2. 对37篇建立知识目标、条件边界、常见错误和四模块投影的统一登记。
3. 审核6节快速了解、72节系统学习、37张现有速记卡和5组现有易混对照。
4. 在正式来源支持的前提下，生成并审核新的速记卡和易混候选。
5. 建立内容版本、来源回链、重复检测、审核状态和运行消费门禁。
6. 分开记录结构检查、内容审核、用户理解验证和发布资格。

### 3.2 本轮不处理

- 不把当前37篇描述成完整政治理论、完整国考或省考范围。
- 不补写科学社会主义独立课程、十三个方面成就逐项课程或剩余价值完整前置机制。
- 不引入时政、党史或当前资料之外的考试扩展内容。
- 不把快速了解改造成测试流程。
- 不把系统学习改造成连续答题或每节强制回忆。
- 不以题量、字符数、标签数或自动门禁通过代替内容质量判断。
- 不在本专项中授权上传、发布、状态晋级或主线合并。

范围外内容单列为 `coverageGap`，只能在后续“考试范围扩展专项”获得正式来源与产品决策后进入当前体系。

## 5. 统一知识目标母表

专项只建立一个内容权威层。建议制品名为 `politics-learning-objectives-v1`，每条记录至少包含：

```text
objectiveId
unitIds
title
mustUnderstand
sourceBlockIds
sourceVersion
conditions
boundaries
commonErrors
importance
freshness
coverageGap
quickProjection
systematicLessonIds
recallItemIds
contrastItemIds
reviewState
reviewEvidence
```

关键规则：

1. `mustUnderstand`只表达一个可判断的学习目标；复合目标必须拆分。
2. 每项事实、答案、边界和错误解释都回链正式块；纯教学过渡单独标记，不伪装成正式知识事实。
3. 快速了解可以合并目标形成全貌，但不得反向成为正式分类。
4. 系统学习负责解释目标之间的联系；速记与易混只消费已经登记的目标和边界。
5. 同一目标可以有多个练习投影，但只能有一份权威答案语义。
6. 时效性内容必须记录核验日期与失效条件；无法确认时不得进入运行包。
7. 母表、四类投影和运行包必须有版本关联，禁止静默漂移。

## 6. 三条内容产线

### 6.1 系统学习课程终审

系统学习不建设独立题库。72节逐节审核：

- 本节是否只解决一个明确问题。
- 标题、问题、目标、解释、边界与结论是否指向同一目标。
- 与前后小节的关系是否真实且必要。
- 默认解释是否已经包含必须理解的内容；完整原文是否仍只是可选深入。
- 可选自我解释是否检验本节目标，且没有与考前速记卡机械重复。
- 是否存在重复解释、清单堆叠、无来源推演或超出当前范围的承诺。

终审结果按 `accepted / revise / merge / split / scope-limited / blocked-by-source` 登记，不用单一“通过”掩盖不同处理方式。

### 6.2 考前速记卡库

保留现有37张篇级卡作为基线，按知识目标而不是篇数扩展。合法卡型为：

1. `core-recall`：主动恢复核心表述、对象或结构。
2. `condition-boundary`：恢复成立条件、适用范围和不变量。
3. `error-correction`：判断并纠正常见错误说法。
4. `statement-combination`：对高价值目标核对多项表述；只有来源和答案唯一时启用。
5. `light-application`：使用材料判断目标或边界；当前来源不能支持时不生成。

每张卡必须包含单一主目标、题干、标准答案、答案来源、错误解释、难度、重要性、时效性和回看落点。题量由有效目标和卡型决定，不预设数量指标。

### 6.3 易混辨析库

现有5组作为已核验种子，不直接视为完整题库。新候选只能来自：

- 正式关系中的对照与边界。
- 已审核易错提示中的对象、条件、层级或作用差异。
- 系统学习终审发现的稳定混淆点。
- 多个知识目标共享术语但职责不同的情况。

每组必须具备：双方目标、唯一辨析维度、初判题、标准答案、错误原因、双方来源、关键边界和至少一个复辨变式。标题相似、关键词共现或模型主观判断不能单独生成正式易混关系。

## 7. 生成与审核规则

自动生成只承担候选提取、改写建议、重复扫描和缺口提示，不能直接写入正式运行内容。

候选内容依次经过：

```text
正式来源存在
  → 目标与来源块匹配
  → 答案可由来源充分支持
  → 条件与否定词未丢失
  → 题干只有一个主要判断任务
  → 错误项有明确错误原因
  → 与现有内容不构成无意义重复
  → 人工内容审核
  → 候选运行包
```

下列情况自动拒绝：

- 答案需要使用当前来源之外的事实。
- 通过常识推断补齐政治固定表述。
- 为凑题量制造同义改写。
- 易混题无法说明同一比较维度。
- 选择题干扰项只是措辞怪异，而非真实边界错误。
- 系统学习自我解释与速记卡完全同题同答且没有阶段差异。
- 自动评分无法给出唯一依据，却仍报告用户答对或掌握。

### B0：基线冻结与问题清单

执行内容：

- 固定当前知识包、快速导读、系统课程、回忆卡和对照关系版本。
- 导出四模块实际消费清单，而不是只扫描源文件是否存在。
- 建立重复、缺源、复合题干、过宽答案、无可判定结果和范围偏斜清单。
- 标出时效性政治表述和当前核验日期。

停止条件：基线版本或实际消费者无法唯一确定时，先修正文档和消费事实，不进入内容生成。

### B1：知识目标母表与覆盖矩阵

执行内容：

- 将37篇拆成可审核的单目标记录。
- 为每个目标登记必须理解、条件、边界、常见错误和正式来源。
- 映射快速了解、72节系统学习、现有37卡和5组对照。
- 识别四类状态：`covered / duplicated / misplaced / missing`。

停止条件：出现需要范围外知识才能成立的目标时，登记缺口并限缩，不用教学文案填平。

### B2：易混辨析库专项

执行内容：

- 先复审现有5组是否仍是高价值混淆点。
- 对37篇的易错提示、边界、关系和系统教学目标做候选扫描。
- 候选先登记，不直接创建正式关系。
- 对通过审核的候选编写初判、正式答案、错误原因和复辨变式。
- 按知识区域报告覆盖，避免全部集中在三条辩证法规律。

停止条件：双方来源不足、只能凭标题相似比较、答案取决于未提供语境时拒绝入库。

### B3：考前速记卡库专项

执行内容：

- 逐张复审现有37卡的目标粒度、题干长度、答案完整性和易错提示。
- 将一题承载多个独立目标的卡拆分；同义卡合并。
- 为重要目标补条件边界、错误纠正或组合表述卡。
- 建立卡组策展规则：按范围、重要性、未记住历史和时效性选卡；随机只作为用户显式选择。
- 保留提示—揭晓—自评—回看主流程，不把题库扩展等同于页面增加操作。

停止条件：不能给出唯一标准答案、来源与答案不一致或需要新增时政事实时，卡片保持候选或拒绝。

### B4：系统学习72节终审

执行内容：

- 按主题组逐节审核，不一次性批量改写全部教学稿。
- 每组完成目标覆盖、段落负担、边界、反思问题和前后衔接审查后再进入下一组。
- 优先复核与速记、易混内容重叠的目标，明确“解释、恢复、辨析”三种任务差异。
- 三项已知来源缺口只能限缩，不得通过模型补写。

停止条件：某组核心目标无法由当前来源解释，标记 `blocked-by-source`，不阻塞其他独立组继续审核。

### B5：快速了解与跨模块收敛

执行内容：

- 检查6节是否仍覆盖决定全貌的关键板块，且不因题库扩展而增长为系统课程。
- 对同一目标在四模块中的术语、结论和边界做一致性核对。
- 删除无任务差异的重复投影；保留有明确阶段差异的重复接触。
- 确认快速了解结束后能自然进入系统学习，但不把后者内容提前搬入。

停止条件：快速了解超过既定轻量阅读预算或出现必须答题才能结束时，退回修订。

### B6：有效性验证与候选交接

验证分四层记录：

1. **来源正确**：目标、答案、边界和错误原因均可回源。
2. **教学正确**：题目或课程确实检验声明的目标，模块之间职责不同。
3. **交互可用**：完成、跳过、退出、恢复和原文回看不破坏内容状态。
4. **用户有效**：第一次使用者能描述全貌；系统学习后能解释目标与边界；速记复测能恢复答案；易混变式能正确区分。

自动检查、编辑审核、本地模拟器、真实用户结果分别登记，任何一项不能代替另一项。B6通过只形成可评审候选；提交、上传、发布和主线合并仍需独立决定。

### B7：题库运行接入与扩库治理

执行内容：

- 将B2的10组易混题和B3的67张速记卡生成版本化运行制品并由政治运行包唯一消费。
- 易混题接入两选一初判、双侧证据和反向复辨；速记保持每轮4张并支持连续进入下一组。
- 明确旧速记会话失效、旧系统学习进度兼容和回退边界。
- 把继续扩库限定为小批编辑审查，并登记低产出、重复、缺来源和无用户收益的退出条件。

停止条件：运行制品与评审制品不一致、正式来源无法解析、旧系统进度无法安全恢复或任一核心路线回归失败时，不得宣称接入完成。

### B8—B10：扩库与退出

执行内容：

- B8处理11项一课一目标的高置信缺口，并从9条待审跨单元关系中只接受4组具备唯一维度、双侧来源与反向变式的易混题。
- B9逐项复核26项共享来源目标，只接受12个新的主动恢复任务，其余14项由系统学习承接。
- B10把5条跨单元关系登记为拒绝，把67条单元内信号转交纠错卡或系统解释，并确认当前正式来源内所有候选已有处置。
- 运行题库扩展为90张速记、14组易混；单次学习负担继续保持4张/1组。

退出条件已触发：后续只因新正式来源、大纲或权威表述变化、反复用户错误或既有题纠错而重开扩库。详见[B8—B10执行记录](./politics-learning-content-b8-b10-bank-expansion-20261021.md)。

## 10. 专项完成定义

专项完成必须同时满足：

- 37篇当前范围都有明确知识目标和来源；范围缺口单列。
- 6节快速了解、72节系统学习、全部运行速记卡和易混题均映射到母表。
- 系统学习逐节完成教学终审，没有被题库化。
- 速记卡具备分层任务、精确答案和补救落点。
- 易混题具备真实混淆价值、双方证据、可判定答案和复辨变式。
- 同一知识在四模块中没有事实冲突，重复出现有明确学习阶段理由。
- 自动门禁、人工内容审核、运行消费和用户效果各有独立证据。
- 不把当前37篇或本专项结果描述成完整政治考试覆盖。
