## 3. 现有5组复审

以下正式对照全部保留：

1. 对立统一规律与量变质变规律：区分发展动力与发展状态、形式。
2. 对立统一规律与否定之否定规律：区分发展动力与发展方向、道路。
3. 量变质变规律与否定之否定规律：区分状态变化与前进性、曲折性。
4. 物质和意识与社会存在和社会意识：区分一般哲学关系与社会历史领域。
5. 商品二因素与劳动二重性：区分商品属性与生产商品劳动的两重规定。

三条辩证法规律形成3组两两比较，内容维度不同，因此保留；默认一轮最多选其中1组，避免连续出现造成机械重复。

## 4. 新时代思想5组候选

| 候选 | 唯一辨析维度 | 结论边界 |
|---|---|---|
| 党的全面领导 / 全面从严治党 | 领导地位与自身建设回答的问题 | 前者说明领导地位和制度优势；后者说明党的自身建设和自我革命保障 |
| 以人民为中心 / 保障和改善民生 | 价值取向与民生实践的层级 | 前者是根本价值取向；后者是就业、分配、保障、健康等具体展开 |
| 中国式现代化 / 高质量发展 | 整体路径与发展任务的层级 | 前者是强国建设和民族复兴的整体路径；后者是现代化建设首要任务和本质要求之一 |
| 全面深化改革 / 全面依法治国 | 推进治理现代化的作用 | 前者侧重完善和发展制度、推进治理现代化；后者侧重以法治方式保障和推进治理 |
| 总体国家安全观 / 国防和军队建设 | 总体安全体系与军事支撑的层级 | 前者覆盖多领域并强调系统统筹；后者是总体国家安全体系的重要支撑 |

每组都绑定两侧正式知识、目标ID和来源块，并包含：

- 单一辨析维度。
- 双方边界。
- 两选一初判题及唯一答案。
- 错误选项与错误原因。
- 答案来源。
- 答案方向相反的复辨变式。

B5收敛审计将目标映射进一步收紧为“每侧只登记本题直接辨析的一项目标”。同一知识单元中虽有其他来源相交的学习目标，也不再因为同篇出现而被计为本题覆盖。10组候选因此直接映射17项目标，题目内容与数量未变。

这5组只进入评审候选库。正式关系数量仍为5，运行产品中的易混内容没有增加。
