## 1. 执行原则

- 优先选择没有参与产品设计、没有预先阅读本次文档的首次使用者。
- 建议先做3—5人小样本，用于发现明显理解障碍，不据此宣称普遍学习效果。
- 主持人只说明操作任务，不解释知识答案；出现卡顿、追问和误解要原样记录。
- 每个结果区分“独立完成、提示后完成、未完成”，不能把提示后回答计为独立理解。
- 所有任务继续受当前37篇和4项已知范围缺口限制。

## 2. 快速了解：能否形成全貌

### 操作

让用户从首页进入快速了解，自行浏览到结束。结束后离开页面，在不回看的情况下回答：

1. 当前内容主要有哪两条主线？
2. 每条主线大致包含什么？各举一至两个板块或概念。
3. 两条主线通过什么连接？
4. 当前导读明确没有覆盖什么？

### 通过标准

- 能说出“马克思主义基本原理”和“习近平新时代中国特色社会主义思想”两条主线，措辞可不同但对象不能错。
- 能在基本原理中提到哲学或政治经济学，在新时代思想中提到核心表述或现实实践领域。
- 能把“两个结合”说成连接点，或用准确的等价表达说明基本原理同中国实际、中华优秀传统文化结合。
- 能意识到这不是完整考试范围，并至少说出时政、党史、科学社会主义未独立展开中的一项边界。

只记住零散名词、无法说出两条主线，判为未形成全貌。

## 3. 系统学习：能否解释一个小目标

### 操作

从以下两个代表小节中随机分配一个，完成默认阅读和可选自我解释：

- `TEN-02`：布局怎样连接改革与法治。
- `BASICS-03`：物质为什么同时讲运动与静止。

离开页面后请用户用自己的话说明：本节要解决什么、各部分怎样相连、最容易混淆的边界是什么。

### 通过标准

- `TEN-02`：能区分布局、改革总目标和依法治国总目标，并说明它们相连但对象与层次不同。
- `BASICS-03`：能说清客观实在性是物质的唯一特性，运动是根本属性和存在方式，相对静止是特殊状态。
- 回答必须包含一项明确边界；只复述标题或罗列词语不算解释。

记录用户在哪一段开始形成理解、哪些文字造成停顿，以及是否必须展开完整解释才能回答。

## 4. 考前速记：能否恢复并完成补救

前置条件：145张运行卡已完成本批技术接入，页面仍保持一轮4张及“提示—揭晓—自评—回看”流程。

### 操作

1. 首轮随机但按策展规则抽取4张，答案默认隐藏。
2. 用户先口头回答，再揭晓并选择记得、模糊或没记住。
3. 对模糊或没记住项完成原文补救。
4. 至少间隔24小时，用同一目标的卡再次测试，不提前展示答案。

### 通过标准

- 首轮状态与用户实际回答基本一致，不能依靠直接看答案完成。
- 未记住项能准确进入对应原文落点，并在返回后保留进度。
- 复测时能独立恢复目标答案或关键边界；只认得答案但说不出来，仍记为未恢复。
- 单次“记得”只记录本轮结果，不宣称长期掌握。

## 5. 易混突破：能否在变式中区分

前置条件：14组运行内容已完成本批技术接入，并保留初判、双方解释、来源回看和复辨变式。

### 操作

为每名用户分配一组未练过的候选：

1. 完成初判并说明理由。
2. 阅读双方边界和错误原因。
3. 不回看答案，完成材料或条件改变的变式；答案可同概念也可换概念，不能提示或预期必换边。
4. 用一句话说明真正的辨析维度。

### 通过标准

- 变式能够独立答对。
- 解释使用本组声明的唯一维度，不能只说“名字不同”或背左右标题。
- 初判错误但学习后变式正确，可记为本轮纠正成功；初判正确、变式错误仍不算分清。

## 7. 候选交接判定

四类任务必须分别记录，不能用某一模块表现替代另一模块。小样本只要出现同一位置两人及以上无法理解，先作为内容或交互缺陷复核；不要用平均分掩盖共同障碍。
