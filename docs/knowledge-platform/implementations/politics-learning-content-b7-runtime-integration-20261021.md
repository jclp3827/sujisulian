## 4. 是否继续扩库

结论是**有必要继续，但应按有效学习任务扩展，不按题量无限增长**。

当前67张速记卡直接检验60/97项目标，仍有37项目标没有速记投影。其中11项是一课一目标、来源边界清楚，适合作为下一批8—12张卡的优先池；另26项与同课另一目标共享来源，需要逐项判断是否真的值得单独回忆，不能自动变成26张新卡。

当前10组易混题之外，账本还有9条“关系成立但缺唯一辨析维度”的信号，以及67条单元内区分信号。它们说明仍有编辑空间，不说明还能直接生成76组题。下一批只建议审3—6组：必须同时具备两个正式对象、一个清楚维度、双侧来源、初判、反向变式和唯一评分答案。

优先扩展的11项速记目标为：

1. 共同富裕的对象、节奏与三次分配。
2. 研究环节、创新主体与人才评价。
3. 三种依法行为与三种建设目标。
4. 生态文明的时间目标、控制线与保护地体系。
5. 党的组织重点、群众联系与纪律制度保障。
6. “三不腐”的联系及自我革命的位置。
7. 风险任务、领导保证与公共安全。
8. 统一问题中的根本保证、方针、基础、途径与动力。
9. 辩证法中的根据、条件与作用途径。
10. 人与自然和人与人的生产关系。
11. 不变资本、可变资本与资本构成的不同维度。

## 5. 扩库节奏与退出机制

后续每批固定采用“小批生成—来源审核—重复扫描—运行验证—用户效果复核”的节奏：速记8—12张，易混3—6组。题库可以增长，用户每轮仍只看到4张速记或1组易混。

满足以下任一条件就停止主动挖掘，转入维护模式：

1. 当前正式来源内所有合格信号都已有`accepted / held / rejected`明确处置。
2. 连续两个批次每批少于3个高价值合格新题，或两批合计通过率低于10%。
3. 新候选主要重复已有题干、答案、边界或辨析维度，不能形成新的回忆任务。
4. 剩余题目必须依赖当前正式来源之外的事实、案例或评分语境。
5. 两个内容批次后的用户小样本没有显示回忆恢复率或易混纠正率改善。

进入维护模式后，只因以下事件重新开放扩库：新增正式来源、考试范围或权威表述变化、用户反复出现且有来源支持的缺题、既有题目纠错。这样可以尽可能建立题库，同时避免为了数量制造同义题和低价值辨析。
