## 精确数据映射

| 语义层 | 政治数据 | 预算与行为 |
|---|---|---|
| L0 | 根节点下两篇 | 2个稳定区域，点击进入 L1，不建立焦点 |
| L1（第一篇） | 两个正式章节点 | 2个正式分支，点击进入 L2 |
| L1（第二篇） | 18个直属知识点 | 超过12个预算，按正式顺序稳定聚合为1–9、10–18两个范围；聚合不是知识 |
| L2 | 当前章的知识点，或第二篇所选聚合中的知识点 | 每屏不超过16个；点击知识点建立焦点并进入 L3 |
| L3 | 当前知识点与已确认直接关系 | 中心1个、关系邻居最多6个；关系只作地形叠加，不改变目录 |

第二篇没有章级结构，不补造章节。聚合 ID 固定为 `agg:<scopeNodeId>:<firstOrder>:<lastOrder>`；打开聚合只改变视窗。完整目录始终按42个正式节点呈现等价访问。
