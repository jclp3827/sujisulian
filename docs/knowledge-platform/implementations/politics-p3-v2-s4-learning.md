## 本切片交付

1. 新增纯`RoutePlanner / RouteSession / SearchProjector / RecallProjector`，计划只保存稳定ID、范围、依据和顺序，不复制正文或答案。
2. 首页增加快速了解、系统学习、易混突破、考前速记四个紧凑目标入口；全部先进入明确范围选择，不建立默认第一知识焦点。
3. 快速了解按正式范围结构；系统学习按范围内prerequisite拓扑约束并以正式order稳定破同层；范围外前置只提示；易混只使用正式contrast；速记只使用范围内RecallItem，可显式选择稳定顺序或冻结seed随机。
4. 路线页冻结计划和本地会话，支持完成、跳过、退出恢复和版本失效；完成只报告步骤、揭晓、回看和跳过，不输出掌握度。
5. 速记在路线内执行提示—揭晓—记得/模糊/未记得/跳过，并提供真实存在的体系/易混/原文补救；缺失块锚点时降到完整阅读。
6. 搜索改为canonical可解释投影，卡片点击先预览；体系定位不建立焦点，关系/阅读由显式操作确认后建立。增加结构化意图筛选，不拼接新答案。
7. `KnowledgeContext.goalContext`只携带路线ID、类型、范围和步骤；路线会话使用政治独立存储，不污染其他模块焦点。

## 自动验收

1. 四路线对空/单项/多项范围输出确定；无范围不能计划；相同输入/seed顺序一致。
2. systematic满足范围内全部prerequisite约束、目录稳定破同层，范围外前置透明且不静默加入。
3. confusion只包含正式contrast；无contrast范围禁用。exam无卡片禁用，随机恢复ID顺序不变。
4. 会话版本失效过期；完成报告不出现掌握率；跳过、揭晓、回看计数准确。
5. 搜索标题优先于正文，结果说明路径、命中类型和安全片段；预览不建立焦点，显式关系/阅读才建立。
6. 无焦点速记不得选择数组第一项；路线和焦点按moduleId隔离。
7. S1至S3B、政治内容/关系/展现、常识与笔记主门禁保持基线。

## 用户手测

1. 首页四目标均先出现范围说明；直接进入考前速记时不自动打开第一知识。
2. 分别选择第一篇、第二篇或较小章节，检查四类计划的范围、依据、步数和顺序说明。
3. 退出一条未完成路线再进入，确认恢复同一步；随机速记顺序不改变。
4. 完成数张速记，检查揭晓、模糊、未记得、跳过和补救返回；页面不显示掌握百分比。
5. 搜索标题词与正文词，确认命中解释和路径；点结果只预览，体系定位不改变最近焦点，阅读/关系需确认。

## 回滚与遗留

- 失败时政治阶段退回`workbench`，首页隐藏路线入口并保留S3B工作台；路线存储可保留但旧页面不得读取。
- 当前关系/回忆精确blockId为空，补救降级完整阅读；上游补齐后由现有接口直接提升。

## S5 交互收口边界

- **进入S5立即处理**：入口含义不清、下一步不明确、误触、返回丢位置、焦点或路线状态断裂、弹层遮挡、滚动跳变、不可达操作、同一动作反馈不一致。
- **随S5视觉阶段处理**：色彩、间距、阴影、图标、动效节奏、空间过渡和不同屏宽下的视觉一致性。
- **继续延期**：不影响当前任务完成的偏好型微交互，以及依赖P4掌握度、个性化和跨设备能力的交互。
- S5开始前先建立交互问题清单，并逐项绑定场景、严重度、预期行为和回归用例；不得以零散页面补丁替代主链路审计。
