### R1.1 设计思想有效性复审

| 设计思想 | 当前判断 | 可证伪条件/处置 |
|---|---|---|

| `capability = profile ∩ data ∩ target`与诚实降级 | 保留 | 数据不足却仍展示能力承诺即失败 |

| 自由探索与引导任务分工 | 保留方向、重做交互 | 两者若仍表现为同一种“选篇章—进详情”，则设计未成立 |
| 知识地形/语义缩放 | 待R3原型证明 | 若320px无法同时保留整体、当前分支和直接深入，则不再以“地形”命名，退回结构化分区总览 |

| 一个状态一个主动作 | 保留为注意力预算，不作机械数量规则 | 若关键恢复/退出必须隐藏才满足“一按钮”，则规则失败；主次层级优先于绝对数量 |
| “最适合你”的默认推荐 | 否决 | 无个人证据时只能称“默认建议起点”并解释依据 |
| 固定首页版式和顺序 | 待R3原型证明 | 首屏识别测试失败即调整布局，不把当前组件顺序当平台规则 |

### R2.1 J1–J5黄金旅程状态契约

每条旅程都必须覆盖`开始 → 进行中 → 完成 → 返回 → 失败/恢复`。下表中的“唯一下一步”指视觉主动作；原生返回、安全退出和必要恢复可作为清晰次级动作，不受机械的一按钮限制。

| 旅程 | 开始 | 进行中 | 完成 | 返回 | 失败/恢复与320px要求 |
|---|---|---|---|---|---|
| J1 自由探索/共享表面 | 首页通过熟悉搜索或可见“浏览知识全景”进入；全景先表达稳定分区而非37篇入口 | 当前分支原地展开，兄弟分支压缩但在场；目录按正式父子树等价；点具体知识直接进入同一完整大卡 | 阅读、关系或回忆不被伪装成统一“完成”；用户可明确选择继续当前上下文或回到空间 | 原生返回到原分支、原滚动/viewport和原焦点；目录/地形互返不换事实 | 无图形能力时降级为结构树；无关系/回忆时正文仍成立。320px首屏只放总体位置、当前分支和一个深入动作，禁止重复节点阵列 |
| J2 快速了解 | 首页说明这是默认建议起点；一键直接进入真实导读内容，不先选篇章、不经过ready或四站数量 | 单页连续呈现两条主线、正式连接、当代理论体系、方法镜头和两个代表例；结构只伴随定位，详情可选 | 到达合拢段并提交或暂缓一次自我解释后显式结束；只报告到达/打开/保存事实，不报告掌握 | 进入同源完整卡后原生返回原段原viewport；退出后同一RouteSession可继续 | 必需导读制品或来源失效时明确content-unavailable，不回退目录游并称快速了解。320px首屏先见实质内容，SEC-01至07无需按钮通行 |
| J3 系统学习 | 系统给出可解释的正式范围、前置项、知识数和首尾知识；“开始学习”为主，调整范围为次 | 始终显示当前知识、序号、为何此刻学习及“关系—阅读—回忆”周期；规定事件直接推进同一会话 | 报告已完成动作、跳过项、未完成前置与建议下一范围，不报告抽象掌握度 | 从卡片、原生返回或再次进入均恢复同一周期和步骤 | 前置缺失、内容变化、存储失败均说明影响并允许重建/退出。320px先见当前任务和主动作，路线详情折叠为次级 |
| J4 易混突破 | 系统按当前焦点/最近范围/profile推荐一组正式ContrastPair并说明推荐依据；直接开始辨析 | 左右对象、判断维度和关键边界持续同屏；先答—看依据—复答，必要原文直接定位 | 报告本组核对过的边界、初答/复答事实，并给出下一组或回到相关知识 | 返回保持本组、当前阶段和左右顺序，不退回普通篇章选择器 | 没有正式对、锚点失效或内容未审时诚实退出/换组，不用相似文本猜对。320px纵向配对但保持双方标签和同一判断维度可见 |
| J5 考前速记 | 有有效RouteSession就恢复；否则以可解释默认范围生成冻结卡组，一键开始，范围/随机为次 | 单卡只显示提示→揭晓→自评；保留卡组进度，记得/模糊/未记住/跳过生成事实记录 | 分项报告四类自评和待补救卡，不推断掌握；允许进入补救队列或结束 | 暂停后从同一卡与同一面继续；返回具体知识仍用同一KnowledgeCard与锚点 | 版本/范围变更时说明失效并重建；存储失败不假装已保存。320px每屏只有当前提示或揭晓及一个阶段主动作 |

### R2.2 允许与禁止的产品形态

| 允许 | 禁止 |
|---|---|
| 同一事实在空间、路线、搜索中以不同ViewModel投影，但进入具体知识后复用一个KnowledgeCard渲染器 | 地形卡、路线卡、详情卡各复制一份正文或各自维护焦点 |
| 页面栈分工与语义连续性并存 | 为追求“同一页面”把全景、路线、正文、关系、回忆同时铺在320px首屏 |

## 1. 本切片为什么存在

S0至S5已经证明政治模块的体系、关系、阅读、回忆、路线和搜索能够连通，自动门禁及微信开发者工具预览编译也已通过。但产品复盘发现，技术闭环尚未自然收敛为学习闭环：同一去向被多个入口重复表达，工程和审计语言进入默认界面，L0至L3虽然改变数据粒度，视觉上仍接近不同密度的目录。

S5.5不是补功能，也不是装饰优化。它解决以下候选版阻塞项：

1. 让用户始终知道当前所在位置和唯一推荐的下一步。
2. 让体系理解、关系探索、完整阅读、主动回忆共享一个连续焦点，不再形成多套导航。
3. 将数据结构、审计和构建术语从学习者界面移到来源层或诊断层。
4. 让快速了解、系统学习、易混突破和考前速记从入口开始就是四种不同的学习任务，而不是同一个“选择篇章后逐层进入知识”流程的四种名称。

在S5.5完成前，当前candidate只视为**技术候选版**，不得提交S6产品验收，也不得标记`verified`。

| SURF-013 | 来源与纠错是上下文工具 | 合并为低干扰入口；纠错面向用户说“提交内容反馈”，内部修订流程不外露 |
| SURF-014 | 保持空间连续性优先于动效 | 切换前后保留焦点、路径、来源和返回位置；动效只辅助解释，不成为状态本身 |
| SURF-015 | 本切片不补上游语义事实 | 不猜关系、不改正文分类、不伪造块锚点；数据缺口进入后续内容加工任务 |
| SURF-016 | 四类目标共享明确范围契约，但主流程由系统推荐并持续引导 | 快速了解由系统交付内容先行的连续新手导读，结构只伴随定位；系统学习由系统按正式范围和依赖深入；易混突破由系统推荐已确认对照；考前速记优先恢复或生成有效卡组。调整范围只是次级控制，不得把四类目标做成四种选择器 |

## 4. 词汇与信息分层契约

### 4.1 默认学习者层

只回答：我在哪里、这是什么、下一步做什么。推荐替换如下：

| 禁止直接展示 | 学习者表达 |
|---|---|
| `L0/L1/L2/L3`、语义层 | 知识全景 / 篇章 / 主题 / 当前知识，或不显示层级名 |
| 建立知识焦点 | 查看这个知识 |
| 一跳/一层关系 | 直接相关 |
| 范围聚合 | 主题组 |
| 正式目录范围 | 本次学习范围 |
| 进入焦点工作台 | 开始了解 / 继续学习，按上下文选择其一 |
| 隔离展现联调、不代表正式发布 | 内容校订中，部分内容可能调整 |
| 全量联调知识点 | 个知识点 |
| 关系定向 | 学前提示 / 相关知识，按所在场景选择 |
| 内容块 | 正文内容，通常不显示数量 |
| 正式 Markdown 修订并重新构建 | 提交内容反馈 |

### 4.2 来源信任层

允许展示来源名称、来源页码、修订日期和“校订中/已核对”等人类可理解状态。默认不展示文件路径、构建版本、数据包ID、哈希、blockId和内部风险编号。关系缺少精确块锚点时显示“可查看该知识的完整来源”，不显示实现缺口。

### 4.3 编辑诊断层

文件、schema、blockId、canonical、构建包、review/release、风险页和联调信息仅供开发/校订诊断。S5.5不要求新建完整后台；现有默认页面必须移除这些信息，确需保留时由显式开发开关控制，生产默认关闭。

## 5. 精确实施切片

### S5.5A 主流程和动作去重

1. 政治首页：采用搜索熟悉入口、单一状态主任务、紧凑四目标和可见全景预览；首次默认推荐快速了解，不让任一入口与状态主任务同权竞争。
2. 详情工作台：使用单一KnowledgeSurface和可选GoalGuide；ActivityStage保留内部，不显示四活动持久控制器。
3. 搜索：结果卡片移除体系/阅读/关系三个并列快捷动作；根据正式命中直接进入完整内容、关系或回忆。
4. 关系预览：根据关系上下文提供一个推荐主动作；“切换焦点/全文阅读/体系定位”不再三按钮同权并列。
5. 路线：系统先生成默认推荐计划并持续投影当前引导；规定完成事件在工作台内直接推进同一RouteSession，用户无需返回路线总览二次确认；调整与跳过保持次级。
6. 阅读工具：将字号、行距、密度、重点等归入单一“显示”入口；专注阅读可保留为直接动作，切换偏好不得主动滚动正文。

### S5.5B 知识空间与知识卡片展现

详细规格见[S5.5B独立文档](./politics-p3-v2-s5-5b-knowledge-space-and-cards.md)。本节原L0–L3条目只保留为历史方向；2026-08-30最新复测决定取消全部知识卡预览，知识入口直接进入完整详情；分支态改为紧凑区域栏加当前分支，完整目录按正式“篇—章—知识”结构投影。同一页面现承载全览、分支、完整卡和回忆四种状态。

1. L0知识全景：用少量领域区域及相对位置表达总体结构，禁止退化为完整知识卡片列表。
2. L1篇章骨架：突出主干、当前篇章及其上下文，显示向下深入的方向。
3. L2主题簇：展示有限节点组合、核心节点和必要的跨主题连接；溢出进入目录，不堆叠全部卡片。
4. L3焦点：当前知识稳定居中，直接关系围绕分布；列表仍作为无障碍等价视图。
5. 进入、返回、地形/目录切换均消费现有焦点与viewport状态；不得为了视觉改版另建页面级知识状态。
6. 小程序端只做受控投影，不实现无限画布、自由拖拽或双指缩放。

### S5.5C 用户语言与工具降噪

详细规格见[S5.5C独立文档](./politics-p3-v2-s5-5c-language-and-context-tools.md)。本节条目继续作为实施清单；产品方向、声音所有权、语言密度、词典、信任披露、情境工具、降级语义和candidate门禁以独立规格为准。

1. 按第4节逐页清理首页、地形、详情、搜索和路线的默认可见文案与无障碍名称。
2. 将来源、校订状态和纠错合并为次级上下文区域；正文首屏不展示文件、版本和内部处理流程。
3. 在政治profile或共享展示层建立最小用户文案映射；模块专有词归profile，共享行为词归平台，不复制散落常量。
4. 扩展candidate校验：扫描政治WXML默认可见文本，禁止内部词；检查搜索、关系预览和详情不存在重复同权动作组；检查详情只有一个活动控制器。
5. 不为文案映射建立通用国际化框架，不引入组件库或第三方依赖。

### S5.5D 四类学习目标入口分化

原实现虽然在`RoutePlanner`中生成了不同步骤，但四个首页目标均进入同一“选择本次范围”页面，范围项也主要以篇章和知识数量表达。首轮S5.5D只改成了不同入口对象，用户复测仍判定进入后共用卡片列表、确认预览、当前步骤和完成页，真实体验方向没有成立。S5.5D因此必须覆盖“首页识别 → 系统推荐 → 持续引导 → 目标完成反馈”整条路线，而不是只分化标题和首屏数据。

1. 快速了解：系统默认生成模块L0/L1主分支与显式核心锚点的有限导览，用户一键开始并由引导逐站了解；区域调整只用于次级缩小导览，不展示成普通篇章学习清单，不自动进入长正文。
2. 系统学习：系统根据profile推荐正式范围或当前有效上下文，按前置约束、正式顺序和“关系—阅读—回忆”生成深入路径；用户首先开始学习而不是先配置范围，范围和范围外前置作为可解释、可调整信息。空间地形只负责说明位置，不替代这条时间顺序。
3. 易混突破：系统优先按当前焦点、最近范围和profile策展顺序推荐第一组已确认易混对，直接引导关系理由、边界、必要原文和辨析回忆；“换一组/限定区域”是次级控制，不先让用户从普通篇章或易混对列表自行编排。
4. 考前速记：系统优先恢复最近有效会话；无会话时按profile默认正式范围生成可解释卡组并一键开始提示—揭晓—自评；调整范围和明确随机是次级控制，不以浏览知识层级或先配置卡组为主流程。
5. 四类入口继续复用现有LearningRouteDefinition、LearningRoutePlan、RouteSession、KnowledgeFocus和范围投影，不建立第二套路线或焦点状态；允许复用底层范围数据，不允许复用成相同的首屏交互。
6. 首页目标说明、系统推荐依据、持续引导方式、进行中主动作和完成说明必须随目标变化；不能只改变标题后继续渲染同一篇章卡片列表，也不能把四类目标改成四种范围选择器。
7. 进行中展现必须直接投影路线结构：快速了解同时显示主干及当前位置；系统学习显示当前知识序号和“关系—阅读—回忆”阶段；易混突破保持左右知识与判断关键同屏；考前速记保持单卡提示、揭晓和自评。
8. 四类目标都必须先给出系统推荐并允许一键开始，同时按任务成本提供必要解释：快速了解说明导览主干；系统学习说明知识数、依赖、首尾知识和三阶段节奏；易混说明推荐对照及理由；速记说明恢复状态或卡片范围。调整、换组或随机不得取代开始引导成为主流程。
9. 完成反馈必须回答各自目标：快速了解报告已看主干并回到全景深入，系统学习报告学习动作及跳过项，易混报告本组边界已核对，速记报告记得/模糊/没记住/跳过；不得统一成“路线完成N步”。
