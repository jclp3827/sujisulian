产品侧复用每日练习/一问一答原有“直接查看对应原文”按钮，保留一键打开、返回练习和原会话。新增投影仅含24题的位置、目标和题目版本，5015字节，位于政治分包`practice/remedy-targets.js`；完整管理目录不进入小程序包。未揭晓、版本不符或绑定失效时拒绝跳到猜测位置。

## 来源变更后的工作顺序

```sh
# 先编辑并生成原内容链的候选运行知识包、题库或课程，保留旧管理基线
# 在重新生成U2基线之前，检查候选变化
node scripts/check-politics-question-impact.js
# 也可显式对比保存的上一份基线
node scripts/check-politics-question-impact.js --baseline=/path/to/previous-management.json
```

无变化返回`unchanged`及退出码0；有变化返回`review-required`及退出码1。报告包含变化的来源块、来源引用、目标、题目与阅读投影，受影响条目及原因、实际使用路径和补救关系。删除和解除关联使用新旧关系并集，不因当前已找不到引用就漏报。未能定位到实体的全局/元数据变化也保留为`unmappedInputChanges`，不能当作“无影响”。

检查读取当前候选运行知识包、两类运行库、课程投影和正式目标表；不会自动监视任意上游文档。只修改上游源稿但未运行原生成链时，不能用这里的`unchanged`声称源稿已核验。

复核报告涉及的题干、答案、解释、来源及消费路径，需要时按原生成链更新题目版本；不得用重建基线替代内容复核。完成复核后再生成派生制品：

```sh
node scripts/build-politics-question-catalogue.js
node scripts/build-politics-question-management.js
node scripts/validate-politics-learning-banks-runtime-v1.js
node scripts/validate-politics-daily-practice.js
```

U1目录、U2基线与分包投影均可重建，不能直接手改JSON/生成JS。现有题库门禁已同时检查U1和U2；直接重建基线不构成内容审核、人工验收或发布批准。

## 补救关联与消费路径

开发侧读取基线的`remedies`可按questionId查询：`objectiveId`和`lessonId`来自正式目标登记；`primaryRecallItemIds`仅包含同主目标卡；`supportingRecallItemIds`是显式辅助关联；`readingTargets`保留全部依据的真实单元与块。产品按钮仍仅打开首个已登记依据，不新增回忆/课程跳转按钮或每日混排。

| 类型 | 本批核实的消费方式 | 说明 |
| --- | --- | --- |
| 回忆卡 | 考前速记、搜索回忆提示 | 可涉及全部145卡 |
| 回忆卡首张 | 正文默认回忆、旧系统学习兼容路径 | 当前每个单元的首张，不能等同于全部卡 |
| 回忆投影依赖 | 焦点工作台回忆数据、易混载荷中的recallItemIds | 单列projectionDependencies，不声称易混页面展示这些卡 |
| 应用题 | 每日练习、一问一答 | 同一24题库、各自会话事实 |
| 易混组 | 易混初判与材料复辨 | 保留一组的双阶段结构 |
| 阅读稿 | 正文、系统小节、快速了解单元 | 按显式来源、目标与正文首张回忆关联核查 |

以上路径对照`learning.js`的exam/legacy systematic/search、`projectors.js`的focus和首张recall projection，以及`detail/index.js`的原文回忆使用方式。未映射的包级变化需另核查实际消费者，不能凭主要投放模块推定全部影响。
