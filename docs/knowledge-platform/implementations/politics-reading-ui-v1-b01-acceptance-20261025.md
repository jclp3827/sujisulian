## 已有进度时如何进入

- 快速了解可以从当前继续位置用「上一步」或继续按钮找到第2、第4步，不需要清除旧记录。
- 系统学习若主题已读完，进入该主题后，在对应小节点击「回看」。已读回看也采用样板新排版，不要求重新学习或重新标记已读。
- 仅上述8个页面启用新阅读样式，相邻步骤及小节仍保留原版，便于本轮对照。

## 每页核对

1. 默认字号先扫标题、概念和重点，再连续阅读；学习目标不应压过正文。
2. 点击「字号」切换标准/大/特大，以及标准/舒展行距。长标题完整，当前阅读位置不发生明显跳失。
3. 主按钮完整可见，字号入口不挤压按钮；底部末段能滚到操作栏上方。
4. 系统学习只出现一个「本节结论」，有左侧线；自测可展开、收起，原文往返保留当前小节与答案状态。
5. 正文点击「目录」后，点击一个主题，目标应避开顶部导航；原文内容、重点与来源定位保持正确。
6. 普通搜索进入正文时保留「回忆一下」主动作；从样板系统学习小节查看原文时，优先提供「返回本节学习」。
