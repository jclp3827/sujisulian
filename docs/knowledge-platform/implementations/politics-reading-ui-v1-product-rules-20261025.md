# 政治理论文字型界面产品规则 · 阅读 UI V1

日期：2026-10-25。状态：用户批准第0批及第1批8个代表页面实施；全量扩展尚未开始。工作树：`codex/politics-quick-reading`，HEAD `2f2472e`。本规则是现有内容与蓝色阅读主题规则的新增补充，不改写已封存的历史验收记录。

## 目标与模式职责

连续分层阅读：结构能扫清、判断能抓住、长文能连续读、关键操作可发现、离开后可恢复。快速了解建立知识全貌；系统学习理解概念与关系；正文支持深入阅读、定位与核对。三者共享文字、间距、重点、设置与动作规范，不强制使用同一信息结构。

## 第0批基线

已冻结当前5步、77节、37篇以及178张回忆卡、24道理解应用题、14组易混内容。正文、来源块、题目答案、学习版本、学习记录键和完成规则均以本轮开始时的内容为准。基线清单覆盖工作树现有3052个文件；只允许明确列出的展示代码发生变化。保留原工作树所有修改、未跟踪文件和 Git 引用，不提交、不合并、不上传、不发布。

## 通用阅读合同

1. 375px设计基准下，正文34rpx，三档34/36/40rpx；页面标题48/52/56rpx，节标题40/44/48rpx，辅助说明28/30/32rpx。实际逻辑像素按当前窗口宽度计算，不把rpx误报为固定px。
2. 正文默认1.8倍行距，舒展2倍；段间24rpx、节间56rpx，正文左右40rpx。字号变化时标题同步变化，文字完整换行，不缩小长标题、不省略核心概念。
3. 一屏只有一个主要标题。长标题的内容与序号可分行，文本和顺序仍完整。学习目标降为普通字重的辅助说明，不承担第二个标题的职责。
4. 行内重点始终显示，以加粗和克制浅底表现完整判断及必要限定词。不得提供关闭重点的入口，不设强制高亮比例；强调超过半段只是检查信号，完整定义可保留。
5. 分段根据语义。第1批只对明确指定的句末或分号断点做无损展示投影；所有段落拼接须逐字还原原文，标点不得丢失。强调片段跨断点时保留其角色。找不到合法选择器时回退完整原文。
6. 系统学习统一且只出现一个“本节结论”，保留左侧线强调。解释负责展开，结论负责收束关系；有效辨析放在所解释的概念附近或融合入结论，不能另造重复模块。正文不强行插入原本不存在的结论或摘要。
7. 核心定义、条件和判断默认可读。相关知识、额外依据细目可按需展开。候选状态、失效定位等会影响理解的信息不得被隐藏成装饰。
8. 普通说明文字也必须可读，主张可读文字前景/背景对比度至少4.5:1。辅助信息通过字号、位置、留白降权，不依靠浅灰文字弱化至不可读。
9. 不新增多层粘性栏。快速了解进度区不重复完整页面标题；正文完整一级目录继续可见，子节可展开，阅读途中提供目录入口。目录跳转目标必须避开顶部导航与定位栏。
10. 快速了解与系统学习保留左辅助、中央唯一主动作、右跳过的已验收位置和职责。显示设置不推进学习、不标记已读、不改变跳过事实。
11. 正文从学习任务进入时，主要返回入口优先，避免与“回忆一下”竞争；独立正文保留回忆主动作。目录、字号为辅助入口，不重复布置。
12. 触摸操作以至少88rpx、在常规375px基准约44px校准，结合实际几何核对；底栏处理安全区、长文案、放大文字及末段遮挡。
13. 字号与行距共用现有显示偏好键。新入口保存失败明确反馈且不套用未保存设置；不迁移或改写学习进度。调整后尽可能保持当前可见语义块的位置；连续选择以最新设置为准，目录跳转等明确定位动作应取消旧的显示恢复回调。
14. 共用组件只提供展示及事件；不复制题库、不重新计算学习完成、评分、队列或掌握度。阅读样式显式按阅读模式和样板ID启用，回忆、练习与旧路线保持原有表现。
15. 产品规则、代码/结构检查、微信模拟器实际渲染与交互、人工验收、主线集成和发布分别记录。320px和真机验证沿用用户豁免，不恢复为验收门槛。

## 第1批完成与停止边界

第1批应完成8页默认与特大字号、设置保存/失败、正文目录跳转、参考答案展开、原文与任务往返，以及非样板/题库隔离检查。全量5步/77节/37篇属于后续批次，未在本轮授权下提前扩展。凡需修改已通过知识语义、删知识点、改变学习完成/跳过规则或影响无关模块业务，应停止提出具体问题；间距、换行、颜色、样式范围与无损分段由执行者决策。

参考：W3C [Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)。这些是对比度与适应性参照；上述字号/间距为本产品的样板校准值，并非标准强制值。
