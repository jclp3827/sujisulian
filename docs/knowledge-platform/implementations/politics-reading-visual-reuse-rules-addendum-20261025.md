# 阅读界面复用规则补充：一级脉络与差异样板

日期：2026-10-25。适用工作树：`codex/politics-quick-reading`。本补充承接已验收样板及复用方案；本轮用户最新的“只摘取关键脉络，比如1/2/3，更细的不要”优先于原方案中展示多级脉络的安排。历史验收与证据文件不改写。

## 当前执行规则

1. **本篇脉络只显示一级主线**，使用已有一级目录数据，不新编概括、不删改原标题。二、三级标题只在正文内保留，不显示在脉络区，不提供“展开子节”入口；底栏“目录”同样只能定位到一级主线。无一级脉络时不制造目录。
2. 短且少的一级主线沿用科学体系样板的紧凑两列；长标题单列完整换行。大/特大字号使用单列。序号与标题保持配对，不截断或缩小标题。
3. 标题、导读、正文、已有重点、结论、自测和操作区复用已验收角色。正文17px基线、1.7倍行距及自然字距，具体逻辑像素以模拟器实际计算为准；字号/行距继承现有偏好。蓝色重点底部42%→36%→24%→透明，只改变已有强调的显示，不新增标注。
4. 蓝底模块由明确的区域ID映射启用，`reading-heading`不等于模块导读。普通标题与连续讲解通过字重、字号和留白区分，不全部装入蓝色卡片。
5. 概念对照按“维度—对象—对应内容”纵向排版；保留原对象和维度配对，不拆平数据。相关知识标题直接跳转；有正式区别说明时另设“查看区别/收起区别”，保留原有维度和边界文字，不复制一份相同的关系理由。
6. 快速了解维持5步、前后步、稍后继续、跳过和完成事实；完成页保留浏览记录及“不代表掌握程度”的说明。浏览全部知识、系统学习和返回首页沿用现有操作，不改变模式职责。
7. 系统学习沿用已验收样板：只有一个“本节结论”，自测只保留小号“快速自测”、题目、答案按钮和展开的答案。已有正常阅读/回看/补读与返回逻辑保持一致。
8. 展示策略集中登记启用ID和能力，页面外壳与正文组件同步启用；旧分段投影、正文/题目/答案/重点范围/依据ID、内容版本、学习存储键及学习事件均冻结。未启用页面和非阅读模式保持原有展示。
9. 模拟器验证与人工视觉验收分别登记；320px和真机继续不作为验收条件。新结构样板确认前不进入大批推广。
