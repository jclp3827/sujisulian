## 二、逐卡工作方式与交付物

为145个原cardId建立逐卡记录，至少包含：原卡ID/版本、主题、原题型、知识对象、明确回忆任务、当前知识与目标关联、来源及实际支持语句、题干/答案/说明处置、处置理由、新旧ID及版本关系、原文落点、两个独立角色结论、前端/进度验证状态、完整验收路径。

实施时处置采用以下唯一主分类，兼容记录多个修改动作：

| 主处置 | 适用条件 | 要求 |
| --- | --- | --- |
| 保留 | 任务清楚、答案准确、说明增量且有来源 | 仍须复核，不按既有通过跳过 |
| 改写 | 知识有用，题干、答案、说明或来源展示不合格 | 修源稿与生成链，不只改页面 |
| 拆分 | 原卡承担多个可独立核对的任务 | 先查已有卡；子卡不得继承旧记住状态 |
| 合并 | 多卡实质重复或仅正反措辞不同 | 记录合并去向与原身份，不删除历史 |
| 退役 | 无独立回忆价值、来源不足或纯编排任务 | 从新投放退出，保留来源及历史记录 |

内部编辑备注与面向用户的易错说明分开管理。每批保存修订前后源稿、实际显示投影、角色审查、必要来源核对、计数和处置流转表；不覆写历史审核结论。

### P3 优化后定向补缺

在145张原卡均完成主处置、跨卡去重及当前知识映射复核后，才决定补多少有效知识点。优先核对当前课程新增的科学社会主义两节、十三个方面成就三节等尚无直接练习小节绑定的内容；它们只是候选检查区，不能按五节机械各补一题，更不能重新做数字清单背诵。

复用/拆分能覆盖的，不以新ID重复造题；只需解释整组关系、没有独立回忆价值的仍留系统学习。确有重要、可独立核对、来源充分而无有效卡的知识，分小组补题并按相同双角色和前端标准验收。

不预设扩到200或其他总数，不以旧90/97为目标。现有正式来源能够支持的补题属于本方案内常规处理；没有可靠来源的不编造，单列待办，只有其是否纳入本轮会实质改变用户目标时才提出决策。

退出：每个候选缺口均有复用/拆分/新增/不适合回忆/来源不足的理由；无具备独立价值且来源充分的未处置必要缺口时结束补题。不能以“这一批少于几张”为替代语义标准。

## 五、必要停止门与可独立决策事项

可独立处理：常规题干/答案措辞、无增量说明删除、已有来源内的拆分合并、样板及批次内部排序、局部展示和必要兼容修复、基于已审来源的补缺。遇到问题先在当前批解决，不频繁追加批准流程。

只有以下情况需要停止相关工作并说明具体证据：

1. 正式来源冲突或不足，无法独立确定正确答案，且将实质影响本轮范围；不能用编者猜测补齐。
2. 需扩大到24应用题、14易混、考试地区/年份或新的正式来源建设等本轮外产品目标。
3. 方案必须清除、覆盖用户历史，或无法提供保留历史的可恢复升级路径。
4. 发现其他工作树/并发改动冲突，继续将覆盖用户受保护内容；或执行被自动审批拒绝且无安全替代。

局部缺来源卡可以先退出新投放并保留待办，其他卡继续；不将非必要缺口或可解决技术问题作为全任务停止理由。提交、合并、上传及发布不属于本实施方案授权范围。
