## 1. 目标与边界

目标是让政治模块完整使用常识和训练的应用共享主题，维持已验收的页面结构、按钮位置和学习内容。本次审计不重新设计导航，不重排路线，不扩库，不修改正文事实、进度存储和完成规则，不动照片及其他工作树，不提交或发布。

审计覆盖政治首页、搜索、知识图谱、独立正文、快速了解、系统学习、考前速记、易混突破、每日练习／一问一答及相邻共享渲染组件。源码检查覆盖颜色、token、按钮／卡片、进度与完成态、阅读强调和复用边界。运行抽查补充普通小节按钮尺寸、速记模糊自评状态和练习答错反馈；不把源码通过视为全部状态均已运行验收。

共享优先原则（用户补充）：另外三个模块已经共用一套主题色并建立 design token。政治理论首先复用其颜色、几何、按钮、卡片与状态表达；只有学习任务和信息语义确有差异时才做局部延伸，不复制独立色板，不强行复用生命周期不同的实现。

## 2. 已成立的结论

- 政治皮肤直接引用应用共享蓝色、浅蓝背景、白色卡片、边线和阴影；本范围旧红色和临时青绿色常量扫描未发现残留。原生导航 JSON 与共享页面背景一致。
- 主要底栏已实际使用共享按钮基元、动作 token 和左中右位置；基础进度轨道与训练同源，分段状态为必要扩展。
- 快速了解的步骤、系统学习的已读比例、速记的卡片／阶段和每日练习的数字进度表达不同业务事实，保留差异。系统学习跳过不计入已读，主题“已读完”不等于掌握；自动检查通过。
- 重点词保留加粗＋浅蓝底线式底纹，边界保留橙色下划线；独立正文通过显式政治皮肤处理组件隔离，大字号的对照布局有单列降级规则。
- 政治长期阅读记录不适合训练短期 session-store；不迁移状态机或存储。正文连续阅读不用强制套白色题卡；单动作阶段不强制补成三按钮。
