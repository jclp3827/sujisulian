## 已实现

- 移除红线标出的“本主题已读完”、重复的下一主题/返回首页说明以及“阅读记录不代表掌握程度”提示。含跳过小节时保留真实未读数量，不把到达末尾说成全部读完。
- 主题标题使用20px层级，避免短主题名末尾单字折行。小节标题使用可伸缩列和18px层级，操作按钮固定44px宽度及至少44px触摸高度，不再挤占大半行。标题完整自然换行。
- “已读”使用与路线列表共用的绿色辅助标签；未读/待阅读采用中性标签。回看和补读沿用原索引、事件及状态更新规则。
- 下一主题采用已验收的用户说明，不展示“不展开…”等内部scope。底部主按钮整行显示并处理安全区，普通正文和已有知识结论保持原样。
- 回看入口页固定字号、无字号设置；进入具体小节后使用已验收正文及其字号设置。

## 验收路径

政治理论 → 系统学习 → 新时代思想 → 核心要义、新时代与“两个结合” → 已读主题的结束/回看页 → 回看。

也可在该主题最后一节读完后进入；若主题尚未全部读完，应显示未读数量，并对跳过的小节保留“补读”。点击“进入下一主题”应进入十个明确。已读主题可从路线列表再次进入。目标项目不注入验收记录，界面取决于用户真实进度。
