# 系统学习主题结束与回看页 UI 规则

用户已验收路线列表，继续优化回看页。删除冗余的“本主题已读完”、进入下一主题/返回首页的操作说明及“阅读记录不代表掌握程度”说明，保留真实的未读数量提示。主题名沿用列表必要标点，下一主题使用已验收的用户说明，不展示内部scope。完整篇结论中的知识总结与边界保留。

回看列表标题使用可伸缩列，操作按钮使用不增长的44px触摸区域，避免默认按钮宽度挤压标题。标题完整自然换行；已读使用通用绿色标签，未读/待阅读使用中性标签，保留原“补读/回看”的动作和索引。与路线列表共用政治辅助标签样式，蓝主绿辅，不修改知识正文、已读/跳过/补读事件及记录。

结束/回看入口页固定字号，无字号设置；进入具体正文后沿用已验收正文与设置。底部主操作整行显示并保留安全区。范围覆盖主题正常结束、含跳过小节、最后主题的边界显示及回看往返；不把已到末尾误写成全部已读。合成记录仅用于隔离模拟器，不改目标项目用户进度。人工视觉验收、技术验证与发布分别登记。
