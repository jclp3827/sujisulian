# 系统学习路线列表 UI 方案与批次

日期：2026-10-25。用户接受方案并授权分批执行。范围为两篇、21个主题（新时代思想14主题51节；马克思主义基本原理7主题26节）。正文、题库、知识顺序及完成/跳过规则不变。

## 产品规则

列表帮助用户看懂学什么、找到续学位置、扫描主题和真实进度。标题层级、说明、操作与状态分别承担职责。

- 内容主标题“学习路线”，不提供字号入口。两篇切换保留完整名称和已读数量，自然换行，不缩小长名称。
- 删除路线说明大模块及内部范围限制。主题使用单独用户说明投影，内部scope与正式知识内容保留；只规范主题标题的必要标点。
- 有学习位置时显示轻量浅蓝续学区域，保留“继续当前小节／进入下一主题／查看当前主题”的现有动作。标签匹配真实状态，不将主题结束说成本篇完成，不将已读说成掌握。
- 主题卡片结构：序号＋完整标题、紧邻标题的绿色进度标签、浅蓝区域中的学习说明及右侧圆形箭头。移除逐项进度条和重复状态胶囊。未开始“共N节”，进行中“已读R/N节”，读完“✓ 已读完 · N节”。完成项保持白底，仅状态用绿色。
- 标题24px、主题18px、说明14px、辅助12px为设计基准；复用token，上屏计算值校准。两侧20px；大区20—24px；标题与说明6—8px；说明与进度8—12px；主题项上下约16px。固定高度与截断不得隐藏核心内容。
- 普通主题采用常识第三级风格的白色圆角卡片，续学区域保留浅蓝底和蓝色主操作。列表名称不套正文重点渐变。没有固定底栏，不沿用正文300rpx底部预留，仅合理留白及安全区。
- 字号设置仅服务正文。路线列表、完成/目录等非正文状态使用固定字号和行距，不显示相关设置；不受正文偏好缩放影响。旧学习记录入口保留为次级操作。
- 只对groups屏幕启用新样式和列表展示字段，正文及其模板/样式保持原样。错误/过期等状态既有功能保留，专项批次再完善。

## 批次

| 批次 | 范围 | 交付与边界 |
|---|---|---|
| L0 | 登记规则、21条说明、批前冻结 | 不修改知识源中的内部scope |
| L1 | 两篇切换、续学、21主题、固定字号层级、旧入口 | 完整列表样板接入前端，人工集中确认视觉后继续L2 |
| L2 | 首次/进行中/已读完/全篇读完/旧记录/读取失败的完整状态设计 | 不更改进度算法和记录归属 |
| L3 | 集中交互回归与收口 | 切篇、续学、主题进入、返回路线、字号及正文隔离 |

L1会运行必要的正常状态与记录保护检查，但不把这些技术检查冒充L2全部状态设计完成。检查正文三档偏好及舒展行距均不影响列表；320px与真机继续不设门槛。目标为codex/politics-quick-reading工作树；不提交、合并、上传或发布。

## 样板执行中的用户修订

用户要求参照常识第三级知识卡，不采用过素的平铺分隔列表。主题项改为浅蓝页面上的白色圆角卡片，内容说明置于浅蓝内嵌区域，右侧使用圆形进入箭头；不为模仿卡片而新增或重复知识摘要。进度紧邻标题显示，长标题空间不足时自然换行，不挤压或截断概念。

政治模块统一采用蓝主绿辅：蓝色负责选中、主操作、导航和内容结构；绿色负责辅助标签、进度数量和已读标记。普通正文保持深色。绿色标签可表示课程数量，并不单独代表完成；已读完须有明确文字和勾选。本批先在路线列表落实，后续政治模块同类辅助组件复用；不批量将已验收正文改色。

此更新替代原L1“轻分隔列表、底部进度”的视觉方案，学习数据、主题说明和原动作保持不变。字号恢复以可见主题标题为锚点，等文字重排稳定后执行，重复选择相同设置不得取消进行中的恢复。

## 字号设置边界的用户修订

用户明确“字号只服务于正文，其他页面无需字号相关设置”。路线列表移除字号及行距入口，使用固定的标题/说明/辅助信息层级，不受正文显示偏好缩放影响；正文仍使用现有设置和保存逻辑。撤回列表字号恢复控制器，不将原型中的字号功能继续推广到其他非正文页面。该要求覆盖前文L1字号适配和列表位置恢复的安排。
