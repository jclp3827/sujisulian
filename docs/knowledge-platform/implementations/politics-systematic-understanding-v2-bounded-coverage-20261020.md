# 系统学习两条路线与核心目标覆盖

日期：2026-10-20。状态：候选教学草稿，待内容终审与P5阅读反馈。

## 本轮完成到什么范围

当前两条路线共21组、72单元，新时代思想48单元，基本原理24单元；14个编排主题均有单元，37篇各有明确的主要教学责任。它是一套按现有材料编排的、有边界的基础理解路线，不等于完整政治理论、完整考试范围，也不表示每项原文细节均已授课。

来源引用与教学覆盖分开：`primaryUnitIds`明确本单元主要解释哪篇，`corePromises`核查新稿承诺在默认解释中出现的关键内容；逐块`teachingDisposition`只区分默认引用、可选引用或原文查阅，不把引用一块计作教完一块。

## 两条路线的安排

首次只展示一个小目标和开始动作，默认从新时代思想A1起步；可直接切到基本原理起点，两者无强制前后关系。完整路线与换主题是次级入口；每组结束可停下，明确选择下一组后先确认范围，开始成功保存才切换。原文与可选参考不构成通关条件。
