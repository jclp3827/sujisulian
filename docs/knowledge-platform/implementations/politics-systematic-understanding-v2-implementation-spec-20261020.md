# 系统学习小单元样板实施规格

日期：2026-10-20。阶段：P2。依据：[产品方案](politics-systematic-understanding-v2-product-plan-20261020.md)、[内容可用性表](politics-systematic-understanding-v2-content-inventory-20261020.md)、[连续阅读稿](politics-systematic-understanding-v2-content-samples-20261020.md)。

本规格用于下一批政治候选样板实现。14 个小单元仍是教学草稿，来源核对不授予内容终审或体验验收。当前运行中的 J3 仍采用完整阅读与回忆；本规格不声称样板页面已存在。

## 1 接入范围

首批仅接入十个明确 4 单元、商品劳动价值量 3 单元、高质量发展 7 单元，三组独立试读，不按数组拼成一条全量课程。入口显示可试读范围，不将缺少 A1 前序脚本的十个明确宣称为全库默认起点。

候选小单元入口与现有系统学习使用同一目标身份 `systematic`，但有明确的编排版本。P3 提供可辨认的候选入口后测试，既有默认入口在完成样板体验评估前保持当前行为；已有有效小单元会话则无论从哪个系统学习入口进入，都优先按正确模式恢复。最终推广时再统一切换；不永久保留两套同名学习产品。

## 2 内容制品与版本

P1 的 `systematic-learning-v2-samples.json` 是作者制品，保存目标、解释、边界、回看、可选参考、顺序、枚举责任与来源绑定；`systematic-learning-v2-content-inventory.json` 持有 37 篇可用性和来源块底稿。

P3 增加确定性编译步骤，将通过检查的候选脚本生成独立的政治学习编排产物，禁止页面直接读取 docs。产物包含：

| 字段 | 约束 |
|---|---|
| id / curriculumVersion | 由样板正文、顺序、引用及编排元数据生成确定性版本 |
| knowledgePackageVersion | 绑定被引用的正式事实包，加载时核对 |
| candidateOnly / reviewState | 草稿仅能从候选入口进入，正式默认构建不得自动采用 |
| groups / lessons | 稳定组与单元 ID；固定单元顺序；未编写后续只作说明，不生成可点击空入口 |
| sourceBindings | 来源块 ID 与原文哈希；失效时拒绝编译或明确不可用 |
| renderParts | 每段稳定标识、文本片段、强调与来源；可恢复位置绑定段落标识 |

正式知识内容与学习编排分别持有版本。仅修改教学编排不改变正式事实包的字节或版本，不因此使快速了解、易混与速记会话全部失效。若正式事实实际变化，则照既有内容版本规则处理，不绕过失效检查。

编排产物是正式来源上的派生内容，不保存第二套正式事实。运行时只消费编译产物；原文跳转继续使用正式 pointId/blockId。

## 3 计划与会话归属

沿用既有 `RoutePlan → RouteSession → route-progress` 持久化通道。新计划增加 `experienceKind=systematic-units-v2`、`curriculumId/curriculumVersion`、当前组与有序 lessonIds；一个计划对应一组样板。

每单元只生成一个必需阅读步骤。问题、目标、解释、边界、回看和参考展开都是该步骤的内容，不各自产生待完成任务。参考表达展开是可选会话信息，不生成 recall 必需步骤，不写入速记自评。

当前单元由 `plan.steps[session.currentIndex]` 推导。单元已读从既有完成步骤集合推导；不得另设一份与它并行的已读列表。当前步骤已读但尚未继续时，投影为本单元收尾；该界面状态也由完成记录推导。

保存当前单元的段落锚点；回源前保存来源单元和锚点，原生返回恢复同一处。段落缺失但版本兼容时明确回到本单元顶部，不跳到其他单元。

## 4 合法事件与完成语义

| 用户动作 | 事件与状态 | 不发生的变化 |
|---|---|---|
| 本单元读完 | `COMPLETE_SYSTEMATIC_UNIT`，只将当前阅读步骤记为完成，显示收尾 | 不自动把索引移到下一单元，不生成掌握结果 |
| 继续下一单元 | `CONTINUE_SYSTEMATIC_UNIT`，仅当前单元已读且有合法后继时推进 | 不因打开参考或全文而自动推进 |
| 今天先到这里 | 保存后返回政治首页；当前单元保持已读，下一单元可推荐 | 不把未读单元标为跳过或完成 |
| 稍后继续 / 原生返回 | 保存未完成单元与段落位置 | 不完成单元 |
| 暂时跳过 | 记录当前单元跳过状态，按明确动作继续 | 不加入完成步骤集合 |
| 回看已读单元 | 显示内容并保留当前推进位置 | 不倒退或清空已读记录 |

最后一个必需单元明确读完后，当前组可结束；有跳过则报告“本组已结束，仍有未读单元”，不能写“全部读完”。三组之间不自动跳转。

同一完成事件重复触发应幂等。继续事件必须核对计划版本、当前单元及合法后继；快速双击不得跳过一个单元。保存失败显示重试，停留原处，不返回首页或伪造保存成功。

## 5 页面结构

阅读页保持一页连续内容：当前主题与位置、单元标题、目标、解释段落、就近边界、整体回看、可选自问与参考。只提供一个“本单元读完”主动作，以及独立的“稍后继续”。

标题、强调、边界、字号与来源复用共享阅读能力。按单元投影所需内容，不将整个正式文章塞入默认页面；完整正文仍由现有知识正文组件负责。来源入口可放在次级查阅区，不在每段之间堆技术性标签。

完成后显示一句已读目标与下一单元标题。“今天先到这里”和“继续下一单元”都是有效选择；不重复播放整个回看，也不立即开始下一页。最后一单元显示本组结束与返回首页，不出现无效下一步。

源条目顺序与必要条件不因页面裁剪改变。强调使用精确片段，始终开启；长名称自然换行。没有正式可用对照或匹配回忆资料时不显示易混、速记空入口。

## 6 首页与入口

有效未读单元：显示“继续……”与具体单元标题，点击恢复该单元锚点。

当前单元已读且有后继：显示“接着了解……”与后继标题。点击才触发显式继续意图；同时核对原当前单元 ID 和版本，重复点击不再推进一次。

本组已结束：提供回看该组与其他已开放组，不能用三个样板的结束状态宣称整条两篇路线完成。

路线与换组位于次级入口，产品给出建议顺序与内容理由。四目标进度继续独立，无冲突确认；用户不必先完成快速了解。

## 7 旧进度与候选进入

保持既有系统学习记录。进入小单元候选时，若存在旧文章路线，显示“学习内容已重新编排”，说明原记录会保留并提供继续旧任务或开始候选的选择；仅用户明确开始候选后按现有历史机制归档旧记录。归档写入失败不得覆盖当前记录。

旧版已完成文章或回忆不折算成新单元已读。候选阶段从哪个入口进入、所选组和建议起点均显式记录，不能猜测旧步骤数字对应的新单元。

现有 `archiveActiveRoute` 只保留最近 8 条历史，且无按组恢复入口，因此不能用它承诺多组的长期恢复。P3 在 `knowledgeRoute:politics:systematic` 同一个键下扩展兼容封装：顶层 `planOptions/session` 继续是唯一当前会话，`savedSystematicRecords` 仅保存不活跃计划的原始会话，以计划及编排版本定位；当前计划不得同时出现在保存区。切换时构造完整新封装并一次写入，成功后才更新界面；取消或保存失败保持原封装。原始文章会话也保留在这一不活跃区，审计历史不承担恢复事实。

`route-progress.js` 增加纯函数负责封装读取、保存区选择与切换构造，页面沿用既有存储读写通道。恢复已保存组时只采用兼容版本；旧内容漂移按明确失效处理。快速了解、易混、速记继续使用各自既有键，不因本封装修改而迁移。

编排版本失效时显示重建说明，保留旧记录；仅缺少兼容锚点时退回本单元顶部。不能把内容版本漂移当作已读进度可无条件继承。

## 8 构建与内容门禁

候选编译至少检查：源文件及源块哈希、引用存在、目标与必要边界非空、单元顺序闭合、枚举组不漏项、重点精确匹配、说明与参考均有来源、组间无伪造后继、候选状态不可隐式发布。

正文预算超过初始上限时阻止本批候选生成并提示复核拆分；将来可经内容审查调整预算，不能由页面截断处理。检查仅验证结构与引用，解释是否充分、准确仍需编辑和用户阅读反馈。

当前样板默认正文 344—574 字，十个明确十条均在默认解释中出现；可选参考不能充当枚举缺项的补丁。未编写主题仍记录为未编写，不能因在可用性表中存在就变为可点击课程。

## 9 P3 验证清单

| 范围 | 必需验证 |
|---|---|
| 真实消费 | 候选入口真实加载新编排，目标与段落来自产物，非静态样例 |
| 阅读闭合 | 不展开参考、不打开全文也可读完单元；默认无逐篇回忆阶段 |
| 推进与收尾 | 完成仅到收尾，继续才进入后继；末单元无非法下一步；重复动作幂等 |
| 离开恢复 | 中途锚点、收尾状态、首页下一单元、全文往返及原生返回 |
| 版本与存储 | 旧文章记录归档失败、版本漂移、缺失引用、保存失败、换组取消与恢复 |
| 目标隔离 | 快速了解、易混、速记记录与事实包版本保持兼容，不能因编排变化统一失效 |
| 表现 | 390px 本地核对，320px、大字号与固定操作区分别验证；未验证项明确列出 |

正式知识、已确认快速了解和相邻路线回归按实际改动选取；没有更改的模块不因本任务重写测试。真实新手理解与自然结束感保留为 P5，不能由自动检查替代。

## 10 与现行上层规范的对应

政治小单元候选是现有“完整阅读 → 回忆”规则的已授权专项变更。总纲目标、产品模型、内容契约与路线规则增加本规格索引并标明候选适用范围。旧 J3 验收继续对应旧运行实现，新样板需单独获得消费、交互与体验证据。

本规格不自动迁移其他知识模块，不改变内容发布资格，不授权上传或合并主线。
