# 政治理论四类学习入口与系统学习小单元产品方案

日期：2026-10-20。

状态：用户已确认“小目标、轻量而有深度、产品编排路线”的方向，并授权建立方案。本方案已登记；主题拆分、内容脚本和新界面尚未实施。现有快速了解内容保持已确认版本，发布、上传与主线合并继续暂停。

适用范围：政治理论当前两篇、37 篇正式知识。下文是政治模块的下一版产品设计，不自动改变常识和笔记，也不把方案登记等同于体验验收。

## 1 产品定位

保留快速了解、系统学习、易混突破、考前速记四个入口。它们按用户意图区分，共用正式知识、来源和阅读能力。自由阅读与知识空间是共同底座，不替代四个入口中的任何一个。

系统学习的定位为：**沿产品安排的路线，一次围绕一个清楚的小目标理解必要知识，逐步把局部连接成体系。**

“系统”由整条路线的覆盖、前置安排、知识衔接和阶段归纳共同保证；“轻量”由单次目标、默认内容量和自然结束点保证。不能以连续读完所有文章代替系统理解，也不能以只认得术语代替有深度的学习。

首版保留“系统学习”的入口名称，说明语采用“一次学懂一个小目标，逐步串起知识”。“学懂”表达产品目标，结果反馈只报告实际阅读和自我回想行为，不判定用户已经掌握。

### 四个入口的分工

| 入口 | 用户的问题 | 默认内容与粒度 | 一次结束的位置 | 不承担的任务 |
|---|---|---|---|---|
| 快速了解 | 这里有什么，主要讲什么 | 现有六单元全貌导读，关键名称与最小含义 | 六单元收束，允许中途保存 | 逐项解释每组内容、验证理解或完整阅读 |
| 系统学习 | 这个概念或这组知识到底是什么意思，怎样联系起来 | 一个小目标对应一个学习单元；解释、必要条件和联系 | 本单元合拢后即可结束，下一个单元可选继续 | 每次展示整个主题、逐篇回忆、刷题或背完整清单 |
| 易混突破 | 这两个概念为什么容易混，怎样分清 | 一组有正式依据的对照，围绕同一判断维度 | 完成本组既有辨析流程 | 重讲整个主题、为所有概念制造易混对 |
| 考前速记 | 已接触的关键内容现在还能否想起 | 明确范围的现有回忆卡组，必要时回看 | 本组回忆结束 | 用记忆表现代替系统解释，强迫系统学习用户进入速记 |

同一知识可以服务四个目标，但默认呈现的内容不同。例如快速了解说明“十个明确”的大致作用；系统学习逐步解释其具体内容与联系；易混只处理有依据的特定区别；速记使用经过审核的回忆问题。

四个入口不是必须依次完成的课程漏斗。系统学习可独立开始，快速了解不作前置门槛；各目标进度继续独立。系统学习末尾不默认把用户送入易混或速记。

## 2 当前问题与本轮裁决

当前系统学习已实现正式范围、前置排序、同源全文和阅读后回忆。默认总论包含 4 篇，正文块文本含标题粗计 5,027 字；37 篇单篇约 265 至 2,357 字，全部各有一个回忆项。当前范围选择能细分部分新时代思想内容，但马原主要只能选整篇 18 个知识。

| 当前安排 | 下一版裁决 |
|---|---|
| 正式篇章同时决定用户一次学习的大小 | 正式目录保持知识身份；学习单元另按理解目标组织 |
| 一篇全文阅读后默认进入一次回忆 | 解释过程中自然推进，每个小单元末尾最多一次轻量回想 |
| 必须先看完整篇才能推进 | 默认内容自身讲清本次目标，完整原文作为可选查阅 |
| 以“按正式顺序”解释为什么学下一篇 | 保留前置约束，每次补充有内容意义的衔接 |
| 完成页主要统计阅读和回忆数量 | 先回看本单元的内容关系，再给结束与下一单元选择 |
| 选择篇、章、节作为主要范围控制 | 优先恢复当前小单元或推荐下一小单元，查看路线与换主题为次级 |

本轮改的是默认内容编排与学习粒度。全文、来源、目录、跨知识关系和回忆能力继续复用；不另建第二份正式知识库。

## 3 路线 主题与学习单元

采用“学习路线 → 主题 → 学习单元 → 内容段落”的组织方式。

| 层次 | 职责 | 示例 |
|---|---|---|
| 学习路线 | 保持长期顺序、前置约束和覆盖进度 | 新时代思想；马克思主义基本原理 |
| 主题 | 聚合相近的理解目标，帮助定位 | 科学体系；认识与实践 |
| 学习单元 | 用户一次可以自然完成的小目标 | 十个明确中的领导力量、总任务与社会主要矛盾 |
| 内容段落 | 连续解释本单元的必要内容 | 关键表述、最小解释、关系衔接、必要边界 |

一篇正式知识可以供多个学习单元引用，一个学习单元也可以引用几篇中的必要内容。二者通过稳定知识与块引用关联，不修改正式目录，也不凭浏览分组新增理论分类。

拆分规则：

1. 一个单元只设一个核心问题，通常设 1 至 3 个明确理解目标。
2. 如果某个概念的解释、必要条件与边界尚未闭合，不因字数或屏数而切断。
3. 如果用户需要同时记住多组无直接关系的概念，或出现第二个独立问题，应拆为下一单元。
4. “十个明确”可以是主题内的一组内容，不强行规定它必须一口气讲完，也不机械拆成十个页面。
5. 多个小单元组成的主题要有合拢位置，避免局部读得轻松、最终仍无法连成整体。

## 4 每个单元的内容合同

内容脚本先明确“本次必须理解什么”，再决定选材与排版。每个单元在编写时必须填写以下字段，用户界面只展示与阅读有关的内容。

| 字段 | 必须回答的问题 |
|---|---|
| 标题与核心问题 | 这次究竟要弄明白什么 |
| 理解目标 | 结束时希望用户能够解释哪 1 至 3 件事 |
| 完成边界 | 哪些内容本次解释，哪些留在后续或查阅 |
| 最小前置 | 哪些概念必须先有最小认识，如何在当前页补足 |
| 解释内容 | 哪些正式原句、最小解释和例子足以支撑目标 |
| 知识联系 | 本单元内部以及前后单元之间为什么相关 |
| 必要条件与区别 | 省略什么会导致误解，哪些概念不能互换 |
| 合拢表达 | 如何把刚才的内容放回同一个结构 |
| 轻量回想 | 一个可自问的问题及有来源的参考表达 |
| 来源与覆盖 | 对应哪些 unit、block 或 atom，承担哪些核心内容 |
| 下一单元 | 默认接着学什么，以及内容上的衔接理由 |

### 默认内容与可选内容

默认显示核心解释、支撑结论的必要条件、关键联系，以及避免误解所需的边界。它们必须使本单元独立成立，不能把关键解释藏到“查看全文”中。

可选内容包括扩展背景、更多例子、完整历史材料和不属于本次目标的详细条目。完整原文始终可查，返回后恢复到当前单元和阅读位置，不改变学习进度。

枚举组的范围必须诚实。例如目标为“理解十个明确的主要内容”时，整组后续单元合起来必须实质覆盖十条，不能只提名称、解释三条、把余下全部移到查阅层。单次只讲其中三条时，标题与完成边界必须说明是哪一部分。

### 轻量与深度的共同标准

- 内部试写以单元默认正文约 400 至 800 字作为初始预算，标题另计。超过约 900 字应复核是否包含多个目标；这不是硬截断线，也不作为用户可见的时长承诺。
- 简单目标可以更短；复杂目标优先拆分或增加自然段落，不缩字号、不删必要条件来凑预算。
- 深度至少体现为：解释概念含义，说明关系或理由，并保留必要边界；不以堆积术语、增加字数或要求背诵来证明。
- 例子只在能帮助理解时使用。有正式来源则引用；教学情境须明确其性质，不能凭例子推导新的事实或政策结论。
- 重点默认显示，沿用正文的精确行内标注，不增加关闭开关或标签墙。

## 5 一次学习的阅读节奏

五个环节是内容组织原则，不强制对应五页、五个按钮或五次打卡。

| 环节 | 默认呈现 | 用户动作 |
|---|---|---|
| 明确问题与目标 | 标题、一句本次目标、必要时一句最小前置 | 直接开始阅读，不先填写或确认目标 |
| 逐步解释关键知识 | 连续的短段落与少量明确小标题；随内容解释关系 | 正常阅读和滚动 |
| 保留必要边界 | 放在相关解释附近，不统一堆到文末 | 需要时查看补充原文 |
| 合起来回看 | 一段归纳或简洁关系结构，回答开头的问题 | 到此有明确收束感 |
| 一次轻量自我解释 | 一个自问提示，参考表达默认收起 | 可想一想再展开，也可直接结束 |

“本单元读完”无需填写答案、评分、背诵或打开参考表达。结束事件只记录单元已读；展开参考仅记录展开行为，不计算掌握率。

每个单元是一页可连续滚动的阅读内容，不机械把一个概念拆成多次点击。正文仍过长时先复核目标与拆分，不依赖连续“下一步”隐藏篇幅。

### 覆盖验收

建立两层覆盖表：

1. 篇级：当前 37 篇都归入主题，明确主要学习单元与完整正文入口。
2. 核心内容级：从现有语义块和知识原子中人工确定每个主题承诺讲清的内容，逐项映射到默认解释、必要边界或合理的可选资料；不能仅凭来源引用计作已覆盖。

若本轮只完成样板，产品只能开放已完成的单元并说明可学范围；不能以 37 篇均有标题映射宣称新路线已全量实现。

总体边界继续是当前两篇。科学社会主义无独立详细单元，时政、党史不在范围内，完整考试大纲覆盖尚未证明。本方案不补造这些内容。

## 8 入口 推进与自然结束

### 推荐顺序

1. 恢复有效的未完成单元，显示具体标题与上次位置。
2. 没有未完成单元时，推荐当前路线的下一单元。
3. 从具体主题主动进入时，推荐该主题的起点，先提供最小前置提示。
4. 无上下文时采用首批路线的明确默认起点，不声称个性化最优。

首次页面只需说明本次主题、小目标和开始动作；完整路线、主题切换、已读单元回看放在次级入口。既不要求用户自己组课，也不锁死用户顺序选择。

### 推进与离开

- 阅读页底部主动作“本单元读完”。点击后用一句话确认本次已读目标，并呈现下一单元标题；不重复播放归纳内容，也不自动开始下一单元。
- 收尾主动作“今天先到这里”，保存后返回政治首页；“继续下一单元”作为清楚可见的另一个选择。两者都不表示失败或中断惩罚。
- 中途“稍后继续”保存当前位置；原生返回按既有规则保存，回到入口后能继续同一内容段落。
- 完成后首页推荐下一单元，文案为“接着了解……”；未完成则为“继续……”并显示具体单元。
- 最后一单元完成时仅表示这条已开放路线已读完；不展示掌握率，也不自动进入另一条路线或速记。
- 回看已完成单元不重置进度；切换主题或路线先保存原位置，返回时继续可恢复。

前置提醒就近提供有来源的最小说明和可选入口。学习记录不足不能被当作能力不足，也不能为了继续当前单元强迫用户读完一整条前置路线。

### 进度语义

当前单元与主题内位置优先展示，如“十个明确 · 第 1 单元”。整条路线的完成情况在次级路线视图中展示，不把 37 篇或内部内容段落堆成首页待办任务。

已读、未读、中途离开、参考展开分别记录。一个单元的明确结束不等于整个主题完成，更不等于对应正式文章全部读过；只有全部必需单元都明确结束，主题才标记已读完。允许跳过，但记录为暂未阅读，不冒充完成。

## 9 四模块之间的衔接

快速了解的结束页保留可选系统学习入口；进入后落到推荐的小单元，不重复播放全貌导读。若今后添加主题直达入口，必须映射到具体可用单元，不按快速了解的页数自动映射学习进度。

系统学习只讲清本单元必要的区别。存在正式易混对且用户需要进一步练习时，提供“进一步辨析”的次级入口，往返后恢复当前单元。没有正式对照能力时不显示空入口。

速记继续使用现有正式回忆资料。新单元若没有匹配的回忆项，仍可正常学习与结束；不能将整篇现有回忆题硬塞给只读了其中一部分的用户。新的自我解释题属于教学内容，需单独记录来源与审查，不能直接冒充已验证的速记题。

查看完整正文、易混或速记不自动完成学习单元，也不覆盖其他目标进度。四个入口只是对同一份知识采取不同方式，不复制正式事实。

## 10 内容与实现约束

正式 Markdown、稳定 unit/block/atom 与已确认关系继续是事实来源。新增学习编排制品保存主题顺序、学习目标、来源片段、过渡说明、必要边界、自我解释与覆盖清单。

原文摘取使用稳定引用或精确选择器；必须结合原上下文核对，不能截掉限定条件。教学解释可以按已核对来源另行编写，但属于经过审查的派生内容，不能在页面运行时自动生成事实或把教学衔接写回正式关系图。

后续实现应明确区分：

| 对象 | 持有的事实 |
|---|---|
| 正式知识 | 原始内容、知识身份、来源与语义关系 |
| 学习编排制品 | 路线、主题、单元、目标、来源绑定与覆盖责任 |
| 学习计划 | 本次采用的单元顺序及版本 |
| 既有会话与持久化层 | 当前单元、位置、明确结束与跳过记录 |
| 界面 | 阅读排版与临时展开状态 |

沿用 RoutePlan/RouteSession 的状态归属与存储通道，扩展小单元语义；具体迁移字段在实施规格中确定。不另建与既有会话并行的完成状态来源。

共享正文的片段、重点与来源渲染能力应继续复用。增加“按单元选择内容”的投影，不把整个完整卡强行塞进单元；完整原文仍由现有正文组件负责。

源内容变化、引用失效或必要边界缺失时，候选构建失败或单元不可用；不静默删去失效内容后仍展示“内容完整”。产品文案不暴露构建器字段和内部审查标签。

旧版系统学习按文章与回忆记录的进度不能直接折算为新单元已完成。保留旧记录，明确说明路线已调整；可提示原来阅读的位置并给出可解释的新起点，由用户选择开始，不按数字强行迁移。快速了解、易混与速记记录不变。

## 11 分阶段实施路径

| 阶段 | 工作与产物 | 完成依据 |
|---|---|---|
| P0 产品方案 | 本方案、四入口分工、首批主题骨架及登记入口 | 已登记；不改运行代码 |
| P1 内容设计 | 建立 37 篇与核心内容覆盖表；编写十个明确连续单元、商品与劳动相连单元、高质量发展长文拆分样板 | 默认内容闭合目标；边界完整；来源精确；确认最终拆分与正文预算 |
| P2 实施规格 | 确定编排制品与会话字段、候选开关、旧进度恢复、共享片段投影及页面动作 | 可执行规格与正反例齐备；同步上层规范的政治专项变更 |
| P3 样板实现 | 接入候选小单元路线，默认显示目标与解释、单元收尾、恢复、可选全文 | 自动检查与本地交互通过；可以完整演示多个相连单元 |
| P4 内容扩展 | 按主题逐批加工，逐项补齐覆盖表与回看衔接 | 每批先完成内容核对再开放；未完成主题不冒充可学 |
| P5 产品验收 | 核对首次理解、阅读负担、前后衔接和自然结束感 | 用户能说清单元目标与主要关系；体验反馈与自动结果分开记录 |

实施顺序先内容、再规格、再界面。首先用连续的真实样板确认学习单元是否合理，避免先搭一套通用课程外壳再填内容。无需等全部 37 篇重编完才验证样板，也不能把样板通过外推为全量完成。

本轮授权只完成 P0。后续执行仍需以用户继续实施的指令为依据；方案中的阶段不是自动发布授权。

## 12 验收标准

| 编号 | 可检查的标准 |
|---|---|
| AC01 定位 | 四入口的用户目标、默认内容与结束方式可区分；系统学习不依赖先完成快速了解 |
| AC02 小目标 | 每个单元有一个核心问题和明确理解目标，不以整篇标题代替目标 |
| AC03 默认内容完整 | 不打开全文或补充材料，也能接触解释本次目标所需的事实、关系与必要边界 |
| AC04 深度 | 内容能帮助解释含义与联系，不能仅重复快速了解的一句话作用说明 |
| AC05 枚举覆盖 | 十个明确等已承诺展开的组在所属单元集合中不漏项，原序号和关键含义可核对 |
| AC06 整体覆盖 | 篇级覆盖闭合当前 37 篇；核心内容有具体承担单元，资料缺口明确，不把仅引用当作已讲清 |
| AC07 自然结束 | 一个单元可以独立结束；参考表达可不展开；结束不强制继续、测试或切换其他目标 |
| AC08 连续性 | 未完成恢复原单元与内容位置，已完成推荐下一单元；主题收尾能将已读内容合拢 |
| AC09 状态诚实 | 阅读、结束、跳过、自我解释与掌握程度不混同；旧文章进度不冒充新单元进度 |
| AC10 同源与隔离 | 片段、解释与答案均能回源；其余三个目标、完整正文及照片工作区不受改动 |
| AC11 显示与操作 | 长名称、重点跨行、320px/390px、大字号、正文往返及固定操作区遮挡分别检查；未测项不标通过 |
| AC12 内容失效 | 缺失引用、源内容漂移、缺少必要边界和不完整枚举有真实拒绝或不可用处理 |

自动检查证明引用、覆盖声明、顺序与状态正确；新手是否理解、一次是否过重、结束是否自然仍需要阅读反馈。文档登记不授予这些验收结果。
