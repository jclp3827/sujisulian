## 1. 盘点范围

盘点以用户实际页面为准，而不是直接照抄作者源字段：

| 对象 | 数量 |
|---|---:|
| 显示标题／核心问题／合并后的学习结果 | 72／72／72 |
| 正文小标题／正文 | 186／186 |
| 边界标题与正文 | 72／72 |
| 结论标题与正文 | 72／72 |
| 自测题／参考答案 | 72／72 |
| 主要及相关来源入口 | 96 |
| 合计 | **1116** |

作者源有97条独立目标，但页面将每节目标合并为一条“读完能理解”，因此按72个结果对象审核。页面还会为每节显示主要来源，并在24节显示相关来源入口，因此加入96个来源入口。按这一真实投影计算为1116个对象。

覆盖结果：2条路线、21个主题、72节、186个正文段落均进入台账；15个截图种子全部映射到稳定`objectId`。

## 2. 结论

截图问题是系统性的，不是15处局部文案错误。

- 63节至少被一个AI角色或截图种子确认存在L1/L2问题；
- 9节没有角色确认问题，但仍有机器候选，只能记为“本轮无新增信号”，不能称为通过；
- 去重后确认114个对象级问题，其中L1 26项、L2 88项；
- 另有238个机器候选等待编辑定性；机器命中没有自动转成问题；
- 四角色分别覆盖72节，共180条逐节意见；不同角色状态独立保存，没有按多数票合并；
- 角色级hold合计触及20节，其中学科事实或来源直接阻断为4节。

已确认问题按切片分布：

| 切片 | 已确认数 | 主要表现 |

| S3 来源层泄漏 | 21 | 用“原文、正文、现有材料”代替知识对象 |

| S8 事实与边界 | 19 | 教学分类越界、来源限缩或对象来源不充分 |

## 3. 四角色审核结果

| 角色 | risk | hold | 本轮无新增信号 | 结论边界 |
|---|---:|---:|---:|---|
| AI首次使用者 | 48 | 1 | 23 | 20/21主题出现理解风险；不代表事实判断 |
| AI公考学习者 | 48 | 1 | 23 | 同一只读审查中的考试学习视角，关注快速理解与迁移价值 |
| AI学科专家 | 25 | 4 | 43 | 只核当前绑定来源；不以模型常识补源 |
| AI测评与内容设计专家 | 37 | 16 | 19 | 关注题答对应、任务数量、模块职责与小节粒度 |

“本轮无新增信号”不是`pass`、`accepted`或真人理解验收。AI首次使用者与公考学习者在同一次只读审查中分别记录两个视角；学科与测评角色独立执行。

学科审核的4个直接hold为：

1. `DEMOCRACY-03`把统一战线写成人民当家作主的第三层，当前来源不支持这一上位分类；
2. `CULTUREECO-02`自测答案混入生态来源，部分职责表述缺少直接支持；
3. `PARTY-02`自测答案混入反腐与自我革命来源，并加入未被当前块直接支持的结论；
4. `COGNITION-01`答案缺少支持“不要求人人亲历”的直接来源块。

这组发现将合同从10条增补为11条：每个用户可见事实对象必须绑定自己的最小充分来源集。

## 5. UC2样板与实施顺序

UC2使用六节样板覆盖八类问题和本轮新增来源合同：

| 样板 | 主要覆盖 | 先解决什么 |
|---|---|---|
| `TEN-02` | S1/S4/S8 | 补足“十个明确”父级锚点，区分正式对象与教学连续阅读 |
| `TEN-03` | S2/S3/S4 | 删除编辑动作标题和来源层语言，改成制度、理念、格局的直接映射 |
| `SYS-01` | S2/S4/S7/S8 | 四组内容逐项说明职责，保持十三个方面的来源限缩 |
| `MOD-01` | S5/S7 | 将虚构提纲纠错移出默认自测，改为一个直接理解问题 |
| `DEV-06` | S4/S6/S8 | 核对五项定位和最小来源，答案先写明对象再解释关系 |
| `DIALECTICS-01` | S4/S5 | 裁决当前小节是否过宽，必要时先提出拆分方案而不直接迁移旧进度 |

实施顺序为：先冻结六节当前对象和来源 → 分别给出最小改写与删除／迁移决定 → 学科角色逐对象核源 → 首次用户与公考学习者复述测试 → 测评角色检查一题一目标 → 重建候选并验证稳定ID和进度影响。样板仍出现“用户不知道在说什么”或事实来源越界时，停在UC2补规则，不扩到UC3。
