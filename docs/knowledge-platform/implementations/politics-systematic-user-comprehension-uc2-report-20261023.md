## 2. 关键裁决

### 2.1 教学整理不冒充正式分类

- `TEN-02`第4至6条是连续阅读安排，不是正式子系统，也不建立布局与两个总目标的一一对应。
- `TEN-03`按制度、阶段、理念、格局和质量建立理解线索，但答案仍完整回到第7条的正式内容。
- `DEV-06`的五项内容只用于定位辨析，不等于乡村振兴的完整结构；“五项振兴”是另一组正式内容。

### 2.2 默认自测只保留直接任务

- `SYS-01`用四组定位的直接回忆题替代情境辨认。
- `MOD-01`删除产品虚构的提纲纠错；该题只登记为理解应用题审核候选，没有进入其他题库。
- 六节最终题干、默认正文、自测和答案使用同一对象集合，答案逐项对应。

### 2.3 DIALECTICS-01拆段不拆节

首次用户和学科专家支持保留一节，首轮测评角色提出拆节。最终按正式来源单元和最小学习目标裁决为三个并列展示段：联系的客观性与条件、整体与部分的功能关系、新旧事物的发展趋势标准。

只有真实首次用户仍把“发展”理解成第四个独立任务、无法一次复述三种标准，或后续继续加入应用材料时，才重新提出拆节；不得静默改变旧进度。

## 3. 来源处理

最终提案逐对象检查106个`sourceBlockIds`引用，学科角色确认全部存在且直接支持当前对象，无来源缺口或事实越界。

假设作者稿的精确绑定由490项降至479项。11个不再使用的绑定只从假设作者稿的精确绑定表移除，对应来源块仍保留在正式知识包和内容盘点中，作为查阅材料或后续相邻小节审查输入，不删除知识源。其中包括乡村振兴的总纲／总抓手／农业强国头等大事、实现中国梦三个途径的展开解释、2035年后细目、三组时代课题和联系普遍性的重复解释；`u007:b052`则与本节乡村振兴结论无关。

为避免把内容生产状态暴露给用户，`SYS-01`使用“本节只比较定位，不展开完整清单”的知识范围表达。现有内容验证器同时接受旧候选的“没有逐项列出”和新提案的“不展开完整清单”，仍会阻止把十三个方面成就冒充完整展开。
