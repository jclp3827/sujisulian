## 3. 自查维度

| 编号 | 检查项 | 通过标准 | 检查方式 |
|---|---|---|---|
| C01 | 用户语言 | 普通界面无内部工作流/测试术语；必要领域术语与错误提示准确 | 可见文案、无障碍标签及投影逐项核对 |
| C02 | 冗余 | 相同范围、数量、阶段与动作不重复出现；说明不争抢内容 | 看首屏及各阶段，逐块判断是否可合并 |
| C03 | 信息层级 | 操作对象和核心内容醒目；辅助说明不与主内容同权重 | 截图与实际阅读核对 |
| C04 | 阶段关系 | 阅读/回忆是同一知识的连续阶段；初判/复答互不混淆 | 顺序操作并检查状态 |
| C05 | 主次动作 | 主动作明确；上下位置稳定；范围调整不重复；退出有一致职责 | 各状态实点，核对按钮矩阵 |
| C06 | 输入与步骤 | 快速了解不要求键盘；无无必要确认与中转 | 全流程不输入完成一次 |
| C07 | 字体 | 标题、正文、标签和说明使用对应角色；正文可读、不靠小字挤空间 | token 消费及当前模拟器呈现 |
| C08 | 图标与箭头 | 同角色形态、尺寸一致；视觉缩小不缩小可点热区 | token/组件及实际点击 |
| C09 | 间距与对齐 | 页面边距、卡片内边距、段间距一致；按钮文字水平/垂直居中 | 样式角色及当前界面 |
| C10 | 底部操作 | 连续流程操作区一致；末尾、自评、错误不被遮挡 | 滚动到底与不同阶段验证 |
| C11 | 返回与进度 | 正文返回正确来源、对象与位置；暂停/重进不丢状态 | 页面路径及进度核对 |
| C12 | 必要边界 | 精简不删除真实内容覆盖范围、未保存错误和恢复操作 | 与现有数据含义核对 |
| C13 | 模块一致性 | 结构与动作角色一致、政治颜色作皮肤；例外有使用理由 | 同角色对照，其他模块不修改 |
| C14 | 完成结果 | 只报告真实行为，不把浏览或点击说成掌握 | 完成状态、报告字段与文案核对 |
