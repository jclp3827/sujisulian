# 云端题库分批加载实施批次（2026-10-28）

## 范围与发布边界

覆盖笔记练习、笔记快记、常识问答与知识导读。政治理论、照片处理和支付链路不纳入本批次。题目正文由 `learningBank` 云函数按需返回；小程序保留来源导航、答题、学习记录及设置语义。用户负责小程序上传、审核和正式发布，本计划执行到可交付候选与真机验收门。

| 批次 | 工作 | 完成条件 |
| --- | --- | --- |
| B0 基线 | 核对工作树、公开准入规则、原题库数量与未提交改动 | 所有无关改动保留，公开内容边界明确 |
| B1 数据与云函数 | 生成公开题库目录及每五条正文分片；实现目录、开组、续批、按 ID 恢复、版本检查 | 五库数量、ID、哈希、范围、单批大小本地校验通过，云函数部署成功 |

| B5 真机验收门 | 用待上传候选在真机检查首屏、第二批、弱网重试、旧记录、退出再进、各入口设置 | 取得用户或真机实际结果后才能宣布上传就绪；小程序上传仍由用户完成 |

## 执行与停止规则

同一批次的代码修改、构建和模拟器验证由实施者自行完成。若 B1–B4 出现功能或内容不一致，先修复并重新验证。B5 必须有真实手机操作证据；开发者工具模拟器不替代该证据。到 B5 如无法直接完成真机操作，停在验收门，提供精确候选状态、测试步骤和剩余风险，不代替用户上传。

扩库按“源内容审核 → 构建 → 校验 → 部署新云函数 → 体验版验证 → 用户上传”顺序进行。当前云函数只保留一个活跃题库版本，旧轮次锁定旧版本尚未实现；在建立版本并存机制前，扩库或改题须作为新发布批次单独验收。
