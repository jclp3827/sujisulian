## 产品决定

| 决策 | 本次确定的行为 |
|---|---|
| NOTE-001 | 主要练习方式固定为基础快练、方法判断、完整题应用。按主要作答动作区分知识回忆、辨析试用、完成原题，三个入口保留。 |
| NOTE-002 | 首页按搜索、全部笔记、三类练习入口组织。首期不新增每日、个人回顾、考前急救或政治四路线入口。 |
| NOTE-003 | 全部笔记以科目切换、专题分组、知识点直达组织；知识结构保留，目录层级尽量在同一页面切换。 |
| NOTE-004 | 三类练习均可查对应知识点和页签；原生返回恢复同一题、选择、提交状态、材料位置和题组。 |
| NOTE-005 | 正文继续由既有笔记源和构建链路维护；计算技能归既有训练，笔记保留精确跳转；新增知识原子、对照关系与小任务的离线编写适配。 |
| NOTE-006 | 后续以五个考试模块逐批重建，每模块内部按专题、每次最多12题审核；题量由有效目标确定，不跨模块平均凑数；已有完整应用按来源核验导入。 |
| NOTE-007 | 方法判断可直接比较概念、公式、条件和方法，不要求新情境；主动易混辨析主要归此入口。 |
| NOTE-008 | 所有题以公考实际调取目标为准，主归属、目标与实际考察一致；不从定义、标签、一般建议自动造快练。 |
| NOTE-009 | 题干、选项和解析不以“笔记说／本节要求”为权威；来源留在引用与查阅入口；干扰项来自同域真实误用。 |
| NOTE-010 | 图形优先口诀展开、观察清单与触发边界；口诀主归属和原正文来源分离登记，跨科来源须显式核验适配，不复制正文绕过。 |
| NOTE-011 | 笔记本体承担系统精炼、框架与知识关联；练习准入不作为删除整理／解释内容的标准。 |
| NOTE-012 | 语义回执绑定题目有效内容、规则与主／辅助目标及来源依赖，追加保存；与正式批准分离。 |
| NOTE-013 | 实质目标／知识／来源／共享绑定更新仅使相关活动组失效，保留作答与无关会话；旧实例兼容须有证据。 |

## 导航和范围

首页搜索覆盖现有五科笔记。全部笔记的科目和专题只负责定位，知识点继续使用现有详情渲染器。练习入口可选择科目、专题和数量；从某个知识点开始时自动带入范围。

首期保留资料分析、数量关系、判断推理、言语理解、图形推理五个科目及原知识点 ID。判断推理中的图形内容与独立图形科目先保留归属，使用显式关联处理；目录去重不删除原内容、不自动合并不同知识点。分类名“秒杀模块”等宣传性或含混名称列入后续目录校正清单，修改另记新旧映射。

## 三类练习

| 方式 | 检测目的 | 首期形式 | 具体笔记入口 |
|---|---|---|---|
| 基础快练 `basic` | 快速调用有明确公考用途且易混易忘的具体规则、公式、概念边界、词义限制、口诀展开与关键方法条件 | 单选承载回忆与知识确认，不做具体计算求值 | 定位本项知识页签 |
| 方法判断 `method` | 概念/公式/条件/方法直接辨析与小任务试用 | 对照问题、关系匹配、错误诊断、选法或列式，不强制新情境 | 定位对照关系、依据和相关笔记 |
| 完整题应用 `application` | 独立完成原笔记已有完整题的原任务 | 保留完整题干、材料、提问、选项及图像，逐题核验 | 定位主要和辅助知识 |

讲解型例题仍可阅读；缺选项、答案或判分规则时，不静默转换为可计分题。内容资源保存一个稳定身份，入口以显式清单复用。

## 事实和状态归属

| 事实 | 唯一归属 |
|---|---|
| 正文、公式、方法、原例题 | 现有 `miniprogram/models/note-*/` JSON 源及单向构建 |
| 学习目标、候选题、来源、入口选用 | 新增笔记派生内容源及其构建器 |
| 现成数值生成、容差、计算技能结果 | 现有训练实现；新版笔记仅准确跳转，不纳入题组计分 |
| 笔记题组、当前题、作答和查阅行为 | 笔记练习会话；独立于常识与政治状态 |
| 阅读位置 | 笔记目录和详情的导航状态 |
| 内容批准 | 对应版本的人工审核记录 |

提交前查过笔记、查看过答案、独立答对分别记录。阅读完成、揭晓或单次正确不折算为知识掌握。综合题的关联知识点不能同时被判为薄弱点。

## 复用和模块边界

常识提供目录、内容目标映射、入口编排、题组冻结与恢复的参考实现。其参考成果含未提交文件；N0已记录参考文件和哈希并保存最小依赖集合的原始字节归档与清单，形成可恢复快照。不整树搬运，不在运行时读取另一个 worktree。

政治提供多路线状态隔离、正文往返与失效恢复的参考。笔记不直接使用 `knowledgeRoute:politics:*`、政治四路线名称或政治知识包。

本次是笔记独立产品切片。用户的新请求接管旧版推广排期与首页形态中针对笔记的限制；通用平台的来源、状态隔离、逐批验证和可回退约定继续适用。该切片不宣称完成通用知识地形迁移，也不修改政治或常识的实施阶段。

## 当前实现和停止门

基础只接收单项知识回忆，方法支持直接对照和小任务，应用只选入有原例题定位的完整任务。编译与运行入口同时核对主要检测目的、来源、知识及辨析依赖；不通过数字或公式是否出现判断题型。方法题可主动查看共享对照，提交前查阅后答对记辅助完成，阅读本身不计独立答对。

两个计算配方退出笔记入口，训练生成器、30处原训练连接及用户训练历史不变。数量旧计算基础题被新ID步骤题替代，自编比例应用退出本轮原题选用，旧记录仍保存。原有7道应用内容不变可恢复旧会话；实际题目或依赖更新只影响相关会话。

两道言语例题显式补充中性作答说明，原文段、选项、答案及解析沿用原块；这不代表复原考试问句或核实考试身份。两张立体拼合讲解图已有C/D答案圈及推导，暂不作独立完整应用。正式内容批准、320px／大字号／真机往返和实际压缩包体仍为待完成门，不能由自动检查替代。
