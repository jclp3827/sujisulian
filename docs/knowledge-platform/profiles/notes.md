## 当前产品决定

| 决策 | 已确定规则 |
|---|---|
| NOTE-V5-001 | 笔记是公共积累的行测知识的系统精炼整理，以框架、关系、回忆和应用承接为目标；学习主体为知识快闪卡。 |
| NOTE-V5-002 | 首页保留搜索、全部笔记，以基础快记／方法判断／考前速记及独立的完整题应用连接学习。卡片只提供查看原文；应用题通过首页与原页承接，沿用已有题目、判分与答题记录。 |
| NOTE-V5-003 | 基础以公式、符号和必要条件直接记忆为重点，资料／数量侧重；方法以识别信号、适用范围、做法和区别为重点，判断／言语侧重。归类按目标，不按科目硬切。 |
| NOTE-V5-004 | 图推统一放入方法判断的图文知识卡，保留原配图和观察方法；标出答案的图片可作讲解，不能称独立判题。 |
| NOTE-V5-005 | 切片单位为可独立理解的知识组合；允许多块重组，保留公式条件、对照共同背景、表头／分组、导图父主题和必要图像；复杂体系关联总览与子卡。 |
| NOTE-V5-006 | 尽量引用原内容和样式。原JSON与单向构建为正文权威，现有轻量公式渲染不另造；补充标题／前提／连接语与原引文分开审阅。 |
| NOTE-V5-007 | 新轮次先回忆后揭晓，不提供模式切换；取消手势换卡，使用揭晓／自评／跳过／上一张按钮；阅读滚动不换卡。反馈保存成功才推进。 |
| NOTE-V5-008 | 四项反馈为记住了／有点模糊／没想起／跳过。跳过本次未评估，不覆盖已有有效自评或清弱项；浏览和回忆自评分别记录，不等于客观掌握。 |
| NOTE-V5-009 | 考前速记复用已有卡片，按范围筛没想起及模糊，前者优先；跨会话保存弱项，冻结本轮，重评更新下一轮，空态不混入新内容。 |
| NOTE-V5-010 | 正文页移除新增返回及知识点／专题入口，以顶部原生返回键回到原卡；原图关闭后也返回同卡，恢复位置、方式、揭晓和反馈；应用答题／曝光与卡片状态分别保留。 |
| NOTE-V5-011 | 全部卡片目录有真实数量、状态与逐卡直达，不受题组数量或题族去重限制；来源、候选组合、可用卡、可达卡和弱项数分开报告。 |
